## 题目描述

时间限制：1 秒；内存限制：512 MB。

这是一道通信题。对于每组测试，你的程序会在两个相互独立的进程中各运行一次。

### 第一次运行

给定一个 $1,2,\ldots,n$ 的排列 $p=(p_1,p_2,\ldots,p_n)$。

输出一个 $n\times n$ 的矩阵 $A$，使得每一行都是 $1,2,\ldots,n$ 的排列，且所有行两两不同。

### 第二次运行

在第二次运行前，评测程序会随机打乱 $A$ 的行顺序，得到矩阵 $B$。每一行内部的元素顺序保持不变。给定 $B$，你需要恢复第一次运行时的原排列 $p$。

无论各行以何种顺序排列，你的程序都必须正确恢复 $p$。两次运行之间不会保留任何进程状态；打乱行顺序后的矩阵是从第一次运行传递到第二次运行的唯一信息。时间限制和内存限制分别应用于每次运行。

## 输入格式

第一行包含一个字符串 $op$（为 `first` 或 `second`）和一个整数 $n$（$3\le n\le 2000$），表示当前是哪次运行以及排列的长度。两次运行中的 $n$ 相同。

如果 $op$ 为 `first`，第二行包含 $n$ 个整数 $p_1,p_2,\ldots,p_n$（$1\le p_i\le n$），构成 $1,2,\ldots,n$ 的一个排列。

如果 $op$ 为 `second`，接下来 $n$ 行，每行包含 $n$ 个整数，描述矩阵 $B$ 的一行。该矩阵由第一次运行输出的矩阵仅随机重排行顺序得到。

每次运行只有一组测试数据。

## 输出格式

如果 $op$ 为 `first`，输出 $n$ 行，每行包含 $n$ 个用空格分隔的整数，描述矩阵 $A$。每行必须恰好包含一次从 $1$ 到 $n$ 的每个整数，且这 $n$ 行必须两两不同。

如果 $op$ 为 `second`，在一行中输出 $n$ 个用空格分隔的整数，按原来的顺序给出第一次运行时的排列 $p$。

## 样例 1

### 输入

```text
first 3
2 3 1
```

### 输出

```text
2 3 1
1 2 3
3 2 1
```

## 样例 2

### 输入

```text
second 3
3 2 1
2 3 1
1 2 3
```

### 输出

```text
2 3 1
```

## 说明

两组样例展示了同一组测试的一种可行方案在第一次和第二次运行时的情况。

第一次运行中，输入排列为 $(2,3,1)$，程序输出一个 $3\times3$ 的矩阵，各行是两两不同的 $1,2,3$ 的排列。

第二次运行前，评测程序将该矩阵的第三行、第一行、第二行依次排列，每一行内部的元素顺序保持不变。程序必须从所得矩阵中恢复并输出 $(2,3,1)$。实际评测采用的行顺序可能与样例不同。
