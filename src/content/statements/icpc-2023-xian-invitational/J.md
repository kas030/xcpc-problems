## 题目描述

时间限制：1 秒；内存限制：256 MB。

现在你拥有 $s = 0.5$ 和一个实数 $0 \le a \le 1$。 你可以选择以下两种操作之一： 1. $a = as$ 2. $a = (a - 1)s + 1$

现在你需要通过最多 50 次操作，使 $a$ 等于目标数字 $b$。 若两个数 $x, y$ 满足 $|x - y| \le 10^{-4}$，则认为它们相等。 可以证明答案一定存在。

## 输入格式

第一行包含两个实数 $a, b$。

## 输出格式

输出一个由 '1' 和 '2' 组成的字符串，表示你的操作序列。

## 样例

### 样例输入 1

```text
0.5 0.25
```

### 样例输出 1

```text
1
```

### 样例输入 2

```text
1 0.75
```

### 样例输出 2

```text
12
```

### 样例输入 3

```text
1 0
```

### 样例输出 3

```text
1111111111111111111111
```
