## 题目描述

时间限制：2 秒；内存限制：1024 MB。

一觉醒来，mic 陷入了一场特殊的魔法审判。

初始时有 $n$ 个人，编号为 $1$ 至 $n$。编号 $i$ 的人有一个非负整数可疑度 $a_i$。mic 的编号为 $s$（$1 \le s \le n$）。

另外有 $m$ 条证据，第 $j$ 条证据 $(x_j, y_j, z_j)$ 表示：该证据由编号为 $x_j$ 的人掌握，如果被使用，会使编号为 $y_j$ 的人的可疑度增加 $z_j$（$z_j$ 为非负整数）。

一次审判的流程如下：

1.  <strong>选择证据</strong>：当前仍存活的所有人，各自独立地选择至多一条自己掌握的证据，也可以选择不使用任何证据。
2.  <strong>增加可疑度</strong>：对于每个被选择的证据 $j$，如果此时编号 $y_j$ 的人仍然存活，则将编号 $y_j$ 的人的可疑度增加 $z_j$；如果 $y_j$ 已经死亡（已被处刑），则该证据无效（不产生任何效果）。
3.  <strong>统计并处刑</strong>：计算此时每个人的总可疑度，即 <strong>初始可疑度 $a_i$ 加上本次审判中所有针对 $i$ 的增加量之和</strong>。将总可疑度最高的人送去`处刑`；如果有并列最高，则选择其中编号较大的人处刑。被处刑的人将不再参与后续的任何审判。

上述审判将连续进行 $n-1$ 次，每次处刑一人，直到只剩下一人。

<strong>注意：</strong>同一条证据可以在不同审判中被重复使用；每次审判的可疑度统计都是独立的：过往审判中增加的可疑度不会累积，每次审判均以初始可疑度 $a_i$ 为基础重新开始。

mic 想知道：在万千世界线中，是否存在一系列的证据使用安排（即每次审判中每个存活者可以选择任意一条自己掌握的证据或不选，不必遵循任何理性原则），使得 mic <strong>从未被处刑</strong>，并最终存活到最后？

## Input

第一行一个整数 $t$（$1 \le t \le 10^5$），表示测试数据组数。

对于每组测试数据：

第一行三个整数 $n, m, s$（$1 \le n \le 10^5$，$0 \le m \le 3\times 10^5$，$1 \le s \le n$）。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$（$0 \le a_i \le 10^9$）。

接下来 $m$ 行，每行三个整数 $x_j, y_j, z_j$（$1 \le x_j, y_j \le n$，$0 \le z_j \le 10^9$）。

保证单个测试点内所有测试数据的 $n$ 之和不超过 $10^5$，$m$ 之和不超过 $3\times 10^5$。

## Output

对于每组测试数据，输出一行：若存在满足要求的安排，输出 `YES`，否则输出 `NO`。

## Examples

### Input 1

```text
2
2 1 1
4 1
1 2 2
3 3 1
4 1 2
1 3 2
2 1 1
3 2 4
```

### Output 1

```text
NO
YES
```
