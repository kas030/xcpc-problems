## 题目描述

时间限制：1 秒；内存限制：1024 MB。

模进（也称“级进”或“模仿进行”）是音乐创作中的一种作曲技法。它的核心思想是将一个音乐动机（旋律片段）作为原型，在同一声部中以不同的音高重复出现。简单来说，就像“复制粘贴”一段旋律，但每次粘贴时，整体音高都会比上一次严格升高或降低一个固定的音程度数。

在数学上，我们可以将模进抽象为以下定义：对于长度为 $m$ 的序列 $b_1, b_2, \dots, b_m$，如果存在一个大于 $1$ 的整数 $t$ 满足 $t$ 整除 $m$，并且存在一个固定的常数 $c \in \{-1, 1\}$，使得对于所有满足 $\frac{m}{t} < i \le m$ 的正整数 $i$，都有 $b_i = b_{i - \frac{m}{t}} + c$ 成立，那么序列 $b$ 就是一个模进序列。

例如：$1, 3, 6, 5, 2, 4, 7, 6, 3, 5, 8, 7$ 是一段模进序列（取 $t=3$，此时 $\frac{m}{t}=4$，$c=1$，第 $5\sim 12$ 项分别等于第 $1\sim 8$ 项加 $1$）；$4, 3, 2, 1$ 也是一段模进序列（取 $t=4$，$c=-1$）；而 $1, 3, 4, 4$ 不满足条件，不是模进序列。

在实际的音乐创作中，常常会有装饰音穿插在主旋律中。虽然整段音乐表面上看不再是严格连续的模进序列，但如果过滤掉这些装饰音，剩下的主旋律依然会具有模进的效果。

例如序列 $1, 5, 2, 5, 3, 5, 1, 5, 2, 5, 3, 5, 4, 5, 2, 5, 3, 5, 4, 5, 5, 5, 3, 5$，如果我们提取所有奇数位置上的数，会得到 $1, 2, 3, 1, 2, 3, 4, 2, 3, 4, 5, 3$，这就构成了一段模进序列。

现在给出一段长度为 $n$ 的旋律，用数列 $a_1, a_2, \dots, a_n$ 表示。

接下来有 $q$ 组询问，每次询问给出三个正整数 $l, r, k$。这表示从原数列中提取 $k$ 个元素，使得这 $k$ 个元素在原数列中的下标构成一个等差数列 $p_1, p_2, \dots, p_k$，其中首项 $p_1 = l$，末项 $p_k = r$。换句话说，就是从原数列的第 $l$ 个元素开始，每隔固定步长提取一个元素，共提取 $k$ 次，且最后提取的是第 $r$ 个元素。这个固定的步长（即等差数列的公差）为 $d = \frac{r - l}{k - 1}$，保证为正整数。

对于每次询问，请你判断：由这些下标对应的原数列元素所组成的子序列 $a_{p_1}, a_{p_2}, \dots, a_{p_k}$ 是否为一段模进序列。

## Input

第一行一个正整数 $n$ $(1 \le n \le 10^5)$，表示旋律的长度。

第二行 $n$ 个正整数 $a_1, a_2, \dots, a_n$ $(1 \le a_i \le n)$，表示给定的旋律数列。

第三行一个正整数 $q$ $(1 \le q \le 10^5)$，表示询问的组数。

接下来 $q$ 行，每行三个正整数 $l, r, k$ $(1 \le l < r \le n;\; 2 \le k \le n;\; (k-1) \mid (r-l))$，含义如题目描述所示。

## Output

输出共 $q$ 行。对于每组询问，若子序列是模进序列，输出一行 `Yes`；否则输出一行 `No`。

## Examples

### Input 1

```text
16
1 5 3 5 2 5 1 5 2 5 4 5 3 5 2 5
3
1 15 8
3 7 3
1 16 16
```

### Output 1

```text
Yes
Yes
No
```
