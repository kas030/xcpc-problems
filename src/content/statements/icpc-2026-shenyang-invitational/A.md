## 题目描述

时间限制：4 秒；内存限制：1024 MB。

小 X 是一个焦虑的消息传递者。在接下来的 $n$ 天里，他每天都有一些消息想要发送给小 Y。

每天开始时，小 X 会产生 $a$ 条新的消息。对于第 $t$ 天产生的一条消息，它仅能在第 $t,t+1,\dots,t+b-1$ 天被发送。若截至第 $t+b-1$ 天结束时该消息仍未被发送，则从第 $t+b$ 天开始，该消息永久失效。消息失效后，小 X 不再考虑发送该消息，也不会继续因此产生焦虑值；该消息在失效前已经产生的焦虑值不会被消除。

小 X 可以在每天发送任意数量的当前仍然有效且尚未发送的消息，每条消息最多只能被发送一次。小 X 发送一条消息后，小 Y 会在当天立即收到该消息。

小 Y 的回复行为具有如下规律：

在第 $0$ 天结束时，小 Y 刚刚完成一次回复，此时不存在任何已经发送但尚未收到回复的消息。

当小 Y 完成一次回复后，如果之后再次收到一条尚未回复的消息，则以她收到该回复周期内第一条消息的当天作为新的回复周期起点。若新的回复周期从第 $t$ 天开始，则小 Y 会在第 $t+d$ 天的回复阶段，一次性回复截至该回复阶段开始时所有已经发送但尚未收到回复的消息。

在一个回复周期开始后，直到下一次回复发生前，小 Y 收到的其他消息都会加入当前回复批次，但不会改变本次回复的时间。

每天按照以下顺序发生事件：

1.  小 X 发送任意数量的消息；
2.  小 Y 进行当天的回复；
3.  结算当天产生的焦虑值。

因此，如果某天恰好是回复日，那么小 X 在当天发送的消息会被小 Y 当天收到，并参与当天的回复。

小 X 的总焦虑值由以下两部分组成：

1.  对于每条当前仍然有效但尚未发送的消息，每天产生 $c_1$ 点焦虑值；
2.  对于每条已经发送但尚未收到回复的消息，每天产生 $c_2$ 点焦虑值。

当天发送的消息从当天开始计入"已经发送但尚未收到回复"的消息。若一条消息在当天的回复阶段收到回复，则该消息当天不产生 $c_2$ 点焦虑值。消息收到回复后，不再产生任何焦虑值。

如果当前不存在已经发送但尚未收到回复的消息，则小 Y 不会主动进行回复。小 X 发送的下一条消息会在当天开始一个新的回复周期。

小 X 希望合理安排每天发送的消息数量，使得在第 $n$ 天结束时，他累计产生的总焦虑值最小。请计算这个最小值。

## Input

输入仅一行，包含六个整数 $n,a,b,c_1,c_2,d$（$1\le n\le 5000$，$1\le a,b,c_1,c_2,d\le 10^5$），分别表示消息产生的天数、每天产生的消息数量、消息的有效期、未发送消息每天产生的焦虑值、已发送但未收到回复的消息每天产生的焦虑值以及回复延迟。

## Output

输出一个整数，表示小 X 在接下来的 $n$ 天中累计产生的最小总焦虑值。

## Examples

### Input 1

```text
3 1 3 1 1 3
```

### Output 1

```text
6
```

## Note

在本样例中，$n=3$，且 $c_1 = c_2 = 1$，$d = 3$。

这意味着在第 $1, 2, 3$ 天内，任何已发送的消息都不会收到回复（因为最早的回复发生在第 $4$ 天）。

同时，由于 $c_1$ 和 $c_2$ 相等，无论消息是否发送，每天产生的焦虑值都是 $1$。

因此，我们只需计算每天累积的消息数量：

-   第 $1$ 天有 $1$ 条消息，产生焦虑 $1$；
-   第 $2$ 天有 $2$ 条消息，产生焦虑 $2$；
-   第 $3$ 天有 $3$ 条消息，产生焦虑 $3$。

综上所述，最小总焦虑值为 $1 + 2 + 3 = 6$。
