## 题目描述

时间限制：4 秒；内存限制：1024 MB。

本题为交互题。

Ivy 醒来后正在探索 Node 08 的道路网络。

Node 08 可以建模为一个有 $n$ 个顶点的**边仙人掌**，Ivy 需要找出图中的每一条边。

幸运的是，她可以向 Eye of Horus 询问若干次。每次查询中，Ivy 选择两个顶点 $x$ 和 $y$，以及一个既不包含 $x$ 也不包含 $y$ 的顶点集合 $S$。Eye of Horus 告诉她，从图中删去 $S$ 中的所有顶点以及与它们关联的边之后，$x$ 和 $y$ 是否仍然连通。然而 Eye of Horus 的计算能力有限，因此一次这样的查询代价为 $\max(|S|-1,0)$。

时间有限。Ivy 最多可以进行 $3n^2$ 次查询，且所有查询的代价之和不能超过 $n\lceil\log_2 n\rceil+2n$。你需要帮助 Ivy 设计一种策略，保证确定图中的每一条边。

回顾一下，边仙人掌是一个无向简单连通图，其中每条边至多属于一个简单环。简单图是指既没有重边也没有自环的图。

注意，交互器是**自适应**的，也就是说每个测试用例中的图并不是预先确定的。交互器始终保证至少存在一个图与之前所有回答一致，但它可能根据你的查询来选择回答。交互器只在你提交最终答案时才确定最终的图。

## 输入格式

输入包含多个测试用例。输入的第一行有一个整数 $T$（$1\le T\le 128$），表示测试用例的数量。对于每个测试用例：

第一行包含一个整数 $n$（$2\le n\le 128$），表示图中顶点的数量。

保证所有测试用例的 $n$ 之和不超过 $256$。

查询次数限制和查询代价限制对每个测试用例分别计算。

## 交互协议

要询问一次查询，输出一行。首先输出 `?` 和一个空格，然后输出三个整数 $x$、$y$ 和 $k$，接着输出 $k$ 个整数 $s_1,s_2,\dots,s_k$，所有整数之间用空格分隔。这里 $k=|S|$，$1\le x,y\le n$，$x\neq y$，$0\le k\le n-2$，且 $s_1,s_2,\dots,s_k$ 必须两两不同，并且都不等于 $x$ 和 $y$。

刷新输出后，你的程序应读取一个整数 $t$，表示该查询的答案。如果删去 $S$ 后 $x$ 和 $y$ 仍然连通，则 $t=1$；否则 $t=0$。注意，对于一个测试用例，你最多可以询问 $3n^2$ 次，且所有查询的代价之和不能超过 $n\lceil\log_2 n\rceil+2n$。

如果你想报告图中的所有边，先输出一行。首先输出 `!` 和一个空格，然后输出一个整数 $m$，表示边的数量。接着输出 $m$ 行，第 $i$ 行包含两个整数 $u_i$ 和 $v_i$，表示一条边。边可以按任意顺序列出，每条边的两个端点也可以按任意顺序列出，但同一条边不能输出超过一次。

刷新输出后，你的程序应继续处理下一个测试用例；如果没有更多测试用例，则立即退出。注意，你的最终答案不计作一次查询，也不产生查询代价。

刷新输出可以使用：

- C 和 C++ 中，如果使用 `printf`，使用 `fflush(stdout)`；如果使用 `cout`，使用 `cout.flush()`。
- Java 和 Kotlin 中，使用 `System.out.flush()`。
- Python 中，使用 `sys.stdout.flush()`。
