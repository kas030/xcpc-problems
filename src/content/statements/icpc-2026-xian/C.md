## 题目描述

时间限制：2 秒  
内存限制：1024 MB

Ris 正试图用鼠标输入一个密码。她需要输入的密码是一个长度为 $m$ 的整数序列 $b$，而她的剪贴板中包含一个长度为 $n$ 的序列 $a$。为了完成任务，Ris 可以使用以下三种操作来修改一个初始为空的工作区 $c$：

- 粘贴：花费 $x$ 的代价，将 $a$ 中的所有元素按顺序追加到 $c$ 的末尾。
- 滚动：花费 $y$ 的代价，将 $c$ 中的一个元素增加或减少 $1$。
- 删除：花费 $z$ 的代价，从 $c$ 中删除一个元素。

你需要帮助 Ris 求出所有将 $c$ 变为 $b$ 的方式中，总代价的最小值。

## 输入格式

本题包含多组测试数据。

第一行包含一个正整数 $T$（$1 ≤ T ≤ 10^4$），表示测试用例数量。

对于每组测试用例：

- 第一行包含五个整数 $n, m, x, y, z$（$1 ≤ n, m ≤ 3000$，$0 ≤ x, y, z ≤ 10^6$）。
- 第二行包含 $n$ 个整数 $a_i$（$0 ≤ a_i ≤ 10^9$）。
- 第三行包含 $m$ 个整数 $b_i$（$0 ≤ b_i ≤ 10^9$）。

保证所有测试用例的 $n·m$ 之和不超过 $9×10^6$，且所有测试用例的 $n+m$ 之和不超过 $2×10^5$。

## 输出格式

对于每组测试用例，输出一行一个整数，表示答案。

## 样例

### 样例输入

```text
4
6 7 3 2 5
1 1 4 5 1 4
1 9 1 9 8 1 0
3 2 5 6 7
11 45 14
1919 810
1 7 0 0 0
998244353
1 0 1 0 0 0 0
1 1 1000000 1000000 1000000
0
1000000000
```

### 样例输出

```text
63
15872
0
1000000001000000
```

## 说明

第一组测试数据中，一种最优操作序列如下：

- 粘贴两次。此时 $c$ 变为 [**1**, 1, 4, **5**, **1**, **4**, 1, 1, 4, **5**, **1**, **4**]。
- 删除 $5$ 个元素，保留上一行中的加粗元素。此时 $c$ 变为 $[1,5,1,4,5,1,4]$。
- 滚动 $16$ 次，将其中的第 $2,4,5,7$ 项分别调整为 $9,9,8,0$，得到 $c=[1,9,1,9,8,1,0]$。

总代价为 $2·3 + 16·2 + 5·5 = 63$。
