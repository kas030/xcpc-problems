# 难度分级说明

本站根据各奖牌组的**赛内通过率**，将题目分为铜牌、银牌、金牌和挑战四档，用于训练选题。

## 如何判定难度

金、银、铜牌组互不重叠。每组的通过率为：**该组通过题目的队伍数 ÷ 该组总队伍数**。

依次从铜牌组、银牌组、金牌组判断，取第一个达到 **50%（含）** 的档位。

| 判定条件 | 标签 |
| --- | --- |
| 铜牌组通过率 ≥ 50% | 铜牌题 |
| 铜牌组不足 50%，银牌组达到 50% | 银牌题 |
| 铜、银牌组均不足 50%，金牌组达到 50% | 金牌题 |
| 各奖牌组均未达到 50% | 挑战题 |

例如，铜、银、金牌组通过率分别为 12%、65%、92% 时，该题为**银牌题**。题目详情页可查看各组的通过队数与总队数。

判定时跳过没有队伍的奖牌组。没有可统计的通过记录时，按挑战题收录。

## 奖牌组如何划分

只统计参与对应分组评奖的正式队伍及其赛内提交，排除打星队、场外队和赛后提交。

优先按已核对或榜单配置的奖牌人数分组。缺少可用人数时，以**至少通过一道题的正式队伍数**为基数，将累计前 **10%、30%、60%** 的名次向上取整，依次划为金、银、铜三个组。分界处并列的队伍归入较高奖牌组。

统计采用当前已裁定的赛内提交，页面会注明分组依据。

榜单数据来自 [XCPCIO](https://board.xcpcio.com/)。发现统计错误，可附上题目链接和依据[在 GitHub 反馈](https://github.com/kas030/xcpc-problems/issues/new)。
