# 难度是怎样计算的？

这里的金、银、铜牌题，表示**在对应比赛中，该奖牌档的大多数队伍能够完成的题目**。标签依据真实赛内提交计算，帮助你挑选适合当前训练阶段的题目。

## 先确定队伍，再统计题目

只统计该场比赛正式参赛、参与对应分组评奖的队伍。打星队、场外参赛队和赛后提交不参与统计。女队等附加标签不影响正式队伍资格。

我们使用比赛结束、解封后的提交记录，按照该场的时间单位和罚时规则重建排名。重复提交和重判不会重复计数，编译错误不计罚时，通过后的额外提交不改变成绩。

奖牌组使用榜单中明确配置的数量，或已核对的获奖名单。只有通用奖牌比例、缺少最终榜、存在未裁定提交，或者奖牌边界出现无法确认的并列时，题目保留为“待定”。

## 50% 通过率规则

金、银、铜牌组是三个互不重叠的队伍集合。某组的通过率为：

$$
r_{g,p}=\frac{\text{奖牌组 }g\text{ 中赛内通过题目 }p\text{ 的队伍数}}{\text{奖牌组 }g\text{ 的队伍总数}}
$$

依次从铜牌组、银牌组、金牌组判断，采用第一个达到 **50%（含）** 的档位。

| 条件，按顺序判断 | 标签 |
| --- | --- |
| 铜牌组通过率 ≥ 50% | 铜牌题 |
| 铜牌组不足 50%，银牌组达到 50% | 银牌题 |
| 铜、银牌组均不足 50%，金牌组达到 50% | 金牌题 |
| 金牌组也不足 50% | 挑战题 |
| 数据或奖牌边界未确认，或任一组不足 5 队 | 待定 |

例如，一道题的铜、银、金牌组通过率分别为 12%、65%、92%，它会被标为银牌题。详情页展示每组的通过队数与总队数，你可以自行判断。

50% 是本站统一采用的训练分类阈值，并非主办方给题目指定的官方难度。规则版本为 `medal-cohort-v1`。

## 怎样使用这些标签

- **跨比赛比较时结合赛事级别。** 区域赛的银牌题和总决赛的银牌题并不具有相同的绝对难度。
- **通过率体现赛场表现。** 选题策略、比赛时间、题目长度和队伍擅长的方向都会影响结果。
- **待定不代表更难。** 它表示目前还不能可靠分类。
- **完成状态由你手动标记。** 数据保存在当前浏览器，本站不会读取你的 QOJ 账号或提交记录。

## 比赛标签与来源

比赛标签采用“年份后两位-赛事体系-站点”的形式，例如 `24-ICPC-南京`。年份使用赛事的标称年份；邀请赛、网络赛和总决赛可增加“邀”“网1”“ECF”等标识。

榜单与提交记录来自 [XCPCIO](https://board.xcpcio.com/) 及其 [公开数据仓库](https://github.com/xcpcio/board-data)，题目提交入口指向 [QOJ](https://qoj.ac/)。每场比赛都保留数据版本和原始榜单链接。

首批题目使用已公开的官方中文 PDF。已有 Markdown 整理版时优先展示正文，并保留原始题面。翻译稿会明确标记为“待校对”或“已校对”。

发现题目映射、统计或题面错误，可以[在 GitHub 提交问题](https://github.com/kas030/xcpc-problems/issues/new)。请附上题目链接和对应来源，方便核对。
