D.Minimum Suffix

22-ICPC-EC-Final挑战题QOJ #6301

题面语言
完整题册

题目描述

时间限制：3 秒；内存限制：1024 MB。

对于一个长度为 nnn 的字符串 sss，我们定义 pj=xp_j = xpj​=x，其中 s[x…j]s[x \dots j]s[x…j] 是 s[1…j]s[1 \dots j]s[1…j] 的最小后缀，对于所有 j=1,…,nj = 1, \dots, nj=1,…,n 均成立。（如果一个后缀在字典序上小于该字符串的所有其他后缀，则称其为该字符串的最小后缀。）

你需要根据 p1,…,pnp_1, \dots, p_np1​,…,pn​ 还原字符串 sss。如果存在多个答案，请找出字典序最小的一个。

输入格式

第一行包含一个整数 TTT (1≤T≤1051 \le T \le 10^51≤T≤105)，表示测试用例的数量。

对于每个测试用例，第一行包含一个整数 nnn (1≤n≤3×1061 \le n \le 3 \times 10^61≤n≤3×106)，表示 sss 的长度。下一行包含 nnn 个整数 p1,…,pnp_1, \dots, p_np1​,…,pn​ (1≤pi≤i1 \le p_i \le i1≤pi​≤i，对于所有 1≤i≤n1 \le i \le n1≤i≤n)。

保证所有测试用例的 nnn 之和不超过 3×1063 \times 10^63×106。

输出格式

对于每个测试用例，输出一行。如果没有解，输出 −1-1−1。否则，输出字典序最小的 sss。字符串 sss 中的字符由正整数表示。较小的整数在字典序中代表较小的字符。

3

输出格式 1

1 2 2
-1
1 2 1
1 1 2
2 1 2
1 1 1
