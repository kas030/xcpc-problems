L.Palm Island

23-CCPC-哈尔滨签到题QOJ #7757

题面语言
完整题册

题目描述

时间限制：1.0 秒；内存限制：256 MB。

Toph 正在玩一个纸牌游戏。她有 nnn 张牌，每张牌上都有一个唯一的数字 1,2,…,n1, 2, \dots, n1,2,…,n。在这个游戏中，Toph 可以对牌堆进行操作。假设从牌堆顶到牌堆底的牌依次为 p1,p2,…,pnp_1, p_2, \dots, p_np1​,p2​,…,pn​（一个排列），那么每次操作必须是以下两种情况之一：

  1. 将最顶部的牌放到牌堆底，即将牌堆顺序变为 p2,p3,…,pn,p1p_2, p_3, \dots, p_n, p_1p2​,p3​,…,pn​,p1​。
  2. 将从顶部数第二张牌放到牌堆底，即将牌堆顺序变为 p1,p3,…,pn,p2p_1, p_3, \dots, p_n, p_2p1​,p3​,…,pn​,p2​。

现在，已知 Toph 牌堆的初始顺序（从顶到底）为 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​，Toph 希望经过若干次操作后，将牌堆顺序变为 b1,b2,…,bnb_1, b_2, \dots, b_nb1​,b2​,…,bn​。请构造一个操作序列来帮助 Toph 实现这一变化。

Toph 没有耐心，因此操作次数不应超过 n2n^2n2。

输入格式

第一行包含一个整数 TTT，表示测试用例的数量。 对于每个测试用例： 第一行包含一个整数 nnn (3≤n≤10003 \le n \le 10003≤n≤1000)，表示 Toph 的牌数。 第二行包含 nnn 个整数 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​，表示初始时牌堆的排列顺序。 * 第三行包含 nnn 个整数 b1,b2,…,bnb_1, b_2, \dots, b_nb1​,b2​,…,bn​，表示目标牌堆的排列顺序。

保证所有测试用例中 nnn 的总和不超过 100010001000。

输出格式

对于每个测试用例： 输出一行，包含一个字符串 s1s2…sks_1s_2 \dots s_ks1​s2​…sk​ (si∈{1,2},1≤i≤ks_i \in \{1, 2\}, 1 \le i \le ksi​∈{1,2},1≤i≤k) 作为你的操作序列。 操作序列的长度不能超过 n2n^2n2，否则将得到“Wrong Answer”。 * 如果存在多种解，输出其中任意一个即可。

样例

输入 1

2
3
1 2 3
2 3 1
4
1 2 3 4
2 1 3 4

输出 1

1
112212

说明

如果在一个测试用例中 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​ 与 b1,b2,…,bnb_1, b_2, \dots, b_nb1​,b2​,…,bn​ 相同，输出空字符串是可以的。但在这种情况下，你仍然需要输出一个空行。

不要在行末添加多余的空格，否则将得到“Wrong Answer”判决。
