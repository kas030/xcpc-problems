G.The Only Way to the Destination

23-CCPC-哈尔滨银牌题QOJ #7752

题面语言
完整题册

题目描述

时间限制：1.0 秒；内存限制：512 MB。

有一个 n×mn \times mn×m 的网格迷宫。为方便起见，我们定义 (x,y)(x, y)(x,y) 为第 xxx 行第 yyy 列的网格。

最初，所有网格都是空的。Alice 想要设计这个迷宫，她将在网格中放置 kkk 个墙壁。每个墙壁表示为 x1,x2,yx_1, x_2, yx1​,x2​,y，这意味着对于所有的 x1≤i≤x2x_1 \le i \le x_2x1​≤i≤x2​，(i,y)(i, y)(i,y) 将成为该墙壁的一部分，且不能通过。除了墙壁所在的网格，其他所有网格都是空的。Alice 确保在放置 kkk 个墙壁后，所有空网格保持连通，且迷宫中至少有一个空网格。此外，保证不同的墙壁之间没有公共网格。

现在，Alice 想知道，是否任意一对空网格之间都只有一条简单路径相连？

如果你不熟悉“简单路径”的定义，这里是它的定义： 连接空网格 (xs,ys)(x_s, y_s)(xs​,ys​) 和 (xd,yd)(x_d, y_d)(xd​,yd​) 的简单路径定义为一个网格位置序列 S={(x1,y1),(x2,y2),…,(xlen,ylen)},(len≥2)S = \{(x_1, y_1), (x_2, y_2), \dots, (x_{len}, y_{len})\}, (len \ge 2)S={(x1​,y1​),(x2​,y2​),…,(xlen​,ylen​)},(len≥2)，满足以下条件：

  • (x1,y1)=(xs,ys),(xlen,ylen)=(xd,yd)(x_1, y_1) = (x_s, y_s), (x_{len}, y_{len}) = (x_d, y_d)(x1​,y1​)=(xs​,ys​),(xlen​,ylen​)=(xd​,yd​)
  • ∀1≤i≤len,1≤xi≤n,1≤yi≤m\forall 1 \le i \le len, 1 \le x_i \le n, 1 \le y_i \le m∀1≤i≤len,1≤xi​≤n,1≤yi​≤m
  • ∀1≤i≤len,(xi,yi)\forall 1 \le i \le len, (x_i, y_i)∀1≤i≤len,(xi​,yi​) 是一个空网格
  • ∀1≤i≤len−1,∣xi−xi+1∣+∣yi−yi+1∣=1\forall 1 \le i \le len - 1, |x_i - x_{i+1}| + |y_i - y_{i+1}| = 1∀1≤i≤len−1,∣xi​−xi+1​∣+∣yi​−yi+1​∣=1
  • ∀1≤i<j≤len,(xi,yi)≠(xj,yj)\forall 1 \le i < j \le len, (x_i, y_i) \neq (x_j, y_j)∀1≤i<j≤len,(xi​,yi​)=(xj​,yj​)

如果任意两个不同的空网格 (xs,ys),(xd,yd)(x_s, y_s), (x_d, y_d)(xs​,ys​),(xd​,yd​) 之间都有且仅有一条简单路径相连，输出 “YES”。否则，输出 “NO”。

输入格式

第一行包含三个整数 n,m,k(1≤n,m≤109,1≤k≤105)n, m, k (1 \le n, m \le 10^9, 1 \le k \le 10^5)n,m,k(1≤n,m≤109,1≤k≤105)，分别表示行数、列数和墙壁的数量。

接下来的 kkk 行，每行包含三个整数 x1,x2,y(1≤x1≤x2≤n,1≤y≤m)x_1, x_2, y (1 \le x_1 \le x_2 \le n, 1 \le y \le m)x1​,x2​,y(1≤x1​≤x2​≤n,1≤y≤m)，表示迷宫中放置的一堵墙。

保证每对空网格之间至少有一条简单路径相连。

输出格式

输出一个字符串表示答案，即 “YES” 或 “NO”。

说明

样例解释展示了 Alice 的迷宫，其中黄色方块代表墙壁，白色方块代表空网格。

  1. 在第一个样例中，我们可以观察到无论选择哪个起点和终点，都只有一条简单路径。

  2. 在第二个样例中，选择 (1,1)(1, 1)(1,1) 作为起点，(5,1)(5, 1)(5,1) 作为终点。S1={(1,1),(2,1),(3,1),(4,1),(5,1)}S_1 = \{(1, 1), (2, 1), (3, 1), (4, 1), (5, 1)\}S1​={(1,1),(2,1),(3,1),(4,1),(5,1)} 和 S2={(1,1),(1,2),(1,3),(2,3),(3,3),(4,3),(5,3),(5,2),(5,1)}S_2 = \{(1, 1), (1, 2), (1, 3), (2, 3), (3, 3), (4, 3), (5, 3), (5, 2), (5, 1)\}S2​={(1,1),(1,2),(1,3),(2,3),(3,3),(4,3),(5,3),(5,2),(5,1)} 是两条不同的简单路径。

  3. 在第三个样例中，选择 (1,2)(1, 2)(1,2) 作为起点，(2,3)(2, 3)(2,3) 作为终点。S1={(1,2),(1,3),(2,3)}S_1 = \{(1, 2), (1, 3), (2, 3)\}S1​={(1,2),(1,3),(2,3)} 和 S2={(1,2),(2,2),(2,3)}S_2 = \{(1, 2), (2, 2), (2, 3)\}S2​={(1,2),(2,2),(2,3)} 是两条不同的简单路径。
