C.Karshilov's Matching Problem II

题目描述

时间限制：2.0 秒；内存限制：256 MB。

Karshilov 一如既往地喜欢字符串匹配问题。这一次，他给出了一个长度为 nnn 的字符串 SSS，并为 SSS 的每个前缀分配了一个权值。具体来说，SSS 长度为 iii (1≤i≤n1 \le i \le n1≤i≤n) 的前缀记为 preipre_iprei​，其权值为 wiw_iwi​。

对于任意字符串 ttt，他定义了一个价值函数 f(t)=∑i=1nwi⋅occur(t,prei)f(t) = \sum_{i=1}^n w_i \cdot \text{occur}(t, pre_i)f(t)=∑i=1n​wi​⋅occur(t,prei​)，其中 occur(t,prei)\text{occur}(t, pre_i)occur(t,prei​) 表示 preipre_iprei​ 在字符串 ttt 中出现的次数。例如：occur(heheh,heh)=2\text{occur}(\text{heheh}, \text{heh}) = 2occur(heheh,heh)=2 且 occur(hhh,h)=3\text{occur}(\text{hhh}, \text{h}) = 3occur(hhh,h)=3。

现在，Karshilov 还有另一个长度为 nnn 的字符串 TTT。他将向你提出 mmm 个询问。每个询问包含两个整数 l,rl, rl,r，要求查询 f(T[l,r])f(T[l, r])f(T[l,r]) 的值，其中 T[l,r]T[l, r]T[l,r] 表示字符串 TTT 从第 lll 个字符到第 rrr 个字符的子串（即 TlTl+1…TrT_l T_{l+1} \dots T_rTl​Tl+1​…Tr​）。

你能像两年前那样解决 Karshilov 的询问吗？

输入格式

第一行包含两个整数 n,mn, mn,m (1≤n,m≤150,0001 \le n, m \le 150, 0001≤n,m≤150,000)，分别表示字符串 SSS（及字符串 TTT）的长度和询问次数。

第二行包含一个长度为 nnn 的字符串 SSS。

第三行包含一个长度为 nnn 的字符串 TTT。

第四行包含 nnn 个整数 w1,w2,…,wnw_1, w_2, \dots, w_nw1​,w2​,…,wn​，其中 wiw_iwi​ (0≤wi≤1080 \le w_i \le 10^80≤wi​≤108) 是 preipre_iprei​ 的权值。

接下来的 mmm 行，每行包含两个整数 l,rl, rl,r (1≤l≤r≤n1 \le l \le r \le n1≤l≤r≤n)，表示询问 f(T[l,r])f(T[l, r])f(T[l,r]) 的值。

字符串 SSS 和 TTT 均由小写字母组成。

输出格式

输出包含 mmm 行。第 iii 行包含一个整数，表示第 iii 个询问的答案。
