VegiCat 刚刚学习了线段树，想要练习使用它们。

对于正整数 nnn，他考虑序列 ai=ia_i = iai​=i（1≤i≤n1 \le i \le n1≤i≤n）。他决定建立一棵线段树来回答该序列上的区间平均值查询。

尽管 VegiCat 的算法在一般情况下是不正确的，但它对某些区间会返回正确的平均值。请统计这类区间的数量。

对于一个区间 [L,R][L, R][L,R]，其真实平均值为

∑i=LRaiR−L+1.\frac{\sum_{i=L}^{R} a_i}{R - L + 1}.R−L+1∑i=LR​ai​​.

更确切地说，请统计满足 1≤L≤R≤n1 \le L \le R \le n1≤L≤R≤n 且使得下式成立的数对 (L,R)(L, R)(L,R) 的数量：

Query(1,n,L,R)=∑i=LRaiR−L+1.\text{Query}(1, n, L, R) = \frac{\sum_{i=L}^{R} a_i}{R - L + 1}.Query(1,n,L,R)=R−L+1∑i=LR​ai​​.

所有平均值均作为精确的有理数进行计算，不进行四舍五入或截断。
