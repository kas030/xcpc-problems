题目描述

时间限制：1 秒；内存限制：1024 MB。

VegiCat 正在执行一项扫雷任务。数轴上有 nnn 颗地雷。地雷 iii 位于整数坐标 aia_iai​ 处。地雷按坐标从小到大的顺序编号，因此 a1≤a2≤⋯≤ana_1 \le a_2 \le \cdots \le a_na1​≤a2​≤⋯≤an​。地雷的坐标可能重复。

VegiCat 按照 1,2,…,n1, 2, \ldots, n1,2,…,n 的顺序对每颗地雷各进行一次探测。对于地雷 iii，他选择一个整数坐标 bib_ibi​ 作为探测位置，该坐标可以为负数或零。这次探测的误差为 ∣ai−bi∣|a_i - b_i|∣ai​−bi​∣。

对于每个 2≤i≤n2 \le i \le n2≤i≤n，给定一个整数 lil_ili​，表示地雷 i−1i - 1i−1 和地雷 iii 的探测位置之间所需的最小距离。这些位置必须满足

∣bi−bi−1∣≥li.|b_i - b_{i-1}| \ge l_i.∣bi​−bi−1​∣≥li​.

请帮助 VegiCat 最小化最大的探测误差；也就是说，求

min⁡b1,…,bn∈Z∣bi−bi−1∣≥li (2≤i≤n)(max⁡1≤i≤n∣ai−bi∣).\min_{\substack{b_1, \ldots, b_n \in \mathbb{Z} \\ |b_i - b_{i-1}| \ge l_i \ (2 \le i \le n)}} \left(\max_{1 \le i \le n} |a_i - b_i|\right).b1​,…,bn​∈Z∣bi​−bi−1​∣≥li​ (2≤i≤n)​min​(1≤i≤nmax​∣ai​−bi​∣).

输入格式

第一行包含一个整数 TTT（1≤T≤1041 \le T \le 10^41≤T≤104），表示测试数据的组数。接下来是各组测试数据的描述。

每组测试数据的第一行包含一个整数 nnn（2≤n≤1052 \le n \le 10^52≤n≤105），表示地雷的数量。

第二行包含 nnn 个整数 a1,a2,…,ana_1, a_2, \ldots, a_na1​,a2​,…,an​（1≤ai≤1091 \le a_i \le 10^91≤ai​≤109），其中 aia_iai​ 是地雷 iii 的坐标。保证 a1≤a2≤⋯≤ana_1 \le a_2 \le \cdots \le a_na1​≤a2​≤⋯≤an​。

第三行包含 n−1n - 1n−1 个整数 l2,l3,…,lnl_2, l_3, \ldots, l_nl2​,l3​,…,ln​（1≤li≤1091 \le l_i \le 10^91≤li​≤109），其中 lil_ili​ 是地雷 i−1i - 1i−1 和地雷 iii 的探测位置之间的最小距离。

保证所有测试数据中 nnn 的总和不超过 10510^5105。

对于每组测试数据，输出一个整数——最大探测误差的最小可能值。
