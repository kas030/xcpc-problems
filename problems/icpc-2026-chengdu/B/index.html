B.Bouncing Particles

26-ICPC-成都挑战题QOJ #23593

题面语言
完整题册

题目描述

时间限制：2 秒；内存限制：1024 MB。

本题包含附件。你可以使用它来模拟并可视化粒子的运动。

VegiCat 正在观察一个有 nnn 行 nnn 列的网格上的粒子。左下角格子的坐标为 (1,1)(1, 1)(1,1)。水平坐标从左到右递增，垂直坐标从下到上递增。每个粒子都有一个水平方向（左或右）和一个垂直方向（上或下）。在每一步开始时，每个粒子按如下方式调整其方向：

  • 如果其水平方向上的下一个格子在网格外部，则其水平方向反转。
  • 如果其垂直方向上的下一个格子在网格外部，则其垂直方向反转。

完成这些调整后，位于 (x,y)(x, y)(x,y) 的一个粒子会产生两个子粒子：

  • 若其水平方向为左，则在 (x−1,y)(x - 1, y)(x−1,y) 处产生一个；若为右，则在 (x+1,y)(x + 1, y)(x+1,y) 处产生一个；
  • 若其垂直方向为下，则在 (x,y−1)(x, y - 1)(x,y−1) 处产生一个；若为上，则在 (x,y+1)(x, y + 1)(x,y+1) 处产生一个。

两个子粒子都继承父粒子的水平方向和垂直方向。随后父粒子消失。

多个粒子可以同时占据同一个格子，无论它们的方向如何。它们之间不会相互作用，也不会改变彼此的方向。

在时刻 000，在 (x0,y0)(x_0, y_0)(x0​,y0​) 处有四个粒子，具有以下方向组合：

  • 右和上；
  • 左和上；
  • 右和下；
  • 左和下。

在每一步中，所有粒子同时调整各自的方向，然后按上述方式分裂。

给定 qqq 次查询。每次查询给出整数 A,B,CA, B, CA,B,C 和一个时刻 ttt。对于每次查询，求出在时刻 ttt 满足 Ax+By+C=0Ax + By + C = 0Ax+By+C=0 且至少包含一个粒子的网格格子 (x,y)(x, y)(x,y) 的数量。

输入格式

第一行包含一个整数 TTT（1≤T≤1051 \le T \le 10^51≤T≤105），表示测试数据的组数。接下来是各组测试数据的描述。

每组测试数据的第一行包含四个整数 n,x0,y0,qn, x_0, y_0, qn,x0​,y0​,q（2≤n≤1092 \le n \le 10^92≤n≤109，1≤x0,y0≤n1 \le x_0, y_0 \le n1≤x0​,y0​≤n，1≤q≤1051 \le q \le 10^51≤q≤105）。网格有 nnn 行 nnn 列，初始格子为 (x0,y0)(x_0, y_0)(x0​,y0​)，共有 qqq 次查询。

接下来的 qqq 行中，每行包含四个整数 A,B,CA, B, CA,B,C 和 ttt（∣A∣,∣B∣,∣C∣≤109|A|, |B|, |C| \le 10^9∣A∣,∣B∣,∣C∣≤109，0≤t≤1090 \le t \le 10^90≤t≤109）。这描述了在时刻 ttt 对直线 Ax+By+C=0Ax + By + C = 0Ax+By+C=0 的一次查询。保证 AAA 和 BBB 不会同时为 000。

保证所有测试数据中 qqq 的总和不超过 10510^5105。

输出格式

对于每次查询，在一行中输出一个整数：在时刻 ttt 满足 Ax+By+C=0Ax + By + C = 0Ax+By+C=0 且至少包含一个粒子的网格格子 (x,y)(x, y)(x,y) 的数量。
