题目描述

时间限制：1 秒；内存限制：1024 MB。

这是一道通信（二次运行）题。

VegiCat 和 VegiDog 在一个有 nnn 个顶点（编号从 111 到 nnn）和 mmm 条边的森林上玩游戏。森林是一个没有环的无向图。它不一定连通。

在第一阶段，VegiCat 为每个顶点 uuu 分配一个整数 aua_uau​（1≤au≤2n1 \le a_u \le 2n1≤au​≤2n）。这些数值可以重复。

在 VegiCat 完成赋值后，顶点会被重新编号。设 p1,p2,…,pnp_1, p_2, \ldots, p_np1​,p2​,…,pn​ 是 1,2,…,n1, 2, \ldots, n1,2,…,n 的一个排列，其中从 111 到 nnn 的每个整数恰好出现一次。对于每个 uuu，原本编号为 uuu 的顶点现在编号为 pup_upu​。

每条边 (u,v)(u, v)(u,v) 变为 (pu,pv)(p_u, p_v)(pu​,pv​)。每个顶点保留其被分配的数值。设重新编号后顶点 iii 处的数值为 bib_ibi​，则 bpu=aub_{p_u} = a_ubpu​​=au​。

在第二阶段，VegiDog 只会收到 nnn 和 b1,b2,…,bnb_1, b_2, \ldots, b_nb1​,b2​,…,bn​，而不知道原始森林或排列 ppp。他必须使用新的顶点编号恢复出所有的边。

请为两位玩家设计策略，使其对每一个合法的森林和每一个排列 ppp 都有效。

输入格式

你的程序将运行两次：第一次扮演 VegiCat，第二次扮演 VegiDog。在两次运行中，各组测试数据以相同的顺序出现。

第一次运行。 第一行包含字符串 cat，表示你扮演 VegiCat。

第二行包含一个整数 TTT（1≤T≤1041 \le T \le 10^41≤T≤104），表示测试数据的组数。接下来是各组测试数据的描述。

每组测试数据的第一行包含两个整数 nnn 和 mmm（1≤n≤2⋅1051 \le n \le 2 \cdot 10^51≤n≤2⋅105，0≤m<n0 \le m < n0≤m<n），分别表示顶点数和边数。

接下来的 mmm 行，每行包含两个整数 uuu 和 vvv（1≤u,v≤n1 \le u, v \le n1≤u,v≤n，u≠vu \ne vu=v），描述顶点 uuu 和 vvv 之间的一条无向边。

保证图中没有环或重边。

保证所有测试数据中 nnn 的总和不超过 2⋅1052 \cdot 10^52⋅105。

第二次运行。 第一行包含字符串 dog，表示你扮演 VegiDog。

第二行包含一个整数 TTT（1≤T≤1041 \le T \le 10^41≤T≤104），表示测试数据的组数。接下来是各组测试数据的描述。

每组测试数据的第一行包含一个整数 nnn（1≤n≤2⋅1051 \le n \le 2 \cdot 10^51≤n≤2⋅105），表示顶点数。

第二行包含 nnn 个整数 b1,b2,…,bnb_1, b_2, \ldots, b_nb1​,b2​,…,bn​（1≤bi≤2n1 \le b_i \le 2n1≤bi​≤2n），表示按新顶点顺序排列的赋值。

保证所有测试数据中 nnn 的总和不超过 2⋅1052 \cdot 10^52⋅105。

输出格式

第一次运行。 对于每组测试数据，在一行中输出 nnn 个整数 a1,a2,…,ana_1, a_2, \ldots, a_na1​,a2​,…,an​（1≤ai≤2n1 \le a_i \le 2n1≤ai​≤2n）。整数 aia_iai​ 是分配给顶点 iii 的数值。

第二次运行。 对于每组测试数据，第一行输出一个整数 mmm，表示边数。接下来的 mmm 行，每行必须包含两个整数 uuu 和 vvv（1≤u,v≤n1 \le u, v \le n1≤u,v≤n，u≠vu \ne vu=v），使用新的顶点编号描述一条边。

每条边输出一次，顺序任意。两个端点谁先输出均可。如果 m=0m = 0m=0，则只输出 000。

说明

在第一组测试数据中，森林只有一个顶点且没有边。VegiCat 给该顶点赋值为 111，VegiDog 输出 000。

在最后一组测试数据中，排列为 p=[5,3,6,4,2,9,1,8,7,10]p = [5, 3, 6, 4, 2, 9, 1, 8, 7, 10]p=[5,3,6,4,2,9,1,8,7,10]。

VegiCat 赋值 a7=16a_7 = 16a7​=16。由于 p7=1p_7 = 1p7​=1，VegiDog 收到 b1=16b_1 = 16b1​=16。

原始边 (3,7)(3, 7)(3,7) 变为 (p3,p7)=(6,1)(p_3, p_7) = (6, 1)(p3​,p7​)=(6,1)。

原始边 (4,10)(4, 10)(4,10) 变为 (p4,p10)=(4,10)(p_4, p_{10}) = (4, 10)(p4​,p10​)=(4,10)。样例将该边输出为 (10,4)(10, 4)(10,4)，表示同一条无向边。

样例展示了输入和输出格式。其输出对于所展示的图和排列是正确的。但是，样例中的赋值并不保证属于对每个合法森林和每个排列都有效的策略。
