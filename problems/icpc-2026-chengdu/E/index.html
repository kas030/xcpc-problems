E.Enclose the Point

26-ICPC-成都金牌题QOJ #23596

题面语言
完整题册

题目描述

时间限制：1 秒；内存限制：1024 MB。

平面上有 nnn 个点 P1,P2,…,PnP_1, P_2, \ldots, P_nP1​,P2​,…,Pn​。VegiCat 有 qqq 次询问。每次询问给出一个点 PPP。

对于每次询问，请使用给定的若干个点作为顶点，构造一个简单多边形。该多边形必须将点 PPP 严格包含在内部，并且具有最少的顶点数。如果不存在这样的多边形，请输出 −1-1−1。

简单多边形是由至少三个不同顶点构成的闭合折线。相邻的边仅在它们的公共端点处相交，不相邻的边不相交。

简单多边形与非简单多边形的示例

输入格式

第一行包含一个整数 TTT（1≤T≤2⋅1041 \le T \le 2 \cdot 10^41≤T≤2⋅104），表示测试用例的数量。接下来是各测试用例的描述。

每个测试用例的第一行包含两个正整数 nnn 和 qqq（3≤n≤1053 \le n \le 10^53≤n≤105，1≤q≤1051 \le q \le 10^51≤q≤105），分别表示给定点的数量和询问的数量。

接下来 nnn 行中的第 iii 行包含两个整数 xix_ixi​ 和 yiy_iyi​（−109≤xi,yi≤109-10^9 \le x_i, y_i \le 10^9−109≤xi​,yi​≤109），表示点 PiP_iPi​ 的坐标。保证这 nnn 个点两两不同。

接下来 qqq 行，每行包含两个整数 xxx 和 yyy（−109≤x,y≤109-10^9 \le x, y \le 10^9−109≤x,y≤109），表示所询问点的坐标。

保证所有测试用例中 nnn 的总和不超过 10510^5105。

保证所有测试用例中 qqq 的总和不超过 10510^5105。

输出格式

对于每次询问，如果不存在满足要求的多边形，则在一行中输出一个整数 −1-1−1。

否则，输出一个顶点数最少的多边形。第一行输出一个整数 mmm，表示顶点数。

第二行按顺序输出 mmm 个整数 a1,a2,…,ama_1, a_2, \ldots, a_ma1​,a2​,…,am​（1≤ai≤n1 \le a_i \le n1≤ai​≤n），表示各顶点的编号。该多边形为 Pa1Pa2…PamP_{a_1} P_{a_2} \ldots P_{a_m}Pa1​​Pa2​​…Pam​​。顶点可以按顺时针或逆时针顺序输出。

顶点编号必须两两不同，且输出的多边形必须是简单多边形并将所询问的点严格包含在内部。如果存在多组解，输出任意一组即可。

说明

在第一个测试用例中，三角形 P4P1P2P_4 P_1 P_2P4​P1​P2​ 将所询问的点 P=(0,0)P = (0, 0)P=(0,0) 严格包含在内部。由于多边形至少有三个顶点，因此该三角形具有最少的顶点数。

在第二个测试用例中，唯一可能的多边形是三角形 P1P2P3P_1 P_2 P_3P1​P2​P3​。所询问的点 P=(0,0)P = (0, 0)P=(0,0) 位于边 P2P3P_2 P_3P2​P3​ 上，因此答案为 −1-1−1。
