题目描述

时间限制：4 秒；内存限制：1024 MB。

VegiCat 拥有一家公司，共有 nnn 名员工，分为 kkk 个非空团队。员工们住在一条笔直的道路旁，该道路可以用数轴表示。VegiCat 想要为他们安排两个集合点。

VegiCat 将这些团队划分为两个集合 AAA 和 BBB，每个团队恰好属于其中一个集合。他为每个集合在任意实数坐标处选择一个集合点。同一个团队的所有员工必须前往同一个集合点。 集合 AAA 中的每个团队前往 AAA 的集合点，集合 BBB 中的每个团队前往 BBB 的集合点。任一集合都可以为空。

令 SAS_ASA​ 表示属于 AAA 中团队的所有员工的住址位置列表，并类似地为 BBB 定义 SBS_BSB​。即使住址位置重复，每名员工也会被分别计入。

对于住址位置列表 S=(x1,x2,…,xm)S = (x_1, x_2, \ldots, x_m)S=(x1​,x2​,…,xm​)，这些员工前往同一个集合点的最小总移动距离为

M(S)=min⁡p∈R∑j=1m∣xj−p∣.M(S) = \min_{p \in \mathbb{R}} \sum_{j=1}^{m} |x_j - p|.M(S)=p∈Rmin​j=1∑m​∣xj​−p∣.

当 SSS 为空时，定义 M(S)=0M(S) = 0M(S)=0。请帮助 VegiCat 在将团队划分为两个集合的所有方式中，最小化 M(SA)+M(SB)M(S_A) + M(S_B)M(SA​)+M(SB​)。

输入格式

第一行包含一个整数 TTT（1≤T≤3⋅1051 \le T \le 3 \cdot 10^51≤T≤3⋅105），表示测试数据的组数。接下来是各组测试数据的描述。

每组测试数据的第一行包含两个整数 nnn 和 kkk（1≤k≤n≤3⋅1051 \le k \le n \le 3 \cdot 10^51≤k≤n≤3⋅105），分别表示员工人数和团队数量。

接下来的 kkk 行，每行描述一个团队。第 iii 行包含一个整数 mim_imi​（1≤mi≤n1 \le m_i \le n1≤mi​≤n），表示团队 iii 中的员工人数，随后是 mim_imi​ 个整数 xi,1,…,xi,mix_{i,1}, \ldots, x_{i,m_i}xi,1​,…,xi,mi​​（1≤xi,j≤1071 \le x_{i,j} \le 10^71≤xi,j​≤107），表示他们的住址位置。每组测试数据中所有 mim_imi​ 之和为 nnn。

住址位置可能重复，且可以按任意顺序给出。

保证所有测试数据中 nnn 的总和不超过 3⋅1053 \cdot 10^53⋅105。

输出格式

对于每组测试数据，输出一个整数——最小可能的总移动距离。

说明

在第一组测试数据中，VegiCat 让团队 111 前往位置 111 处的集合点，让团队 222 前往位置 888 处的集合点。每个团队中的员工总移动距离均为 222，因此答案为 444。

在第二组测试数据中，VegiCat 选择位置 333 和 999 作为集合点。他让团队 111 和 222 前往第一个集合点，让团队 333 前往第二个集合点。团队 111、222 和 333 中的员工总移动距离分别为 121212、111 和 222，因此答案为 151515。
