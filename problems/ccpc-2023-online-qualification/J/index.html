J.Find the Gap

题目描述

时间限制：1.0 秒；内存限制：512 MB。

给定三维空间中的 nnn 个点。请找到两个平行平面，使得这 nnn 个点全部位于这两个平行平面之间（包含边界），并使这两个平面之间的距离最小。

输入格式

第一行包含一个整数 nnn (1≤n≤501 \le n \le 501≤n≤50)，表示点的数量。 接下来的 nnn 行，每行包含三个整数 xi,yix_i, y_ixi​,yi​ 和 ziz_izi​ (1≤xi,yi,zi≤10 0001 \le x_i, y_i, z_i \le 10\,0001≤xi​,yi​,zi​≤10000)，描述一个点 (xi,yi,zi)(x_i, y_i, z_i)(xi​,yi​,zi​)。保证所有 nnn 个点互不相同。

输出格式

输出一行，包含一个实数，表示最小的间距。要求绝对误差或相对误差不超过 10−910^{-9}10−9。 具体来说，假设你的答案为 aaa，标准答案为 bbb，当且仅当 ∣a−b∣max⁡{1,∣b∣}≤10−9\frac{|a-b|}{\max\{1, |b|\}} \le 10^{-9}max{1,∣b∣}∣a−b∣​≤10−9 时，你的答案被视为正确。
