题目描述

时间限制：3.0 秒；内存限制：512 MB。

长度为 nnn 的字符串 A=a1a2…anA = a_1a_2 \dots a_nA=a1​a2​…an​ 是 nnn 个字符 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​ 的拼接，其长度记为 ∣A∣|A|∣A∣。类似地，两个字符串 A=a1a2…anA = a_1a_2 \dots a_nA=a1​a2​…an​ 和 B=b1b2…bmB = b_1b_2 \dots b_mB=b1​b2​…bm​ 的拼接为 a1a2…anb1b2…bma_1a_2 \dots a_nb_1b_2 \dots b_ma1​a2​…an​b1​b2​…bm​，记作 A+BA + BA+B。

两个长度均为 nnn 的字符串 A=a1a2…anA = a_1a_2 \dots a_nA=a1​a2​…an​ 和 B=b1b2…bnB = b_1b_2 \dots b_nB=b1​b2​…bn​ 之间的编辑距离定义为满足 ai≠bia_i \neq b_iai​=bi​ 的下标 iii 的个数。

我们将由字符串 BBB 的前 kkk 个字符组成的字符串（k≤∣B∣k \le |B|k≤∣B∣）称为 BBB 的第 kkk 个前缀。若字符串 PPP 满足 ∣P∣≤∣Q∣|P| \le |Q|∣P∣≤∣Q∣，且 PPP 与 QQQ 的第 ∣P∣|P|∣P∣ 个前缀之间的编辑距离不超过 111，则称 PPP 为 QQQ 的一个“准前缀”（almost prefix）。

给定两个由小写英文字母组成的字符串 SSS 和 TTT，你需要找出将 SSS 分割成若干部分的所有方案，使得每一部分都是 TTT 的一个非空准前缀，并计算所有方案中部分数量的平方和，结果对 998244353998244353998244353 取模。更正式地，设 S=P1+P2+⋯+PnS = P_1 + P_2 + \dots + P_nS=P1​+P2​+⋯+Pn​ 为一种可能的分割方式，你需要计算：

(∑S=P1+P2+⋯+Pn∀i=1,2,…,n,Pi 是 T 的准前缀n2)(mod998244353)\left( \sum_{\substack{S=P_1+P_2+\dots+P_n \\ \forall i=1,2,\dots,n, P_i \text{ 是 } T \text{ 的准前缀}}} n^2 \right) \pmod{998244353}​S=P1​+P2​+⋯+Pn​∀i=1,2,…,n,Pi​ 是 T 的准前缀​∑​n2​(mod998244353)

输入格式

输入的第一行包含一个字符串 SSS (1≤∣S∣≤1 000 0001 \le |S| \le 1\,000\,0001≤∣S∣≤1000000)，仅由小写英文字母组成。 下一行包含一个字符串 TTT (1≤∣T∣≤1 000 0001 \le |T| \le 1\,000\,0001≤∣T∣≤1000000)，仅由小写英文字母组成。

输出格式

输出一行，包含一个整数：所有分割方案中部分数量的平方和，对 998244353998244353998244353 取模的结果。

aba

在第一个样例中（S=ababaab,T=abaS = \text{ababaab}, T = \text{aba}S=ababaab,T=aba），共有 19 种分割方式： 1 种分为 3 部分的方案，即 ab+aba+ab\text{ab} + \text{aba} + \text{ab}ab+aba+ab； 6 种分为 4 部分的方案，例如 a+b+aba+ab\text{a} + \text{b} + \text{aba} + \text{ab}a+b+aba+ab； 7 种分为 5 部分的方案，例如 a+b+ab+a+ab\text{a} + \text{b} + \text{ab} + \text{a} + \text{ab}a+b+ab+a+ab； 4 种分为 6 部分的方案，例如 a+b+a+b+a+ab\text{a} + \text{b} + \text{a} + \text{b} + \text{a} + \text{ab}a+b+a+b+a+ab； * 1 种分为 7 部分的方案，即 a+b+a+b+a+a+b\text{a} + \text{b} + \text{a} + \text{b} + \text{a} + \text{a} + \text{b}a+b+a+b+a+a+b。
