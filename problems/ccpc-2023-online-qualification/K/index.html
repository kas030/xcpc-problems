题目描述

时间限制：2.5 秒；内存限制：512 MB。

给定两个长度为 nnn 的序列：[a1,a2,…,an][a_1, a_2, \dots, a_n][a1​,a2​,…,an​] 和 [b1,b2,…,bn][b_1, b_2, \dots, b_n][b1​,b2​,…,bn​]。f(a,b)f(a, b)f(a,b) 的值定义为 f(a,b)=max⁡{ai+bi}f(a, b) = \max \{a_i + b_i\}f(a,b)=max{ai​+bi​}，其中 1≤i≤n1 \le i \le n1≤i≤n。

序列 bbb 可以进行移动。你将进行 qqq 次操作，每次操作分为以下两个步骤：

  • 首先，将序列 bbb 向左移动一位，并丢弃第一个元素，使得序列 b′b'b′ 变为 [b1′=b2,b2′=b3,…,bn−1′=bn][b'_1 = b_2, b'_2 = b_3, \dots, b'_{n-1} = b_n][b1′​=b2​,b2′​=b3​,…,bn−1′​=bn​]。
  • 然后，将 vvv 追加到 bbb 的最右侧，使得序列 b′b'b′ 变为 [b1′=b2,b2′=b3,…,bn−1′=bn,bn′=v][b'_1 = b_2, b'_2 = b_3, \dots, b'_{n-1} = b_n, b'_n = v][b1′​=b2​,b2′​=b3​,…,bn−1′​=bn​,bn′​=v]。

在本题中，你的任务是求出每次操作前后 f(a,b)f(a, b)f(a,b) 的值。

输入格式

第一行包含两个整数 nnn 和 qqq (1≤n≤1 000 000,0≤q≤1 000 0001 \le n \le 1\,000\,000, 0 \le q \le 1\,000\,0001≤n≤1000000,0≤q≤1000000)，分别表示序列的长度和操作次数。

第二行包含 nnn 个整数 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​，表示序列 aaa。

第三行包含 nnn 个整数 b1,b2,…,bnb_1, b_2, \dots, b_nb1​,b2​,…,bn​，表示初始序列 bbb。

接下来的 qqq 行，每行包含一个整数 vvv，表示每次操作中追加的值。该值 vvv 经过加密以强制要求在线处理。

保证所有 ai,bia_i, b_iai​,bi​ 和 vvv 的值均从 [1,109][1, 10^9][1,109] 的整数中均匀随机选取。随机性条件不适用于样例测试，但你的程序必须能够通过样例测试。

设 lastlastlast 为你上一次回答的 f(a,b)f(a, b)f(a,b) 的值。对于每次操作，实际的 vvv 值为 v⊕lastv \oplus lastv⊕last。在上述表达式中，符号“⊕\oplus⊕”表示按位异或运算。同时请注意，题目中描述的约束条件仅在解密后适用于相应的参数，加密后的值不受这些约束限制。

输出格式

输出 q+1q + 1q+1 行。

第一行输出一个整数，表示初始的 f(a,b)f(a, b)f(a,b) 值。

在第 kkk 行（2≤k≤q+12 \le k \le q + 12≤k≤q+1），输出一个整数，表示第 (k−1)(k-1)(k−1) 次操作后当前的 f(a,b)f(a, b)f(a,b) 值。
