C.Clique Challenge

23-CCPC-网预选挑战题QOJ #7514

题面语言
完整题册

题目描述

时间限制：1.0 秒；内存限制：512 MB。

图 GGG 的一个团（clique）是指 GGG 的顶点集 XXX，满足 XXX 中任意两个不同的顶点在 GGG 中均相邻。给定一个包含 nnn 个顶点和 mmm 条边的无向图 GGG，请找出图 GGG 中不同的非空团的数量。

输入格式

第一行包含两个整数 nnn 和 mmm (1≤n,m≤10001 \le n, m \le 10001≤n,m≤1000)，分别表示顶点数和边数。

接下来 mmm 行，每行包含两个整数 uiu_iui​ 和 viv_ivi​ (1≤ui,vi≤n,ui≠vi1 \le u_i, v_i \le n, u_i \neq v_i1≤ui​,vi​≤n,ui​=vi​)，描述连接第 uiu_iui​ 个顶点和第 viv_ivi​ 个顶点的一条无向边。

保证每对不同的顶点之间最多只有一条边。

输出格式

输出一行，包含一个整数，表示团的数量。注意答案可能非常大，请输出其对 (109+7)(10^9 + 7)(109+7) 取模的结果。

样例

输入 1

3 2
1 2
2 3

输出 1

5

输入 2

3 3
1 2
1 3
2 3

输出 2

7

说明

在第一个样例中，团为 {1},{2},{3},{1,2}\{1\}, \{2\}, \{3\}, \{1, 2\}{1},{2},{3},{1,2} 和 {2,3}\{2, 3\}{2,3}。

在第二个样例中，团为 {1},{2},{3},{1,2},{1,3},{2,3}\{1\}, \{2\}, \{3\}, \{1, 2\}, \{1, 3\}, \{2, 3\}{1},{2},{3},{1,2},{1,3},{2,3} 和 {1,2,3}\{1, 2, 3\}{1,2,3}。
