题目描述

时间限制：1.0 秒；内存限制：256 MB。

你需要计算一段 Python 程序的输出结果。

为了简化问题，代码满足以下约束。程序恰好有 5 行。代码的第一行是：

ans=0

第二行和第三行的形式为：

for i in range(a,b,c):
    for j in range(d,e,f):

其中，iii 和 jjj 是循环变量。iii 和 jjj 可以是任意两个不同的小写英文字母。a,b,c,d,e,fa, b, c, d, e, fa,b,c,d,e,f 可以是不含前导零的整数，或者是之前已经引入的循环变量。也就是说，d,ed, ed,e 和 fff 可以是 iii。标记 ccc 或 fff（或两者）可以省略。当省略时，它们等于 1。

代码的第四行形式为：

ans+=j

其中，jjj 是内层循环的循环变量（注意它可能是除 jjj 以外的其他字母）。

代码的第五行是：

print(ans)

对于任何 c≠0c \neq 0c=0，Python 语言中的语句：

for i in range(a,b,c):

解释如下：

  • 如果 c>0c > 0c>0，iii 将依次取值 a,a+c,a+2c,…a, a + c, a + 2c, \dotsa,a+c,a+2c,… 直到 a+kca + kca+kc，其中 kkk 是满足 a+kc<ba + kc < ba+kc<b 的最大整数。如果 a≥ba \ge ba≥b，iii 将不会取任何值。
  • 如果 c<0c < 0c<0，iii 将依次取值 a,a+c,a+2c,…a, a + c, a + 2c, \dotsa,a+c,a+2c,… 直到 a+kca + kca+kc，其中 kkk 是满足 a+kc>ba + kc > ba+kc>b 的最大整数。如果 a≤ba \le ba≤b，iii 将不会取任何值。

输入格式

5 行，表示代码。

保证每行末尾没有多余空格。但是，输入文件末尾可能存在额外的换行符。请注意，输入文件中的每个制表符（tab）均由 4 个空格表示。

保证 1≤a,b,∣c∣,d,e,∣f∣≤1061 \le a, b, |c|, d, e, |f| \le 10^61≤a,b,∣c∣,d,e,∣f∣≤106。

输出格式

一个整数，表示程序的输出。

样例

输入格式 1

ans=0
for a in range(1,3):
    for b in range(5,1,-2):
        ans+=b
print(ans)

输出格式 1

16

说明

对于第一个样例，aaa 将依次取值 1, 2，对于 aaa 取的每一个值，bbb 将取值 5, 3，因此答案为 2×(5+3)=162 \times (5 + 3) = 162×(5+3)=16。

输入格式 2

ans=0
for q in range(100,50,-1):
    for i in range(q,77,20):
        ans+=i
