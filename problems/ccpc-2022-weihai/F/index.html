F.Mooncake Delivery

22-CCPC-威海金牌题QOJ #9596

题面语言
原始题面

题目描述

时间限制：1.0 秒；内存限制：256 MB。

Melon 是一只住在月球上的兔子，每年中秋节负责运送月饼。除了地球外，许多其他星球也有月饼需求。因此，Melon 在运送月饼时需要消耗她的仙力在不同星球间穿梭。

共有 nnn 个星球，编号为 111 到 nnn，以及 mmm 条隧道。每条隧道无向连接两个星球。每个星球 iii 都有一个颜色 cic_ici​ 和一个消耗值 wiw_iwi​，表示 Melon 降落到该星球时需要消耗的仙力。

为了节省星际旅行的仙力，Melon 会使用一种特殊技能：种植桂花树。最初，没有任何星球上种有桂花树。当 Melon 降落到一个没有桂花树的星球时，她会立即在那里种下一棵桂花树，但她不会在同一个星球上种植超过一棵桂花树。如果一个星球已经种有桂花树，Melon 再次降落到该星球时将不会消耗任何仙力。此外，当她位于星球 iii 时，她可以选择一个种有桂花树且颜色不是 cic_ici​ 的星球 jjj，然后远程砍掉星球 jjj 上的桂花树并恢复 wjw_jwj​ 的仙力。

形式化地，Melon 在星球 uuu 时，随时可以执行以下任一操作：

  • 通过隧道移动到相邻且未种植桂花树的星球 vvv，消耗 wvw_vwv​ 仙力，并在星球 vvv 上种下一棵桂花树。
  • 通过隧道移动到相邻且已种植桂花树的星球，不消耗仙力，也不种植额外的树。
  • 选择一个种有桂花树且颜色不是 cuc_ucu​ 的星球 vvv，远程砍掉星球 vvv 上的桂花树（即此后星球 vvv 上不再有桂花树），并恢复 wvw_vwv​ 仙力。请注意，此操作可以在同一个星球上多次执行。

Melon 的仙力不能低于 000，因此她必须在出发前准备足够的仙力。Melon 想知道从起始星球 sss 到目标星球 ttt 旅行所需准备的最小仙力。特别地，Melon 在起始星球 sss 需要消耗 wsw_sws​ 仙力并种下一棵桂花树。

输入格式

第一行包含一个整数 TTT (1≤T≤1001 \le T \le 1001≤T≤100)，表示测试用例的数量。

每个测试用例的第一行包含两个整数 nnn 和 mmm (2≤n≤300,1≤m≤n(n−1)22 \le n \le 300, 1 \le m \le \frac{n(n - 1)}{2}2≤n≤300,1≤m≤2n(n−1)​)，表示星球和隧道的数量。

第二行包含 nnn 个整数 c1,c2,…,cnc_1, c_2, \dots, c_nc1​,c2​,…,cn​ (1≤ci≤n1 \le c_i \le n1≤ci​≤n)，表示每个星球的颜色。

第三行包含 nnn 个整数 w1,w2,…,wnw_1, w_2, \dots, w_nw1​,w2​,…,wn​ (1≤wi≤1091 \le w_i \le 10^91≤wi​≤109)，表示在每个星球上需要消耗的仙力。

接下来的 mmm 行，每行包含两个整数 uuu 和 vvv (1≤u,v≤n,u≠v1 \le u, v \le n, u \neq v1≤u,v≤n,u=v)，表示星球 uuu 和 vvv 之间的一条无向隧道。保证任意两个不同星球之间最多只有一条隧道，且任意两个星球之间都存在路径。

保证所有测试用例的 nnn 之和不超过 300300300。

输出格式

输出 nnn 行，每行包含 nnn 个由空格分隔的整数。第 iii 行第 jjj 列的整数表示从起始星球 iii 到目标星球 jjj 旅行所需准备的最小仙力。特别地，当 i=ji = ji=j 时输出 000。

说明

对于样例，从星球 333 到星球 111 的一种初始仙力为 666 的旅行方式如下：

  1. 消耗 444 点仙力并在星球 333 上种下一棵桂花树。（剩余仙力：222）
  2. 移动到星球 222，消耗 222 点仙力并在其上种下一棵桂花树。（剩余仙力：000）
  3. 砍掉星球 333 上的桂花树并恢复 444 点仙力。（剩余仙力：444）
  4. 移动到星球 111，消耗 111 点仙力并在其上种下一棵桂花树。（剩余仙力：333）
