B.Operating Robot

26-ICPC-西安-邀铜牌题QOJ #17343

完整题册

题目描述

时间限制：1 秒；内存限制：512 MB。

一个机器人位于二维直角坐标系上。初始时，机器人位于 (0,0)(0, 0)(0,0)，Yuki 希望使用一序列指令引导机器人到达 (x,y)(x, y)(x,y)。

具体来说，指令字符串仅由 0 和 1 组成：

  • 0 表示向右移动一步，将机器人的位置从 (a,b)(a, b)(a,b) 变为 (a+1,b)(a + 1, b)(a+1,b)。
  • 1 表示向上移动一步，将机器人的位置从 (a,b)(a, b)(a,b) 变为 (a,b+1)(a, b + 1)(a,b+1)。

Yuki 有一个长度为 nnn 的指令字符串 s=s1…sns = s_1 \dots s_ns=s1​…sn​，其中仅包含 0、1 和 2。Yuki 必须首先将字符串中的所有 2 替换为 0 或 1。然后，机器人按照以下规则运行：

  • 对于每个非负整数 iii，如果机器人在时刻 iii 未处于 (x,y)(x, y)(x,y)，则机器人执行该字符串的第 ((i mod n)+1)((i \bmod n) + 1)((imodn)+1) 条指令。

Yuki 希望找到一种替换方案，使得机器人能够到达 (x,y)(x, y)(x,y)，且得到的指令字符串的字典序尽可能小。你需要帮助 Yuki 找到满足条件的字典序最小的指令字符串，或者报告不存在这样的字符串。

输入格式

本题包含多个测试用例。

第一行包含一个正整数 ttt (1≤t≤1051 \le t \le 10^51≤t≤105)，表示测试用例的数量。

对于每个测试用例：

  • 第一行包含三个整数 n,x,yn, x, yn,x,y (1≤n≤1061 \le n \le 10^61≤n≤106, 0≤x,y≤10180 \le x, y \le 10^{18}0≤x,y≤1018)。
  • 第二行包含一个长度为 nnn 的字符串 sss (si∈{0,1,2}s_i \in \{0, 1, 2\}si​∈{0,1,2})。

保证所有测试用例中 nnn 的总和不超过 10610^6106。

输出格式

对于每个测试用例，输出一行：

  • 如果不存在这样的指令字符串，输出 -1。
  • 如果存在这样的指令字符串，输出一个长度为 nnn 的字符串，表示字典序最小的合法指令字符串。

说明

对于第一个测试用例：

  • 初始时，机器人位于 (0,0)(0, 0)(0,0)，且指令字符串为 01111。
  • 按照规则，机器人依次移动到 (1,0)(1, 0)(1,0)、(1,1)(1, 1)(1,1)、(1,2)(1, 2)(1,2)、(1,3)(1, 3)(1,3)、(1,4)(1, 4)(1,4)、(2,4)(2, 4)(2,4)。
  • 由于机器人到达了 (2,4)(2, 4)(2,4)，因此 01111 是一个合法的指令字符串。可以证明 01111 是字典序最小的合法字符串，所以答案为 01111。

对于第二个测试用例：

  • 初始时，机器人位于 (0,0)(0, 0)(0,0)，我们将指令字符串 02221 替换为 00111。
  • 按照规则，机器人依次移动到 (1,0)(1, 0)(1,0)、(2,0)(2, 0)(2,0)、(2,1)(2, 1)(2,1)、(2,2)(2, 2)(2,2)、(2,3)(2, 3)(2,3)、(3,3)(3, 3)(3,3)。
  • 由于机器人到达了 (3,3)(3, 3)(3,3)，因此 00111 是一个合法的指令字符串。可以证明 00111 是字典序最小的合法字符串，所以答案为 00111。

对于第三个测试用例：

  • 可以证明，无法通过替换指令字符串中的 2 使得机器人到达 (3,3)(3, 3)(3,3)。
