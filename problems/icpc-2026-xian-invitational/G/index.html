题目描述

时间限制：1 秒；内存限制：512 MB。

Yuki 有一个大小为 nnn 的多重集 S={s1,…,sn}S = \{s_1, \dots, s_n\}S={s1​,…,sn​} 和一个整数 kkk。

Yuki 定义了一次变换如下：

  • 选择 SSS 的一个子集 S′S'S′（其中 S′S'S′ 可以是空集），从 SSS 中移除 S′S'S′，并将 S′S'S′ 的 mex∗\text{mex}^*mex∗ 加入到 SSS 中。

现在，Yuki 想要进行若干次变换，使得 SSS 变为 {k}\{k\}{k}。你需要帮助 Yuki 求出使 SSS 等于 {k}\{k\}{k} 所需的最少变换次数。由于答案可能非常大，你只需要输出答案对 998244353998244353998244353 取模后的结果。

可以证明，总是存在至少一种操作序列可以将 SSS 变换为 {k}\{k\}{k}。

∗^*∗: 一个多重集的 mex\text{mex}mex 是指未在其中出现的最小非负整数。例如，mex{0,1,2}=3\text{mex}\{0, 1, 2\} = 3mex{0,1,2}=3，mex{1,0,3,1}=2\text{mex}\{1, 0, 3, 1\} = 2mex{1,0,3,1}=2，且 mex∅=0\text{mex} \emptyset = 0mex∅=0。

输入格式

本题包含多个测试用例。

第一行包含一个正整数 ttt (1≤t≤1051 \le t \le 10^51≤t≤105)，表示测试用例的数量。

对于每个测试用例：

  • 第一行包含两个整数 n,kn, kn,k (1≤n≤5⋅1051 \le n \le 5 \cdot 10^51≤n≤5⋅105, 0≤k≤1090 \le k \le 10^90≤k≤109)。
  • 第二行包含 nnn 个整数 s1,…,sns_1, \dots, s_ns1​,…,sn​ (0≤si≤1090 \le s_i \le 10^90≤si​≤109)。

保证所有测试用例中 nnn 的总和不超过 5⋅1055 \cdot 10^55⋅105。

输出格式

对于每个测试用例，输出一行，包含一个整数，表示将 SSS 变为 {k}\{k\}{k} 所需的最少变换次数对 998244353998244353998244353 取模后的结果。
