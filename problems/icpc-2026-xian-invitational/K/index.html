题目描述

时间限制：3 秒；内存限制：512 MB。

Yuki 有一棵拥有 2n2^n2n 个节点的树，节点编号为 000 到 2n−12^n - 12n−1。第 iii 条边连接节点 uiu_iui​ 和节点 viv_ivi​。

设 lcar(u,v)\text{lca}_r(u, v)lcar​(u,v) 表示以节点 rrr 为根时，节点 uuu 和 vvv 的最近公共祖先（LCA）。

你需要帮助 Yuki 计算：

⨁0≤u<v<2nlcau⊕v(u,v)\bigoplus_{0 \le u < v < 2^n} \text{lca}_{u \oplus v}(u, v)0≤u<v<2n⨁​lcau⊕v​(u,v)

其中 ⊕\oplus⊕ 表示按位异或（XOR）运算。

输入格式

本题包含多个测试用例。

第一行包含一个正整数 ttt (1≤t≤1041 \le t \le 10^41≤t≤104)，表示测试用例的数量。

对于每个测试用例：

  • 第一行包含一个正整数 nnn (1≤n≤211 \le n \le 211≤n≤21)。
  • 接下来的 2n−12^n - 12n−1 行，每行包含两个整数 ui,viu_i, v_iui​,vi​ (0≤ui,vi<2n,ui≠vi0 \le u_i, v_i < 2^n, u_i \neq v_i0≤ui​,vi​<2n,ui​=vi​)。

保证输入构成一棵树，且所有测试用例中 2n2^n2n 的总和不超过 2212^{21}221。

输出格式

对于每个测试用例，输出一行，包含一个整数，表示答案。
