题目描述

时间限制：2 秒；内存限制：1024 MB。

Yuki 发现回文括号序列不一定是合法括号序列，因此她设计了另一种方式来定义回文合法括号序列。

Yuki 根据以下规则定义回文括号序列：

  • 空字符串是回文括号序列。
  • ( 和 ) 是回文括号序列。
  • 如果括号序列 sss 是回文括号序列，那么 (s( 和 )s) 也是回文括号序列。

Yuki 根据以下规则定义合法括号序列：

  • 空字符串是合法括号序列。
  • 如果括号序列 sss 是合法括号序列，那么 (s) 是合法括号序列。
  • 如果括号序列 sss 和 ttt 都是合法括号序列，那么 ststst（两个括号序列的拼接）也是合法括号序列。

对于一个括号序列 s=s1…sns = s_1 \dots s_ns=s1​…sn​，Yuki 定义 sss 是回文合法括号序列当且仅当：

  • s2…sn−1s_2 \dots s_{n-1}s2​…sn−1​ 是回文括号序列。
  • s1…sns_1 \dots s_ns1​…sn​ 是合法括号序列。

特别地，空字符串和 () 也是回文合法括号序列。

例如，(())() 和 ()()(()()) 是回文合法括号序列，而 ((())) 和 ()()(()) 不是。

现在，Yuki 有一个长度为 nnn 的括号序列 sss，她想找到 sss 的最长子序列∗^*∗，使得该子序列是一个回文合法括号序列。然而，Yuki 不知道该怎么做，所以你需要帮助她求出最长此类子序列的长度。

∗^*∗：序列 aaa 是序列 bbb 的子序列当且仅当 aaa 可以通过从 bbb 中删除零个或多个元素获得；特别地，空序列是任何序列的子序列。
