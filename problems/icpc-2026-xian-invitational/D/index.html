D.Qenerals

26-ICPC-西安-邀签到题QOJ #17345

题面语言
完整题册

题目描述

时间限制：1 秒；内存限制：512 MB。

Yuki 正在玩一个名为 Qenerals 的游戏。

在时间 t=0t = 0t=0 时，Yuki 拥有 x=0x = 0x=0 名士兵，并占领了 y=1y = 1y=1 座堡垒。地图上还有 nnn 座未被占领的堡垒，其中第 iii 座堡垒有一个参数 aia_iai​。

游戏持续 mmm 秒。对于满足 1≤i≤m1 \le i \le m1≤i≤m 的每个正整数 iii：

  • 在第 iii 秒开始时，Yuki 占领的每座堡垒都会生产 111 名士兵，即 x←x+yx \leftarrow x + yx←x+y。
  • 在第 iii 秒结束时，Yuki 可以进行任意次数的操作（包括零次）。在每次操作中，Yuki 选择一座未被占领的堡垒 jjj，满足 aj≤xa_j \le xaj​≤x，消耗 aja_jaj​ 名士兵，并占领堡垒 jjj，即 x←x−ajx \leftarrow x - a_jx←x−aj​ 且 y←y+1y \leftarrow y + 1y←y+1。

你需要帮助 Yuki 确定游戏结束时她能拥有的最大士兵数量。

输入格式

本题包含多个测试用例。

第一行包含一个正整数 ttt (1≤t≤1051 \le t \le 10^51≤t≤105)，表示测试用例的数量。

对于每个测试用例：

  • 第一行包含两个正整数 n,mn, mn,m (1≤n≤5⋅1051 \le n \le 5 \cdot 10^51≤n≤5⋅105, 1≤m≤1091 \le m \le 10^91≤m≤109)。
  • 第二行包含 nnn 个正整数 a1,…,ana_1, \dots, a_na1​,…,an​ (1≤ai≤1091 \le a_i \le 10^91≤ai​≤109)。

保证所有测试用例中 nnn 的总和不超过 5⋅1055 \cdot 10^55⋅105。

输出格式

对于每个测试用例，输出一行，包含一个整数，表示游戏结束时 Yuki 能拥有的最大士兵数量。

样例

输入样例 1

3
2 3
2 1
3 6
1 1 3
3 5
1 1 1

输出样例 1

4
13
12

说明

对于第一个测试用例：

  • 在第 111 秒开始时，Yuki 占领的堡垒数量为 y=1y = 1y=1，因此士兵数量 xxx 从 000 增加到 111。
  • 在第 111 秒结束时，Yuki 可以选择占领第 222 座堡垒，因此 yyy 从 111 增加到 222，xxx 从 111 减少到 000。
  • 在第 222 秒开始时，y=2y = 2y=2，因此 xxx 从 000 增加到 222。
  • 在第 222 秒结束时，Yuki 可以选择不进行任何操作。
  • 在第 333 秒开始时，y=2y = 2y=2，因此 xxx 从 222 增加到 444。
  • 在第 333 秒结束时，Yuki 可以选择不进行任何操作。
  • 游戏结束后，士兵数量 xxx 为 444。可以证明 444 是 Yuki 所能获得的最大士兵数量。

对于第二个测试用例：

  • Yuki 可以分别在第 111 秒、第 222 秒和第 333 秒结束时占领第 111、第 222 和第 333 座堡垒，从而在游戏结束时拥有 131313 名士兵。

对于第三个测试用例：

  • Yuki 可以在第 111 秒结束时占领第 111 座堡垒，并在第 222 秒结束时占领第 222 和第 333 座堡垒，从而在游戏结束时拥有 121212 名士兵。
