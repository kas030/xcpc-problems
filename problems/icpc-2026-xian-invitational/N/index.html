N.Zebra Crossing

题目描述

时间限制：1 秒；内存限制：512 MB。

Yuki 面前有一条奇怪的斑马线。

这条斑马线可以看作一棵拥有 nnn 个节点的树。第 iii 条边连接节点 uiu_iui​ 和节点 viv_ivi​。

每个节点都被染成黑色或白色，由一个长度为 nnn 的二进制字符串 sss 描述：

  • 如果 si=0s_i = 0si​=0，节点 iii 的颜色为黑色。
  • 如果 si=1s_i = 1si​=1，节点 iii 的颜色为白色。

Yuki 拥有跳跃能力 kkk，这意味着当她位于节点 xxx 时，她可以跳跃到满足 dist(x,y)≤k\text{dist}(x, y) \le kdist(x,y)≤k 的任意节点 yyy。这里，dist(x,y)\text{dist}(x, y)dist(x,y) 表示节点 xxx 和节点 yyy 之间简单路径上的边数。

接下来，Yuki 将在斑马线上进行 n−1n - 1n−1 轮跳跃。在第 iii 轮中，Yuki 从节点 111 出发，希望通过一系列跳跃到达节点 i+1i + 1i+1。同时，Yuki 希望最小化跳跃后落在黑色节点上的次数。

你需要帮助 Yuki 求出每一轮跳跃中，她落在黑色节点上的最少次数。

输入格式

本题包含多个测试用例。

第一行包含一个正整数 ttt (1≤t≤1051 \le t \le 10^51≤t≤105)，表示测试用例的数量。

对于每个测试用例：

  • 第一行包含两个正整数 n,kn, kn,k (1≤n≤5⋅1051 \le n \le 5 \cdot 10^51≤n≤5⋅105, 1≤k≤n1 \le k \le n1≤k≤n)。
  • 第二行包含一个长度为 nnn 的二进制字符串 sss (si∈{0,1}s_i \in \{0, 1\}si​∈{0,1})。
  • 接下来的 n−1n - 1n−1 行，每行包含两个正整数 ui,viu_i, v_iui​,vi​ (1≤ui,vi≤n1 \le u_i, v_i \le n1≤ui​,vi​≤n, ui≠viu_i \neq v_iui​=vi​)。

保证所有测试用例中 nnn 的总和不超过 5⋅1055 \cdot 10^55⋅105。

输出格式

对于每个测试用例，输出一行，包含 n−1n - 1n−1 个整数，其中第 iii 个整数表示 Yuki 在第 iii 轮跳跃中落在黑色节点上的最少次数。
