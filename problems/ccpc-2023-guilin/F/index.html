F.Redundant Towers

23-CCPC-桂林挑战题QOJ #7682

题面语言
完整题册

题目描述

时间限制：4.0 秒；内存限制：1024 MB。

在 Byteland 有 nnn 个无线通信塔，编号为 1,2,…,n1, 2, \dots, n1,2,…,n。第 iii 个塔位于 (xi,yi)(x_i, y_i)(xi​,yi​)。任意两个塔的 xxx 坐标互不相同，且任意两个塔的 yyy 坐标互不相同。每个塔的传输半径均为 RRR。换句话说，第 iii 个塔可以在一次跳跃内向第 jjj 个塔发送消息，当且仅当 (xi−xj)2+(yi−yj)2≤R\sqrt{(x_i - x_j)^2 + (y_i - y_j)^2} \le R(xi​−xj​)2+(yi​−yj​)2​≤R。初始时，所有塔均处于使用状态。

当且仅当第 aaa 个塔 (1≤a≤n1 \le a \le n1≤a≤n) 满足以下所有条件时，称其为冗余塔： 第 aaa 个塔处于使用状态。 对于每一对处于使用状态的塔 bbb 和 ccc (1≤b<c≤n,b≠a,c≠a1 \le b < c \le n, b \neq a, c \neq a1≤b<c≤n,b=a,c=a)，如果它们之间可以通过处于使用状态的塔直接或间接通信，那么它们之间也可以在不经过第 aaa 个塔的情况下直接或间接通信。注意，消息只能由处于使用状态的塔进行传输。

你需要执行 qqq 次操作。在每次操作中，给定一个整数 kkk (1≤k≤n1 \le k \le n1≤k≤n)，表示状态发生改变的塔的编号。如果第 kkk 个塔处于使用状态，它将变为不使用状态；如果它处于不使用状态，它将变为使用状态。每次操作后，你需要统计当前冗余塔的数量。

输入格式

第一行包含两个整数 nnn 和 RRR (1≤n≤105,2≤R≤51 \le n \le 10^5, 2 \le R \le 51≤n≤105,2≤R≤5)，分别表示塔的数量和传输半径。

接下来的 nnn 行中，第 iii 行包含两个整数 xix_ixi​ 和 yiy_iyi​ (1≤xi,yi≤n1 \le x_i, y_i \le n1≤xi​,yi​≤n)，表示第 iii 个塔的位置。保证任意两个塔的 xxx 坐标互不相同，且任意两个塔的 yyy 坐标互不相同。

下一行包含一个整数 qqq (1≤q≤1051 \le q \le 10^51≤q≤105)，表示操作次数。

接下来的 qqq 行，每行包含一个整数 kkk (1≤k≤n1 \le k \le n1≤k≤n)，表示一次操作。令 lastlastlast 为你上一次回答的冗余塔数量。注意，在输入开始时 lastlastlast 应重置为 000。对于每次操作，kkk 是加密的：其真实值为 k⊕lastk \oplus lastk⊕last。在上述表达式中，符号 “⊕\oplus⊕” 表示按位异或运算。同时请注意，题目描述中给出的约束仅适用于解密后的对应参数，加密后的值不受这些约束限制。

输出格式

对于每次操作，输出一行，包含一个整数，表示当前冗余塔的数量。
