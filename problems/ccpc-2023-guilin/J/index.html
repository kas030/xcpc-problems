题目描述

时间限制：4.0 秒；内存限制：1024 MB。

Putata 带来了他最新的字符串问题。给定两个字符串序列 AAA 和 BBB，每个序列恰好包含 nnn 个字符串，且所有字符串的长度均为 mmm。你需要重新排列这些字符串，使得两个序列中所有字符串拼接后的结果循环同构。

形式化地，你需要选择两个 1,2,…,n1, 2, \dots, n1,2,…,n 的排列 ppp 和 qqq，使得 Ap1+Ap2+⋯+ApnA_{p_1} + A_{p_2} + \dots + A_{p_n}Ap1​​+Ap2​​+⋯+Apn​​ 与 Bq1+Bq2+⋯+BqnB_{q_1} + B_{q_2} + \dots + B_{q_n}Bq1​​+Bq2​​+⋯+Bqn​​ 循环同构。字符串 R=S+TR = S + TR=S+T 满足：对于 i≤∣S∣i \le |S|i≤∣S∣，Ri=SiR_i = S_iRi​=Si​，否则 Ri=Ti−∣S∣R_i = T_{i-|S|}Ri​=Ti−∣S∣​。称两个字符串 S,TS, TS,T 循环同构，当且仅当存在整数 ddd，使得对于所有 1≤i≤∣S∣1 \le i \le |S|1≤i≤∣S∣，都有 Si=T((i+d)(mod∣S∣))+1S_i = T_{((i+d) \pmod{|S|}) + 1}Si​=T((i+d)(mod∣S∣))+1​，且 ∣S∣=∣T∣|S| = |T|∣S∣=∣T∣。

请帮助 Budada 找到 ppp 和 qqq，或者报告不存在这样的 ppp 和 qqq。

输入格式

第一行包含一个整数 ttt (1≤t≤1061 \le t \le 10^61≤t≤106)，表示测试用例的数量。

对于每个测试用例，第一行包含两个整数 n,mn, mn,m (1≤n,m≤106,1≤n⋅m≤1061 \le n, m \le 10^6, 1 \le n \cdot m \le 10^61≤n,m≤106,1≤n⋅m≤106)。

接下来 nnn 行，第 iii 行包含一个字符串 AiA_iAi​ (∣Ai∣=m|A_i| = m∣Ai​∣=m)。

接下来 nnn 行，第 iii 行包含一个字符串 BiB_iBi​ (∣Bi∣=m|B_i| = m∣Bi​∣=m)。

保证所有输入字符串仅包含小写英文字母。

保证所有测试用例中 n⋅mn \cdot mn⋅m 的总和不超过 10610^6106。

对于每个测试用例，如果排列 ppp 和 qqq 存在，请分两行输出它们，排列中的元素用空格分隔。否则，输出 −1-1−1。
