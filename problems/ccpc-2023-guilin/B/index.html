B.The Game

23-CCPC-桂林银牌题QOJ #7678

题面语言
完整题册

题目描述

时间限制：2.0 秒；内存限制：1024 MB。

Randias 正在玩一个游戏。他有两个多重集（可以包含重复元素）AAA 和 BBB，分别包含 nnn 个整数 A1,A2,…,AnA_1, A_2, \dots, A_nA1​,A2​,…,An​ 和 mmm 个整数 B1,B2,…,BmB_1, B_2, \dots, B_mB1​,B2​,…,Bm​。他可以进行任意次数的以下操作：

  • 选择一个元素 x∈Ax \in Ax∈A，将 xxx 变为 x+1x + 1x+1。然后移除 AAA 中的最小元素。注意，如果 AAA 中有多个最小元素，我们只移除其中一个。

例如，如果 A={4,4,5,5,6}A = \{4, 4, 5, 5, 6\}A={4,4,5,5,6} 且我们选择 x=5x = 5x=5，操作后 AAA 将变为 {4,5,6,6}\{4, 5, 6, 6\}{4,5,6,6}。

他想知道是否可以通过若干次（可能为零次）操作使得 A=BA = BA=B？如果可以，请帮助他确定需要执行哪些操作。

如果对于所有 xxx，集合 AAA 和 BBB 中 xxx 出现的次数相同，则认为这两个多重集相等。

输入格式

第一行包含一个整数 ttt (1≤t≤5⋅1041 \le t \le 5 \cdot 10^41≤t≤5⋅104)，表示测试用例的数量。

对于每个测试用例，第一行包含两个整数 n,mn, mn,m (1≤m≤n≤3⋅1051 \le m \le n \le 3 \cdot 10^51≤m≤n≤3⋅105)，表示两个多重集的大小。

接下来一行包含 nnn 个整数 A1,A2,…,AnA_1, A_2, \dots, A_nA1​,A2​,…,An​ (1≤Ai≤1091 \le A_i \le 10^91≤Ai​≤109)。

接下来一行包含 mmm 个整数 B1,B2,…,BmB_1, B_2, \dots, B_mB1​,B2​,…,Bm​ (1≤Bi≤1091 \le B_i \le 10^91≤Bi​≤109)。

保证所有测试用例中 nnn 的总和与 mmm 的总和均不超过 3⋅1053 \cdot 10^53⋅105。

输出格式

对于每个测试用例，如果 Randias 无法使 A=BA = BA=B，输出 “−1-1−1”。

否则，在第一行输出 Randias 需要执行的操作次数 LLL (0≤L≤n0 \le L \le n0≤L≤n)。

下一行包含 LLL 个整数 x1,x2,…,xLx_1, x_2, \dots, x_Lx1​,x2​,…,xL​，表示每次操作所选择的整数 xxx。你必须确保在每次操作前 x∈Ax \in Ax∈A。

如果存在多种方案，输出任意一种即可。
