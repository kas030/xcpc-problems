题目描述

时间限制：1 秒；内存限制：512 MB。

Alice 和 Bob 各自拥有一个实数集合，这两个集合都是若干个不相交闭区间的并集。他们将各自从自己的集合中独立地均匀随机选取一个实数，你需要计算这两个实数之差的绝对值的期望。

更正式地说，给定一个实数集合 S=⋃[l,r]S = \bigcup [l, r]S=⋃[l,r]，从集合 SSS 中均匀随机选取一个实数 xxx 意味着对于 SSS 中任意两个长度相等的区间 [l1,r1],[l2,r2]⊆S[l_1, r_1], [l_2, r_2] \subseteq S[l1​,r1​],[l2​,r2​]⊆S，即 r1−l1=r2−l2r_1 - l_1 = r_2 - l_2r1​−l1​=r2​−l2​，都有 P(x∈[l1,r1])=P(x∈[l2,r2])P(x \in [l_1, r_1]) = P(x \in [l_2, r_2])P(x∈[l1​,r1​])=P(x∈[l2​,r2​])。

输入格式

第一行包含两个整数 nnn 和 mmm (1≤n,m≤1051 \le n, m \le 10^51≤n,m≤105)，分别表示构成 Alice 集合和 Bob 集合的区间数量。

接下来的 n+mn + mn+m 行，每行包含两个整数 lll 和 rrr (−109≤l≤r≤109-10^9 \le l \le r \le 10^9−109≤l≤r≤109)，描述一个闭区间 [l,r][l, r][l,r]。前 nnn 个区间构成 Alice 的集合，后 mmm 个区间构成 Bob 的集合。注意，当 l=rl = rl=r 时，区间 [l,r][l, r][l,r] 为退化区间，仅包含一个实数。

保证构成每个人集合的区间两两不相交。

输出格式

输出一个实数，表示 Alice 和 Bob 分别选取的两个实数之差的绝对值的期望。

如果你的答案的绝对误差或相对误差不超过 10−910^{-9}10−9，则视为正确。形式化地说，假设你的输出为 aaa，标准答案为 bbb，当且仅当 ∣a−b∣max⁡(1,∣b∣)≤10−9\frac{|a-b|}{\max(1, |b|)} \le 10^{-9}max(1,∣b∣)∣a−b∣​≤10−9 时，你的输出被接受。
