题目描述

时间限制：1.0 秒；内存限制：1024 MB。

NIT 喜欢圆螺丝。他也喜欢 ⊕\oplus⊕ 运算符，因为这让他联想到圆螺丝，其中 ⊕\oplus⊕ 表示按位异或（Bitwise-XOR）运算。

定义一个序列 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​ 的值 VaV_aVa​ 为：

Va=a1+an+∑i=1n−1(ai⊕ai+1)V_a = a_1 + a_n + \sum_{i=1}^{n-1} (a_i \oplus a_{i+1})Va​=a1​+an​+i=1∑n−1​(ai​⊕ai+1​)

给定一个序列 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​，你可以进行任意次数的以下操作：

  • 选择一个下标 iii（1≤i≤n1 \le i \le n1≤i≤n），将 aia_iai​ 修改为任意非负整数；该操作的代价为 CCC。

你需要最小化序列的值与操作所产生的代价之和。换句话说，设 ppp 为你进行的操作次数，Va′V_{a'}Va′​ 为操作后序列 aaa 的值，你需要最小化 pC+Va′pC + V_{a'}pC+Va′​。

输入格式

输入包含多个测试用例。输入的第一行包含一个整数 TTT（1≤T≤1001 \le T \le 1001≤T≤100），表示测试用例的数量。

对于每个测试用例： 第一行包含两个整数 n,Cn, Cn,C（2≤n≤105,0≤C<2192 \le n \le 10^5, 0 \le C < 2^{19}2≤n≤105,0≤C<219），分别表示序列的长度和进行一次操作的代价。

第二行包含 nnn 个整数 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​（0≤ai<2180 \le a_i < 2^{18}0≤ai​<218），表示序列中的元素。

保证所有测试用例中 nnn 的总和不超过 2×1052 \times 10^52×105。

输出格式

对于每个测试用例，在一行中输出一个整数，表示 pC+Va′pC + V_{a'}pC+Va′​ 的最小可能值。

输出样例 1

24

说明

对于第一个测试用例，达到最小值的一种方法是将序列修改为 1,1,1,01, \mathbf{1}, \mathbf{1}, \mathbf{0}1,1,1,0；加粗的数字是经过修改的。最终序列的值为 222，进行了 333 次操作；总值 + 代价为 2+3×4=142 + 3 \times 4 = 142+3×4=14。

对于第二个测试用例，达到最小值的一种方法是将序列修改为 6,6,6,6,6,6,6,66, 6, 6, \mathbf{6}, \mathbf{6}, 6, 6, 66,6,6,6,6,6,6,6；最终序列的值为 12+2×6=2412 + 2 \times 6 = 2412+2×6=24。
