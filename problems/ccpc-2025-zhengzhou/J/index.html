题目描述

时间限制：2.0 秒；内存限制：1024 MB。

给定一个长度为 nnn (n≥2n \ge 2n≥2) 的整数序列 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​，以及一个长度为 mmm (m≥2m \ge 2m≥2) 的整数序列 b1,b2,…,bmb_1, b_2, \dots, b_mb1​,b2​,…,bm​。我们可以构造一个 n×mn \times mn×m 的矩阵 ccc，使得对于所有的 1≤i≤n,1≤j≤m1 \le i \le n, 1 \le j \le m1≤i≤n,1≤j≤m，有 ci,j=ai⊕bjc_{i,j} = a_i \oplus b_jci,j​=ai​⊕bj​，其中 ⊕\oplus⊕ 表示按位异或（bitwise XOR）操作。

请你求出有多少个下标对 (i,j)(i, j)(i,j) (1≤i<n,1≤j<m1 \le i < n, 1 \le j < m1≤i<n,1≤j<m)，满足 ccc 中由以下形式给出的子矩阵：

[ci,jci,j+1ci+1,jci+1,j+1]\begin{bmatrix} c_{i,j} & c_{i,j+1} \\ c_{i+1,j} & c_{i+1,j+1} \end{bmatrix}[ci,j​ci+1,j​​ci,j+1​ci+1,j+1​​]

具有如下形式：

[xx+1x+2x+3]\begin{bmatrix} x & x + 1 \\ x + 2 & x + 3 \end{bmatrix}[xx+2​x+1x+3​]

也就是说，满足 ci,j+1=ci,j+1c_{i,j+1} = c_{i,j} + 1ci,j+1​=ci,j​+1，ci+1,j=ci,j+2c_{i+1,j} = c_{i,j} + 2ci+1,j​=ci,j​+2 且 ci+1,j+1=ci,j+3c_{i+1,j+1} = c_{i,j} + 3ci+1,j+1​=ci,j​+3。

输入格式

第一行包含一个整数 TTT (1≤T≤1051 \le T \le 10^51≤T≤105)，表示测试用例的数量。

对于每个测试用例：

  • 第一行包含两个空格分隔的整数 n,mn, mn,m (2≤n,m≤2×1052 \le n, m \le 2 \times 10^52≤n,m≤2×105)，表示矩阵 ccc 的行数和列数。
  • 第二行包含 nnn 个空格分隔的整数，表示 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​ (0≤ai<2300 \le a_i < 2^{30}0≤ai​<230)。
  • 第三行包含 mmm 个空格分隔的整数，表示 b1,b2,…,bmb_1, b_2, \dots, b_mb1​,b2​,…,bm​ (0≤bi<2300 \le b_i < 2^{30}0≤bi​<230)。

保证所有测试用例中 nnn 的总和不超过 2×1052 \times 10^52×105，且 mmm 的总和不超过 2×1052 \times 10^52×105。
