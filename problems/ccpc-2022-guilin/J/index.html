题目描述

时间限制：4.0 秒；内存限制：512 MB。

Little relyt871 正在解决一个谜题。谜题的关键是一个包含 1…n1 \dots n1…n 的排列。排列中某些位置的值已经固定，relyt871 需要将数字填入剩余的位置。

此外，little relyt871 还收集了关于该排列的 mmm 个额外要求。设解为 p1,p2,…,pnp_1, p_2, \dots, p_np1​,p2​,…,pn​，每个线索是一个下标对 (ui,vi)(u_i, v_i)(ui​,vi​)，这意味着在解中必须满足 pui<pvip_{u_i} < p_{v_i}pui​​<pvi​​。

Little relyt871 想知道是否所有要求都能同时满足。请编写一个程序，在存在有效解时找出一个解。

输入的第一行包含测试用例的数量 TTT (1≤T≤20 0001 \le T \le 20\,0001≤T≤20000)。

对于每个测试用例：

  • 第一行包含两个整数 n,mn, mn,m (2≤n≤200 000,1≤m≤500 0002 \le n \le 200\,000, 1 \le m \le 500\,0002≤n≤200000,1≤m≤500000)。
  • 第二行包含 nnn 个整数 p1,p2,…,pnp_1, p_2, \dots, p_np1​,p2​,…,pn​ (0≤pi≤n0 \le p_i \le n0≤pi​≤n)。如果 1≤pi≤n1 \le p_i \le n1≤pi​≤n，则位置 iii 的值固定为 pip_ipi​，否则需要你确定位置 iii 的值。保证对于 1≤i<j≤n1 \le i < j \le n1≤i<j≤n，若 pi>0p_i > 0pi​>0 且 pj>0p_j > 0pj​>0，则 pi≠pjp_i \neq p_jpi​=pj​。
  • 接下来的 mmm 行，每行包含两个整数 ui,viu_i, v_iui​,vi​ (1≤ui,vi≤n1 \le u_i, v_i \le n1≤ui​,vi​≤n)，表示线索。保证线索本身不矛盾。形式上，不存在线索序列 (ui1,vi1),(ui2,vi2),…,(uik,vik)(u_{i_1}, v_{i_1}), (u_{i_2}, v_{i_2}), \dots, (u_{i_k}, v_{i_k})(ui1​​,vi1​​),(ui2​​,vi2​​),…,(uik​​,vik​​) 使得 vij=uij+1v_{i_j} = u_{i_{j+1}}vij​​=uij+1​​ (1≤j<k1 \le j < k1≤j<k) 且 vik=ui1v_{i_k} = u_{i_1}vik​​=ui1​​。

所有测试用例的 nnn 之和不超过 200 000200\,000200000，所有测试用例的 mmm 之和不超过 500 000500\,000500000。

对于每个测试用例：

  • 如果不存在有效解，输出一行 “-1”。
  • 否则，输出一行包含 nnn 个由空格分隔的整数，表示该解。如果存在多个解，输出任意一个即可。
