H.Hysteretic Racing

22-CCPC-桂林挑战题QOJ #6815

题面语言
完整题册

题目描述

时间限制：6.0 秒；内存限制：512 MB。

滞后赛车（Hysteretic Racing）通常是为了追求高速。然而，树懒们却喜欢滞后赛车。它们认为，慢一点可能更有利于展现赛车手的技巧，并且所有树懒都会以相同的速度行驶。获胜者是在整个旅程中驾驶技术最好的人。

图中展示了最贴切的形象：电影《疯狂动物城》中的树懒赛车手兼车管所职员“闪电”。不过，为了避免法律问题，我们使用了这个人工智能生成的树懒司机。

巨大的赛道由 nnn 个土壤网格 0,1,…,n−10, 1, \dots, n-10,1,…,n−1 组成，它们首尾相连形成一个圆环，其中网格 iii 的下一个网格是 (i+1)(modn)(i+1) \pmod n(i+1)(modn)。网格 iii 的难度是一个正整数 did_idi​，难度最低的网格（即难度为 111 的网格）被称为普通网格。通过网格 iii 的时间成本定义如下：如果树懒进入网格 iii 时的速度 vvv 高于 1di\frac{1}{d_i}di​1​（单位：普通网格/秒），则由于树懒的懒惰，速度会被调整为 1di\frac{1}{d_i}di​1​。此后，树懒通过该网格所需的时间将是普通网格的 did_idi​ 倍，即耗时 div\frac{d_i}{v}vdi​​ 秒。

有时，树懒会花钱请勤劳的人类来重建巨大的赛道。将会发生两种工作：

  • Plow（耕地）：在网格 l,(l+1)(modn),…,rl, (l+1) \pmod n, \dots, rl,(l+1)(modn),…,r 中，为每个网格增加特定的难度 Δ\DeltaΔ。
  • Ram（夯土）：在网格 l,(l+1)(modn),…,rl, (l+1) \pmod n, \dots, rl,(l+1)(modn),…,r 中，将每个网格的难度替换为特定的难度 d′d'd′。

为了开始一场赛车游戏，裁判会选择一个起始网格 sss 和游戏总时间 ttt 秒，游戏组织方式如下：

  • 树懒初始速度为 111。
  • 在游戏开始时刻，所有树懒开始进入网格 sss。
  • 通过一个网格后，树懒进入下一个网格，其中“下一个”的定义如上所述。
  • 游戏在 ttt 秒后结束。所有树懒会紧急刹车并停在那里。

树懒只能走得很慢，所以裁判会立即开始走向游戏的终点位置。现在，你也是受雇的人类之一，需要告诉裁判在游戏开始时该去哪里。

既然你不是树懒，你必须快速完成这项工作。

输入格式

第一行包含两个整数 n,qn, qn,q (2≤n,q≤2×1052 \le n, q \le 2 \times 10^52≤n,q≤2×105)，由空格分隔，分别表示巨大赛道的长度以及操作和查询的数量。

第二行包含 nnn 个整数，由空格分隔，第 iii 个数表示 di−1d_{i-1}di−1​，即第 iii 个网格的初始难度。

接下来的 qqq 行包含查询和操作。每一行必须属于以下三种类型之一：

  • P l r Δ：Plow，从第 lll 个网格到第 rrr 个网格，增加难度 Δ\DeltaΔ。
  • R l r d'：Ram，从第 lll 个网格到第 rrr 个网格，将难度替换为 d′d'd′。
  • Q s t：Query，查询从 sss (0≤s<n0 \le s < n0≤s<n) 开始且总时间为 ttt (0≤t≤2×10170 \le t \le 2 \times 10^{17}0≤t≤2×1017) 秒的游戏的终点位置。注意，两个网格边界处的位置被定义为“下一个”网格，这意味着如果树懒在离开第 iii 个网格进入下一个网格时恰好停止，则该位置被定义为网格 (i+1)(modn)(i+1) \pmod n(i+1)(modn)。

保证对于所有出现在 qqq 行中的 l,rl, rl,r，都有 0≤l,r<n0 \le l, r < n0≤l,r<n。我们精确定义区间 [l,r][l, r][l,r] 如下：

  • l≤rl \le rl≤r：{l,l+1,…,r}\{l, l+1, \dots, r\}{l,l+1,…,r}；
  • l>rl > rl>r：{l,l+1,…,n−1,0,1,…,r}\{l, l+1, \dots, n-1, 0, 1, \dots, r\}{l,l+1,…,n−1,0,1,…,r}。

同时保证输入中出现的所有难度，包括 di,Δ,d′d_i, \Delta, d'di​,Δ,d′，均为不超过 10610^6106 的正整数；每次操作后网格的难度均不超过 10610^6106。
