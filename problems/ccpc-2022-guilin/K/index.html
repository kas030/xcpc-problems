22-CCPC-桂林挑战题QOJ #6818

题目描述

时间限制：2.0 秒；内存限制：512 MB。

中国孩子或多或少都听说过“木桶理论”——木桶的容量不取决于最长的木板，而取决于最短的那块，如下图所示。

Minimum

老师和家长们倾向于用这个理论来强调全面发展、素质教育或集体主义的重要性。然而，Little Desprado2 和 Foolish Timsei 对此理论持不同意见。在他们看来，一个好的木桶不仅取决于容量，还取决于外观。

根据木桶理论，如果一个木桶由 nnn 块长度为正整数的木板 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​ 组成，那么木桶的容量为 min⁡i=1nai\min_{i=1}^n a_imini=1n​ai​。他们定义木桶的“丑陋度”为 a1⊕a2⊕⋯⊕ana_1 \oplus a_2 \oplus \dots \oplus a_na1​⊕a2​⊕⋯⊕an​，其中 ⊕\oplus⊕ 表示按位异或（XOR）。他们认为，当且仅当木桶的丑陋度小于其容量时，这个木桶是“好的”。

现在，Foolish Timsei 和 Little Desprado2 有一根长度为 mmm 的长木板，他们想将其切割成 nnn 块，组成一个“好的”木桶，且总长度保持不变。请帮他们找到一个合法的切割方案！

输入格式

第一行包含一个整数 TTT (1≤T≤1051 \le T \le 10^51≤T≤105)，表示测试用例的数量。

每个测试用例包含两个整数 nnn 和 mmm (1≤n≤105,n≤m≤1071 \le n \le 10^5, n \le m \le 10^71≤n≤105,n≤m≤107)，分别表示切割后的木板数量和初始木板的长度。

保证所有测试用例中 nnn 的总和不超过 3×1053 \times 10^53×105；所有测试用例中 mmm 的总和不超过 10710^7107。

输出格式

对于每个测试用例：

  • 如果存在切割方案，输出一行 “YES”，随后输出一行由空格分隔的 nnn 个整数 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​，表示 nnn 块木板的长度。如果存在多种方案，输出任意一种即可。
  • 否则，输出一行 “NO”。
