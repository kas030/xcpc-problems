D.Dark LaTeX vs. Light LaTeX

23-ICPC-沈阳金牌题QOJ #7780

题面语言
完整题册

题目描述

时间限制：2.0 秒；内存限制：512 MB。

在不久的将来，LaTeX 这个几十年来一直是学术界和出版界支柱的古老排版系统，演化出了两个衍生版本——“Dark LaTeX”和“Light LaTeX”。这些衍生版本主要从不同角度优化了外观，以适应无屏幕显示技术。

为了进行兼容性试验，LaTeX 实验室通过分析获得了两个仅包含小写英文字母的非空字符串——Dark LaTeX 字符串 S=s1s2…s∣S∣S = s_1s_2 \dots s_{|S|}S=s1​s2​…s∣S∣​ 和 Light LaTeX 字符串 T=t1t2…t∣T∣T = t_1t_2 \dots t_{|T|}T=t1​t2​…t∣T∣​，其中 ∣S∣|S|∣S∣ 表示 SSS 的长度，∣T∣|T|∣T∣ 表示 TTT 的长度。一个整数四元组 (p,q,u,v)(p, q, u, v)(p,q,u,v) 被认为是可转换的，当且仅当 1≤p≤q≤∣S∣1 \le p \le q \le |S|1≤p≤q≤∣S∣，1≤u≤v≤∣T∣1 \le u \le v \le |T|1≤u≤v≤∣T∣，且 spsp+1…sqtutu+1…tvs_p s_{p+1} \dots s_q t_u t_{u+1} \dots t_vsp​sp+1​…sq​tu​tu+1​…tv​ 是一个平方串。

你的任务是帮助实验室找出可转换四元组的数量。

回想一下，平方串是指一个长度为偶数且前半部分与后半部分完全相同的字符串。例如，“aaaa”和“abcabc”是平方串，而“aaa”和“abcabd”则不是。

输入格式

输入包含两行，第一行包含 Dark LaTeX 字符串 SSS，第二行包含 Light LaTeX 字符串 TTT。

保证 SSS 和 TTT 仅由小写英文字母组成，且它们的长度均不超过 5 0005\,0005000。

输出格式

输出一行一个整数，表示可转换四元组的数量。

样例

样例输入 1

abab
ab

样例输出 1

8

样例输入 2

abab
abaaab

样例输出 2

29

说明

在第一个样例中，可转换的四元组为 (1,1,1,1),(1,2,1,2),(1,3,2,2),(2,2,2,2),(2,4,1,1),(3,3,1,1),(3,4,1,2),(4,4,2,2)(1, 1, 1, 1), (1, 2, 1, 2), (1, 3, 2, 2), (2, 2, 2, 2), (2, 4, 1, 1), (3, 3, 1, 1), (3, 4, 1, 2), (4, 4, 2, 2)(1,1,1,1),(1,2,1,2),(1,3,2,2),(2,2,2,2),(2,4,1,1),(3,3,1,1),(3,4,1,2),(4,4,2,2)。
