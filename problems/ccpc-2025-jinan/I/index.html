25-CCPC-济南挑战题QOJ #15040

题目描述

时间限制：2.0 秒；内存限制：1024 MB。

一个由小写字母组成、长度为 kkk 的字符串 ttt 被称为 CCPC（Character-Character-Palindrome-Character，字符-字符-回文-字符）字符串，当且仅当它满足以下性质：

  • ttt 的长度至少为 4，即 k≥4k \ge 4k≥4；
  • ttt 的第一个字符、第二个字符和最后一个字符相等，即 t1=t2=tkt_1 = t_2 = t_kt1​=t2​=tk​；
  • ttt 的剩余部分是一个回文串，即 t3t4…tk−1t_3 t_4 \dots t_{k-1}t3​t4​…tk−1​ 是一个回文串。

例如，ccpc、ppap、zzzz 和 aabcddcba 都是 CCPC 字符串，而 jinan、aaa 和 oovoo 则不是。

字符串 sss 的子串可以用两个下标 1≤l≤r≤∣s∣1 \le l \le r \le |s|1≤l≤r≤∣s∣ 来表示，对应内容为 slsl+1…srs_l s_{l+1} \dots s_rsl​sl+1​…sr​。在本题中，两个子串被视为不同的，当且仅当所选的下标 l,rl, rl,r 不相同。给定一个仅包含小写字母的字符串 sss，首先计算其中 CCPC 子串的数量。然后将进行 nnn 次操作，每次操作会在 sss 的左侧或右侧插入一个小写字母。你需要确定每次插入后 CCPC 子串的数量。

输入格式

本题包含多组测试数据。输入的第一行包含一个整数 TTT（1≤T≤1001 \le T \le 1001≤T≤100），表示测试数据的组数。

对于每组测试数据：

第一行包含一个仅由小写字母组成的字符串 sss（4≤∣s∣≤5×1054 \le |s| \le 5 \times 10^54≤∣s∣≤5×105），表示字符串的初始内容。

下一行包含一个整数 nnn（1≤n≤5×1051 \le n \le 5 \times 10^51≤n≤5×105），表示操作的次数。

接下来的一行包含 nnn 个长度为 2 的字符串 c1,c2,…,cnc_1, c_2, \dots, c_nc1​,c2​,…,cn​，用空格隔开。这里 cic_ici​ 表示第 iii 次操作的内容：第一个字符为 L 表示在左侧插入，为 R 表示在右侧插入；第二个字符表示要插入的小写字母。

保证所有测试数据的 ∣s∣|s|∣s∣ 之和以及 nnn 之和均不超过 5×1055 \times 10^55×105。

输出格式

对于每组测试数据，输出一行，包含 n+1n + 1n+1 个整数。第一个整数表示初始状态下的答案，随后是 nnn 个整数，其中第 iii 个整数表示前 iii 次操作后的答案。

输出样例 1

说明

对于第二组测试数据，在所有操作完成后，字符串 sss 的内容为 cccccpcpccppcppc。其中的 CCPC 子串包括：s1…4=ccccs_{1\dots4} = \text{cccc}s1…4​=cccc，s1…5=cccccs_{1\dots5} = \text{ccccc}s1…5​=ccccc，s2…5=ccccs_{2\dots5} = \text{cccc}s2…5​=cccc，s3…10=cccpcpccs_{3\dots10} = \text{cccpcpcc}s3…10​=cccpcpcc，s4…7=ccpcs_{4\dots7} = \text{ccpc}s4…7​=ccpc，s4…9=ccpcpcs_{4\dots9} = \text{ccpcpc}s4…9​=ccpcpc，s9…13=ccppcs_{9\dots13} = \text{ccppc}s9…13​=ccppc，s9…16=ccppcppcs_{9\dots16} = \text{ccppcppc}s9…16​=ccppcppc，以及 s11…14=ppcps_{11\dots14} = \text{ppcp}s11…14​=ppcp。
