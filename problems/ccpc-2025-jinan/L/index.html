25-CCPC-济南铜牌题QOJ #15043

题面语言
完整题册

题目描述

时间限制：2.0 秒；内存限制：1024 MB。

小 J 正在为一项活动进行彩排。现在有 nnn 名学生排成一排，每人手里拿着一块写有数字的牌子。从左到右第 iii 名学生手里的牌子上的数字为 aia_iai​。牌子上的数字是 111 到 nnn 之间的互不相同的整数。

现在要进行一次“比较”活动彩排。该活动共进行 n−1n - 1n−1 轮。在每一轮中，最左边的两名学生会走上前，然后比较他们牌子上的数字。数字较大的学生将被选中，而数字较小的学生将回到队列的最右端。需要注意的是，被选中的学生不会回到队列中，且不参与后续轮次的比较。

小 J 想知道在不同的数字排列下，每一轮中谁会被选中。他将进行 mmm 次操作，每次操作为以下两种类型之一：

  • 选择两个位置 x,yx, yx,y 满足 1≤x<y≤n1 \le x < y \le n1≤x<y≤n，然后交换第 xxx 名和第 yyy 名学生手里的牌子；
  • 给定两个参数 l,rl, rl,r 满足 1≤l≤r<n1 \le l \le r < n1≤l≤r<n，模拟一次“比较”活动，并计算在第 lll 轮到第 rrr 轮之间被选中的学生牌子上的数字之和。模拟结束后，所有学生将回到他们原本的位置。

输入格式

输入的第一行包含两个整数 n,mn, mn,m (2≤n≤105,1≤m≤1052 \le n \le 10^5, 1 \le m \le 10^52≤n≤105,1≤m≤105)，分别表示学生的数量和操作的数量。

下一行包含 nnn 个整数 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​ (1≤ai≤n1 \le a_i \le n1≤ai​≤n)，表示每位学生手里牌子上的初始数字。保证所有的 aia_iai​ 互不相同。

接下来的 mmm 行，每行包含一个字符和两个整数，表示一次操作。

  • 如果输入格式为 C x y，表示交换第 xxx 名和第 yyy 名学生手里的牌子，保证 1≤x<y≤n1 \le x < y \le n1≤x<y≤n；
  • 如果输入格式为 A l r，表示模拟一次“比较”活动，并计算第 lll 轮到第 rrr 轮之间被选中的数字之和，保证 1≤l≤r<n1 \le l \le r < n1≤l≤r<n。

输出格式

对于每次模拟操作，在新的一行中输出一个整数，表示答案。

样例

输入样例 1

5 6
4 3 1 2 5
A 3 4
C 1 2
A 3 4
A 2 4
C 3 5
A 1 3

输出样例 1

8
8
10
12

说明

在第一次模拟操作中，学生手里的数字依次为 [4,3,1,2,5][4, 3, 1, 2, 5][4,3,1,2,5]。在四轮比较中，被选中的数字依次为 4,2,5,34, 2, 5, 34,2,5,3，因此第 333 轮到第 444 轮之间被选中的数字之和为 5+3=85 + 3 = 85+3=8。

在最后一次模拟操作中，学生手里的数字依次为 [3,4,5,2,1][3, 4, 5, 2, 1][3,4,5,2,1]。在四轮比较中，被选中的数字依次为 4,5,3,24, 5, 3, 24,5,3,2，因此第 111 轮到第 333 轮之间被选中的数字之和为 4+5+3=124 + 5 + 3 = 124+5+3=12。
