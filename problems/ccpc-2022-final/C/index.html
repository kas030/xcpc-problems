题目描述

时间限制：2 秒；内存限制：1024 MB。

Little Cyan Fish 有一棵包含 nnn 个顶点的树。每个顶点都被标记为 111 到 nnn。现在他想从每个顶点 xxx 开始进行深度优先搜索。DFS 序是深度优先搜索过程中访问节点的顺序。一个顶点在 DFS 序中出现在第 jjj (1≤j≤n1 \le j \le n1≤j≤n) 个位置，意味着它是在访问了其他 j−1j-1j−1 个顶点之后被访问的。由于节点的子节点可以以任意顺序遍历，因此可能存在多种不同的 DFS 序。以下伪代码描述了生成 DFS 序的方法。函数 generate(x) 返回从顶点 xxx 开始的 DFS 序：

procedure dfs(vertex x)
    Append x to the end of dfs_order
    for each son y of x do ▷ Sons can be iterated in arbitrary order.
        dfs(y) ▷ The order might be different in each iteration.
    end for
end procedure
procedure generate(x)
    Root the tree at vertex x
    Let dfs_order be a global variable
    dfs_order ← empty list
    dfs(x)
    return dfs_order
end procedure

令 DiD_iDi​ 为调用 generate(x) 后返回的数组。Little Cyan Fish 记下了所有 nnn 个序列 D1,D2,…,DnD_1, D_2, \dots, D_nD1​,D2​,…,Dn​。多年后，他已经记不清原始树的结构了。Little Cyan Fish 想知道如何利用这 nnn 个序列恢复出原始树。请帮助他！

输入格式

输入包含多组测试数据。第一行包含一个整数 TTT (1≤T≤1051 \le T \le 10^51≤T≤105)，表示测试数据的组数。

对于每组测试数据，第一行包含一个正整数 nnn (1≤n≤10001 \le n \le 10001≤n≤1000)，表示树的顶点数。

接下来的 nnn 行描述了原始树的 DFS 序。其中第 iii 行包含 nnn 个整数 Di,1,Di,2,…,Di,nD_{i,1}, D_{i,2}, \dots, D_{i,n}Di,1​,Di,2​,…,Di,n​，描述了一个 DFS 序。保证 Di,1=iD_{i,1} = iDi,1​=i 且 DiD_iDi​ 是该原始树的一个合法 DFS 序。

保证所有测试数据的 n2n^2n2 之和不超过 2×1062 \times 10^62×106。

输出格式

对于每组测试数据，你需要输出 n−1n-1n−1 行，描述你恢复出的树。在每一行中，输出两个整数 uiu_iui​ 和 viv_ivi​ (1≤ui,vi≤n1 \le u_i, v_i \le n1≤ui​,vi​≤n)，表示顶点 uiu_iui​ 和 viv_ivi​ 之间存在一条边。如果存在多种可能的解，你可以输出其中任意一个。保证至少存在一个解。
