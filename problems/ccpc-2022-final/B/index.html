题单/22-CCPC-总决赛/Problem B

B.Disjoint Set Union

22-CCPC-总决赛挑战题QOJ #6502

题面语言
完整题册

题目描述

时间限制：4 秒；内存限制：1024 MB。

最近，Little Cyan Fish 正在学习并查集（DSU）数据结构。这是一种强大的数据结构，允许你在图中添加边并测试图中两个顶点是否连通。

DSU 维护了一个由 nnn 个顶点组成的有根森林结构。每个顶点 xxx (1≤x≤n1 \le x \le n1≤x≤n) 都有一个唯一的父节点 f[x]f[x]f[x]。如果 x=f[x]x = f[x]x=f[x]，则 xxx 是其子树的根。最初，每个顶点构成一棵单独的根树。也就是说，对于所有 1≤x≤n1 \le x \le n1≤x≤n，都有 f[x]=xf[x] = xf[x]=x。

DSU 的基本接口包含以下两个操作：

  • find xxx：返回 xxx 所在树的根。
  • unite xxx yyy：令 x′←find(x)x' \leftarrow \text{find}(x)x′←find(x) 且 y′←find(y)y' \leftarrow \text{find}(y)y′←find(y)。如果 x′=y′x' = y'x′=y′，则什么都不做。否则，将 x′x'x′ 的父节点修改为 y′y'y′。

为了加速 unite 操作，Little Cyan Fish 使用了一种称为路径压缩（Path Compression）的优化：

  • 如果我们对某个顶点 xxx 调用 find(x)，我们将从 xxx 到根路径上的每个顶点的父节点直接设置为根。

以下伪代码描述了 DSU 的细节。

Algorithm 1 An implementation of DSU with Path Compression
1: procedure find(f, x)
2: if x = f[x] then
3: return x
4: end if
5: f[x] ← find(f, f[x])
6: return f[x]
7: end procedure
8: procedure unite(f, x, y)
9: x ← find(f, x)
10: y ← find(f, y)
11: if x ≠ y then
12: f[x] ← y
13: end if
14: end procedure

Little Cyan Fish 非常喜欢 DSU，所以他想玩一玩它。他得到了一个长度为 nnn 的数组 fff，其中最初 f[i]=if[i] = if[i]=i。然后，Little Cyan Fish 多次（可能为零次）执行了以下操作：

  • 选择一个整数 1≤x≤n1 \le x \le n1≤x≤n，执行 find(x)。
  • 选择两个整数 1≤x≤n1 \le x \le n1≤x≤n 和 1≤y≤n1 \le y \le n1≤y≤n，执行 unite(x, y)。

他会在所有操作完成后给你数组 fff。然而，你希望通过使用上述 DSU 操作将数组 fff 转换为另一个给定的数组 ggg。你想知道是否可以通过执行任何额外的操作，使得对于所有 1≤i≤n1 \le i \le n1≤i≤n，都有 f[i]=g[i]f[i] = g[i]f[i]=g[i]。

输入格式

输入包含多组测试数据。第一行包含一个整数 TTT (1≤T≤1051 \le T \le 10^51≤T≤105)，表示测试数据的组数。

对于每组测试数据，第一行包含一个正整数 nnn (3≤n≤10003 \le n \le 10003≤n≤1000)。

下一行包含 nnn 个整数 f1,f2,…,fnf_1, f_2, \dots, f_nf1​,f2​,…,fn​，表示 Little Cyan Fish 操作后的数组 fff。保证数组 fff 可以通过上述操作生成。

接下来一行包含 nnn 个整数 g1,g2,…,gng_1, g_2, \dots, g_ng1​,g2​,…,gn​，表示你想要将数组 fff 转换成的数组 ggg。

保证所有测试数据的 n2n^2n2 之和不超过 5×1065 \times 10^65×106。

输出格式

对于每组测试数据，如果无法将数组 fff 转换为数组 ggg，则输出一行 NO。

否则，输出的第一行应包含一个单词 YES。

输出的下一行应包含一个整数 mmm (0≤m≤2⋅n20 \le m \le 2 \cdot n^20≤m≤2⋅n2)，表示你使用的操作次数。

接下来的 mmm 行描述你使用的操作。每个操作按以下格式描述：

  • 1 x：调用 find(x)。
  • 2 x y：调用 unite(x, y)。

如果有多种方案，你可以输出其中任意一种。可以证明，如果存在任何解，则存在一个不超过 2⋅n22 \cdot n^22⋅n2 次操作的方案。
