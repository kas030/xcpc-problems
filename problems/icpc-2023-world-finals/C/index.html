C.Three Kinds of Dice

23-ICPC-世界总决赛铜牌题QOJ #8676

题面语言
完整题册

题目描述

时间限制：1 秒；内存限制：2048 MB。

看看它们是怎么滚动的！根据一个著名的故事，沃伦·巴菲特（Warren Buffett）曾经向比尔·盖茨（Bill Gates）发起了一场简单的掷骰子游戏挑战。他有三颗骰子；第一个玩家可以检查它们并从中选择一颗。第二个玩家随后从剩下的骰子中选择一颗，然后两名玩家掷出各自的骰子进行对决，目标是掷出更大的数字。沃伦提出让比尔先选，但这让比尔产生了怀疑，于是他选择后选。事实证明这是一个明智的选择：这些是传递性失效骰子（intransitive dice）。第一颗骰子在与第二颗对决时占优势，第二颗在与第三颗对决时占优势，但第一颗在与第三颗对决时却不占优势！

为了形式化定义：将“骰子”定义为具有至少一个面的任何形状，使得每个面都显示一个正整数。当掷骰子时，其中一个面会被均匀随机地选中。当两颗骰子对决时，显示数字较大的一面所在的骰子获得 1 分；如果两个数字相等，则每颗骰子各获得 12\frac{1}{2}21​ 分。对于骰子 DDD 和 D′D'D′，定义 score(D,D′)score(D, D')score(D,D′) 为 DDD 在单次对决中从 D′D'D′ 处获得的期望得分。如果 score(D,D′)>12score(D, D') > \frac{1}{2}score(D,D′)>21​，我们称 DDD 对 D′D'D′ 占优势；如果 score(D,D′)=12score(D, D') = \frac{1}{2}score(D,D′)=21​，则两颗骰子平局。例如，如果 DDD 是样例输入中的第一颗骰子，D′D'D′ 是第二颗，则 score(D,D′)=49score(D, D') = \frac{4}{9}score(D,D′)=94​ 且 score(D′,D)=59score(D', D) = \frac{5}{9}score(D′,D)=95​，因此 D′D'D′ 对 DDD 占优势。

给定两颗骰子 D1D_1D1​ 和 D2D_2D2​，使得 D1D_1D1​ 对 D2D_2D2​ 占优势，你想要找到第三颗骰子 D3D_3D3​，使其与前两颗组成一个传递性失效的三元组。在所有对 D1D_1D1​ 占优势或与 D1D_1D1​ 平局的 D3D_3D3​ 中，计算 score(D3,D2)score(D_3, D_2)score(D3​,D2​) 的最小值。如果该值小于 12\frac{1}{2}21​，你就可以组成一个传递性失效的三元组！类似地，在所有 D2D_2D2​ 对其占优势或与之平局的 D3D_3D3​ 中，计算 score(D3,D1)score(D_3, D_1)score(D3​,D1​) 的最大值。

输入格式

输入包含两行，每行描述一颗骰子。其中一颗骰子（第一颗或第二颗）对另一颗占优势。占优势的骰子为 D1D_1D1​，另一颗为 D2D_2D2​。

每行的第一个整数给出 nnn (1≤n≤1051 \le n \le 10^51≤n≤105)，即骰子的面数。随后是 nnn 个整数 fif_ifi​ (1≤fi≤1091 \le f_i \le 10^91≤fi​≤109，对于每个 1≤i≤n1 \le i \le n1≤i≤n)，给出了每个面上的整数。

输出格式

输出一行，包含在上述条件下 score(D3,D2)score(D_3, D_2)score(D3​,D2​) 的最小值和 score(D3,D1)score(D_3, D_1)score(D3​,D1​) 的最大值。这两个分数不需要使用相同的骰子 D3D_3D3​。你的答案绝对误差应不超过 10−610^{-6}10−6。
