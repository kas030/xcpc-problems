题目描述

时间限制：1 秒；内存限制：1024 MB。

你和你的两名队友正在参加一场编程比赛，但由于期末考试，你们都必须提前离开。你们每个人都有一个特定的离开时间 ℓi\ell_iℓi​（比赛开始后你必须离开的分钟数）。赛后，你们复盘了题解，并意识到每道题都完美适合你们中的某一个人：第 iii 题最适合由人员 pip_ipi​ 来解决，他可以在 cic_ici​ 分钟内完成，且不会有任何错误提交。不幸的是，由于考试的压力，你们在原本的比赛中表现不佳。

在梦中，你看到了冠军队伍的直播：他们解决了所有 nnn 道题，总罚时为 ttt。当你醒来时，你发现自己重生到了比赛当天的早上。现在，凭借对所有题目细节和冠军表现的完美记忆，你想确定这次是否有办法击败他们。

比赛规则如下：

  • 只有一台电脑可用，因此题目必须按顺序依次解决（一道接一道）。
  • 每道题 iii 必须分配给人员 pip_ipi​，且他必须在其离开时间 ℓpi\ell_{p_i}ℓpi​​ 之前开始解答。
  • 如果人员 pip_ipi​ 在时间 sss 开始解答第 iii 题，他必须在 s+ci≤ℓpis + c_i \le \ell_{p_i}s+ci​≤ℓpi​​ 之前完成。
  • 总罚时是所有已解决题目的完成时间之和。

给定 nnn、ttt 以及每道题的参数 pip_ipi​ 和 cic_ici​，请判断是否存在一种做题顺序，使得：

  • 所有 nnn 道题都被解决。
  • 总罚时严格小于 ttt。

如果存在这样的安排，输出 YES；否则，输出 NO。

输入格式

第一行包含一个整数 qqq (1≤q≤1051 \le q \le 10^51≤q≤105)，表示测试用例的数量。对于每个测试用例：

第一行包含四个整数：nnn、ℓ1\ell_1ℓ1​、ℓ2\ell_2ℓ2​ 和 ℓ3\ell_3ℓ3​ (1≤n≤1051 \le n \le 10^51≤n≤105, 1≤ℓ1,ℓ2,ℓ3≤3⋅1071 \le \ell_1, \ell_2, \ell_3 \le 3 \cdot 10^71≤ℓ1​,ℓ2​,ℓ3​≤3⋅107)，分别表示题目的数量以及三名队友的离开时间（比赛开始后的分钟数）。

接下来的 nnn 行，每行包含两个整数 pip_ipi​ 和 cic_ici​ (1≤pi≤31 \le p_i \le 31≤pi​≤3, 1≤ci≤3001 \le c_i \le 3001≤ci​≤300)，其中 pip_ipi​ 表示第 iii 题的指定队友，cic_ici​ 表示他完成该题所需的时间（分钟）。

最后一行包含一个整数 ttt (1≤t≤10131 \le t \le 10^{13}1≤t≤1013)，表示冠军队伍的总罚时。

所有测试用例中 nnn 的总和不超过 10510^5105。

输出格式

对于每个测试用例，如果存在满足限制条件的做题顺序（所有题目都被解决，且总罚时严格小于 ttt），输出 YES；否则，输出 NO。
