L.Tree Distance

题目描述

时间限制：4 秒；内存限制：512 MB。

给定一棵具有 nnn 个顶点 1,2,…,n1, 2, \dots, n1,2,…,n 的无根加权树 TTT。请回答一些查询。

我们定义 dist(i,j)\text{dist}(i, j)dist(i,j) 为树 TTT 中顶点 iii 和顶点 jjj 之间的距离。

对于每个查询，给定两个整数 l,rl, rl,r。请回答以下值：

min⁡l≤i<j≤r(dist(i,j))\min_{l \le i < j \le r} (\text{dist}(i, j))l≤i<j≤rmin​(dist(i,j))

输入格式

第一行包含一个整数 nnn (1≤n≤2×1051 \le n \le 2 \times 10^51≤n≤2×105)，表示树的顶点数。

接下来的 n−1n - 1n−1 行，每行描述树的一条边。第 iii 条边由三个整数 ai,bi,wia_i, b_i, w_iai​,bi​,wi​ (1≤ai,bi≤n,1≤wi≤1091 \le a_i, b_i \le n, 1 \le w_i \le 10^91≤ai​,bi​≤n,1≤wi​≤109) 表示，分别为其连接的顶点标签及其权重。

随后一行包含一个整数 qqq (1≤q≤1061 \le q \le 10^61≤q≤106)，表示查询次数。

接下来的 qqq 行，每行包含两个整数 l,rl, rl,r (1≤l≤r≤n1 \le l \le r \le n1≤l≤r≤n)，描述一个查询。

保证给定的边构成一棵树。

输出格式

对于每个查询，输出一行答案。如果不存在满足 1≤i<j≤r1 \le i < j \le r1≤i<j≤r 的 i,ji, ji,j，则答案为 −1-1−1。
