22-ICPC-济南铜牌题QOJ #5140

题面语言
完整题册

题目描述

时间限制：2 秒；内存限制：512 MB。

在两千年前的秦朝，曾举办过一场 ICPC 竞赛。比赛共有 mmm 道题目和 nnn 支队伍。历史记录中仅记载了每支队伍解出的题目数量以及他们使用的总时间。这些被称为队伍的最终结果。我们不知道他们具体解出了哪些题目，也不知道他们的提交时间。

最近，我们似乎有了一个发现。我们找到了队伍的冻结记分牌。从一支队伍的冻结记分牌中，我们可以知道他们在整个比赛期间的提交情况，但不知道最后一小时内提交的判决结果。此外，有人发现对于某些队伍，他们的冻结记分牌可能与历史记录中的最终结果相矛盾。

给定各队的最终结果和冻结记分牌，请为每支队伍构建一个既符合其最终结果又符合其冻结记分牌的最终记分牌。

根据比赛期间的提交情况，我们可以按如下方式计算最终记分牌和最终结果：

对于固定的队伍 iii，其最终记分牌是一个包含 mmm 个元素的数组，其中第 jjj 个元素显示了队伍 iii 在题目 jjj 上的相关信息。

  • 如果队伍 iii 没有提交过题目 jjj，则该单元格应为一个字符 “.”（不含引号）。
  • 如果队伍 iii 对题目 jjj 提交了 xxx 次且没有一次通过，则该单元格应包含 −x- x−x。
  • 否则，考虑队伍 iii 对题目 jjj 的所有提交。每次提交都有一个提交时间。假设最早的一次通过提交是第 xxx 次。那么该单元格应包含 +x/y+ x/y+x/y，其中 yyy (0≤y≤2990 \le y \le 2990≤y≤299) 是第 xxx 次提交的提交时间。yyy 是表示提交时间（以分钟为单位）的整数。

注意，在最终记分牌中，我们不关心第一次通过之后的提交。两名或多名选手的提交可能发生在同一分钟。

队伍的最终结果由其最终记分牌计算得出。对于每支队伍，我们可以计算其解出的题目数量。该数量等于队伍最终记分牌中 “+” 的数量。

我们还可以计算其总时间。如果队伍 iii 在第 yyy 分钟解出了题目 jjj，且之前有 x−1x-1x−1 次未通过的提交（换句话说，最终记分牌中第 iii 行第 jjj 个单元格为 +x/y+ x/y+x/y），则题目 jjj 为队伍 iii 贡献了 20(x−1)+y20(x - 1) + y20(x−1)+y 的时间。如果队伍 iii 没有解出题目 jjj，则无论队伍 iii 是否提交过题目 jjj，题目 jjj 对队伍 iii 的贡献均为 0。队伍 iii 的总时间是每道题目贡献之和。

冻结记分牌的规则将在输入部分介绍。我们将区分最后一小时内的提交和其他提交。如果提交时间在 240 到 299 分钟之间，则该提交属于最后一小时。

输入格式

第一行包含两个整数 n,mn, mn,m (1≤n≤1000,1≤m≤131 \le n \le 1000, 1 \le m \le 131≤n≤1000,1≤m≤13)，分别表示参赛队伍数量和题目数量。

接下来有 nnn 个数据块，描述每支队伍的最终结果和冻结记分牌。

第 iii 个数据块代表队伍 iii。在该数据块中，第一行包含两个整数 ai,bia_i, b_iai​,bi​ (0≤ai≤m,0≤bi≤1050 \le a_i \le m, 0 \le b_i \le 10^50≤ai​≤m,0≤bi​≤105)，分别表示队伍 iii 在整个比赛期间解出的题目数量和解出 aia_iai​ 道题目的总时间。这两个数字代表了比赛的最终结果。接下来的 mmm 行描述了队伍 iii 在冻结记分牌中的状态。对于每个 1≤j≤m1 \le j \le m1≤j≤m：

  • 如果第 jjj 行是 +x/y+ x/y+x/y (1≤x≤100,0≤y≤2391 \le x \le 100, 0 \le y \le 2391≤x≤100,0≤y≤239)，表示队伍 iii 在第 yyy 分钟解出了题目 jjj，且通过的提交是他们的第 xxx 次提交。
  • 如果第 jjj 行是 ?xy? x y?xy (1≤x≤y≤1001 \le x \le y \le 1001≤x≤y≤100)，表示队伍 iii 在前四个小时内没有解出题目 jjj。队伍 iii 对题目 jjj 总共提交了 yyy 次，其中有 xxx 次提交是在最后一小时内进行的。注意，最后一小时内发生在通过提交之后的提交会计入冻结记分牌，但不会计入最终记分牌。
  • 如果第 jjj 行是 −x- x−x，表示队伍 iii 在前四个小时内没有解出题目 jjj。队伍 iii 在最后一小时之前对题目 jjj 提交了 xxx (1≤x≤1001 \le x \le 1001≤x≤100) 次，且在最后一小时内没有提交题目 jjj。
  • 如果第 jjj 行是单个字符 “.”（不含引号），表示队伍 iii 完全没有提交过题目 jjj。

输出格式

对于每支队伍 iii，如果其最终结果与冻结记分牌矛盾，则输出一行 No。否则，第一行输出 Yes，随后输出 mmm 行。第 jjj 行应包含：

  • +x/y+ x/y+x/y (1≤x≤100,0≤y≤2991 \le x \le 100, 0 \le y \le 2991≤x≤100,0≤y≤299)，如果队伍 iii 对题目 jjj 的第 xxx 次提交通过，且发生在比赛的第 yyy 分钟。队伍 iii 对题目 jjj 在第 xxx 次提交之前的所有提交均未通过。请不要在斜杠 “/” 前后输出多余空格。
  • −x- x−x (1≤x≤1001 \le x \le 1001≤x≤100)，如果队伍 iii 对题目 jjj 提交了 xxx 次且没有一次通过。
  • ...，如果队伍 iii 完全没有提交过题目 jjj。

请注意，在输入和输出中，每个 ???, +++, 和 −-− 后面总是跟有一个空格。
