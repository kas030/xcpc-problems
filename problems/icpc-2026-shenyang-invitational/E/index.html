E.时空回溯

26-ICPC-沈阳-邀铜牌题QOJ #19017

题目描述

时间限制：1 秒；内存限制：1024 MB。

在某场 ICPC 邀请赛，某支强队花费 000 分钟便阅读完了所有的 NNN 道题目。凭借丰富的比赛经验，他们瞬间想到了所有思路并且准确预估出了完成每道题所需要的时间，完成第 iii 道题需要花费 TiT_iTi​ 分钟。

在比赛开始 000 分钟的时候，这只队伍开始编写所有题目。比赛罚时规则如下：如果你在第 ttt 分钟完成了一道题，那么总罚时会增加 ttt。

此时，这支队伍突然获得了一张 时空回溯卡。通过合理使用这张卡片，他们也许能够逆转自己手速不足的劣势。卡片的使用规则如下：

  • 卡片最多只能使用一次。你只能在比赛开始时（第 000 分钟）或恰好完成某一道题后的时刻使用它（也可以选择整场比赛都不使用）。
  • 使用卡片后，当前比赛时间会立即减半。也就是说，如果你在第 XXX 分钟使用卡片，那么当前时间会瞬间回退到 X/2X/2X/2 分钟。
  • 已经完成的题目状态不会改变，它们此前产生的罚时也会被保留。但之后完成的题目，将基于这个新的时间继续计算完成时刻与罚时。

队伍可以自由决定完成这 NNN 道题目的顺序，也可以自由决定在完成哪一道题之后使用卡片（假设切换题目与使用卡片均不消耗额外时间）。

比赛时间是无限的，无论如何这支队伍都可以写完所有的题目。请你计算，在最优策略下，完成所有题目的最小总罚时是多少。

Input

第一行包含一个正整数 NNN (1≤N≤20001 \le N \le 20001≤N≤2000)，表示还剩下的题目数量。

第二行包含 NNN 个正整数 T1,T2,…,TNT_1, T_2, \dots, T_NT1​,T2​,…,TN​ (1≤Ti≤10001 \le T_i \le 10001≤Ti​≤1000)，分别表示完成每道题目所需的时间（单位：分钟）。

Output

输出一个浮点数，表示能够达到的最小总罚时。

注意：结果请保留恰好一位小数。

Examples

Input 1

3
10 20 30

Output 1

85.0

Note

对于第一个样例：共有 333 道题。最优策略是按 101010 分钟、202020 分钟、303030 分钟的顺序做题，并在刚好做完前两道题后使用卡片。

  1. 第 111 题用时 101010，在第 101010 分钟完成，罚时增加 101010。
  2. 第 222 题用时 202020，在第 303030 分钟完成，罚时增加 303030。此时总耗时为 303030 分钟。
  3. 使用时空回溯卡，当前时间瞬间变成 30/2=1530/2=1530/2=15 分钟。
  4. 第 333 题用时 303030，在第 15+30=4515+30=4515+30=45 分钟完成，罚时增加 454545。

总罚时为 10+30+45=85.010+30+45=85.010+30+45=85.0。
