C.魔法审判

26-ICPC-沈阳-邀挑战题QOJ #19015

题目描述

时间限制：2 秒；内存限制：1024 MB。

一觉醒来，mic 陷入了一场特殊的魔法审判。

初始时有 nnn 个人，编号为 111 至 nnn。编号 iii 的人有一个非负整数可疑度 aia_iai​。mic 的编号为 sss（1≤s≤n1 \le s \le n1≤s≤n）。

另外有 mmm 条证据，第 jjj 条证据 (xj,yj,zj)(x_j, y_j, z_j)(xj​,yj​,zj​) 表示：该证据由编号为 xjx_jxj​ 的人掌握，如果被使用，会使编号为 yjy_jyj​ 的人的可疑度增加 zjz_jzj​（zjz_jzj​ 为非负整数）。

一次审判的流程如下：

  1. 选择证据：当前仍存活的所有人，各自独立地选择至多一条自己掌握的证据，也可以选择不使用任何证据。
  2. 增加可疑度：对于每个被选择的证据 jjj，如果此时编号 yjy_jyj​ 的人仍然存活，则将编号 yjy_jyj​ 的人的可疑度增加 zjz_jzj​；如果 yjy_jyj​ 已经死亡（已被处刑），则该证据无效（不产生任何效果）。
  3. 统计并处刑：计算此时每个人的总可疑度，即 初始可疑度 aia_iai​ 加上本次审判中所有针对 iii 的增加量之和。将总可疑度最高的人送去处刑；如果有并列最高，则选择其中编号较大的人处刑。被处刑的人将不再参与后续的任何审判。

上述审判将连续进行 n−1n-1n−1 次，每次处刑一人，直到只剩下一人。

注意：同一条证据可以在不同审判中被重复使用；每次审判的可疑度统计都是独立的：过往审判中增加的可疑度不会累积，每次审判均以初始可疑度 aia_iai​ 为基础重新开始。

mic 想知道：在万千世界线中，是否存在一系列的证据使用安排（即每次审判中每个存活者可以选择任意一条自己掌握的证据或不选，不必遵循任何理性原则），使得 mic 从未被处刑，并最终存活到最后？

Input

第一行一个整数 ttt（1≤t≤1051 \le t \le 10^51≤t≤105），表示测试数据组数。

对于每组测试数据：

第一行三个整数 n,m,sn, m, sn,m,s（1≤n≤1051 \le n \le 10^51≤n≤105，0≤m≤3×1050 \le m \le 3\times 10^50≤m≤3×105，1≤s≤n1 \le s \le n1≤s≤n）。

第二行 nnn 个整数 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​（0≤ai≤1090 \le a_i \le 10^90≤ai​≤109）。

接下来 mmm 行，每行三个整数 xj,yj,zjx_j, y_j, z_jxj​,yj​,zj​（1≤xj,yj≤n1 \le x_j, y_j \le n1≤xj​,yj​≤n，0≤zj≤1090 \le z_j \le 10^90≤zj​≤109）。

保证单个测试点内所有测试数据的 nnn 之和不超过 10510^5105，mmm 之和不超过 3×1053\times 10^53×105。

Output

对于每组测试数据，输出一行：若存在满足要求的安排，输出 YES，否则输出 NO。
