题单/26-ICPC-沈阳-邀/Problem L

L.渐隐的记忆

26-ICPC-沈阳-邀签到题QOJ #19024

题目描述

时间限制：1 秒；内存限制：1024 MB。

小明有一个电子保险箱，其解锁密码是一个长度为 NNN 的字符串 SSS。随着时间的推移，小明的记忆开始衰退，他已经记不清确切的密码了。

为了找回密码，他先后尝试解锁了 MMM 次。在第 iii 次尝试（1≤i≤M1 \le i \le M1≤i≤M）中，由于短暂的记忆混乱，他记错了密码中一段连续的子串 [Li,Ri][L_i, R_i][Li​,Ri​]（1≤Li≤Ri≤N1 \le L_i \le R_i \le N1≤Li​≤Ri​≤N），并输入了修改后的字符串 AiA_iAi​。而在区间 [Li,Ri][L_i, R_i][Li​,Ri​] 之外的所有位置，他输入的字符都与原密码 SSS 完全一致。

已知小明的记忆混淆并不频繁：对于密码的任意字符位置 kkk（1≤k≤N1 \le k \le N1≤k≤N），该位置落在记错区间 [Li,Ri][L_i, R_i][Li​,Ri​] 内的总次数严格少于总尝试次数 MMM 的一半。

现在给出小明 MMM 次尝试输入的密码记录，请你帮助他还原出最初的真实密码 SSS。

输入格式

第一行包含两个整数 NNN 和 MMM（1≤N≤10001 \le N \le 10001≤N≤1000，3≤M≤9993 \le M \le 9993≤M≤999），分别表示密码的长度和尝试记录的次数。保证 MMM 为奇数。

接下来的 MMM 行，每行包含一个长度为 NNN 的字符串 AiA_iAi​，表示小明在第 iii 次尝试中输入的密码。字符串仅由小写英文字母（'a'—'z'）组成。

数据保证存在唯一合法的原密码 SSS 满足上述所有条件。

输出格式

输出一行包含一个长度为 NNN 的字符串，表示还原出的真实密码 SSS。

样例

输入格式 1

6 5
secret
sexret
sexxet
secret
secxxt

输出格式 1

secret

输入格式 2

5 3
abcde
axcde
abxde

输出格式 2

abcde

说明

在第一个样例中，密码长度 N=6N = 6N=6，尝试次数 M=5M = 5M=5：

  • 第 1,2,5,61, 2, 5, 61,2,5,6 个位置的字符在所有 555 次尝试中都被准确记起。
  • 第 333 个位置（正确字符为 c）在第 2,32, 32,3 次尝试中被记错。
  • 第 444 个位置（正确字符为 r）在第 3,53, 53,5 次尝试中被记错。
  • 第 555 个位置（正确字符为 e）在第 555 次尝试中被记错。
