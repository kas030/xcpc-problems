F.等距矩阵

26-ICPC-沈阳-邀签到题QOJ #19018

题目描述

时间限制：2 秒；内存限制：1024 MB。

对于一个 n×nn \times nn×n 的矩阵，我们需要将 000 到 n2−1n^2-1n2−1 这 n2n^2n2 个互不相同的整数填入其中，使得矩阵中的每个元素恰好出现一次。

定义从左上角 (1,1)(1, 1)(1,1) 出发到右下角 (n,n)(n, n)(n,n) 的一条路径，每一步可以移动到相邻的位置。路径的长度定义为路径上所有经过格子的元素之和。

根据允许的移动方向，分为两种路径：

  • 四连通路径：每一步只能向上、下、左、右四个方向移动（不允许斜向移动）。
  • 八连通路径：每一步允许向上、下、左、右以及四个对角线方向（左上、右上、左下、右下）移动。

记 L4L_4L4​ 为所有四连通路径中长度的最小值，L8L_8L8​ 为所有八连通路径中长度的最小值。

由于八连通路径的移动方式更灵活，显然有 L8≤L4L_8 \le L_4L8​≤L4​。现在，请你构造一个满足条件的 n×nn \times nn×n 矩阵，使得四连通最短路等于八连通最短路，即 L4=L8L_4 = L_8L4​=L8​。

Input

第一行输入一个正整数 ttt (1≤t≤50)(1 \le t \le 50)(1≤t≤50)，表示数据组数。

接下来 ttt 行，每行输入一个正整数 nnn (1≤n≤2000)(1 \le n \le 2000)(1≤n≤2000)，表示需要构造的矩阵的大小。

保证所有测试数据中 nnn 的总和不超过 200020002000。

Output

对于每组测试数据，输出 nnn 行，每行 nnn 个整数，表示你构造的满足条件的矩阵。同一行内的整数之间用空格隔开。

如果有多种合法的构造方案，输出任意一种即可。

Examples

Input 1

2
1
2

Output 1

0 
1 0 
3 2

Note

在第二组样例中，一条四连通最短路为 (1,1)→(1,2)→(2,2)(1,1)\to (1,2)\to (2,2)(1,1)→(1,2)→(2,2)，最短路为 1+0+2=31+0+2=31+0+2=3。一条八连通最短路为 (1,1)→(2,2)(1,1)\to (2,2)(1,1)→(2,2)，最短路为 1+2=31+2=31+2=3。
