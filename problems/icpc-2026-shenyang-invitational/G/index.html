G.三角形

26-ICPC-沈阳-邀挑战题QOJ #19019

题目描述

时间限制：1 秒；内存限制：1024 MB。

宁宁有一个正 nnn 边形 A1A2⋯AnA_1A_2 \cdots A_nA1​A2​⋯An​，每条边都染有红、绿、蓝三种颜色中的一种，每个顶点也都染有红、绿、蓝三种颜色中的一种。

现在希望用这 nnn 个顶点连接出 n−3n - 3n−3 条线段，使得这 n−3n - 3n−3 条线段只在端点处相交，并且将正 nnn 边形分割出 n−2n - 2n−2 个三角形。这 n−3n - 3n−3 条线段也染有红、绿、蓝三种颜色中的一种，并且对于每个分割出的 n−2n - 2n−2 个三角形，三边的颜色要么两两相同，要么两两不同，且三角形三个顶点的颜色两两不同。

请你给出一种满足要求的连接方案，或者指出方案不存在。

Input

本题包含多组测试数据。

第一行一个整数 TTT (1≤T≤105)(1 \le T \le 10^5)(1≤T≤105)，表示数据组数。

对于每组数据：

第一行一个正整数 nnn (1≤n≤2×105)(1 \le n \le 2 \times 10^5)(1≤n≤2×105)，表示正 nnn 边形。

第二行一个长度为 nnn 且只包含 R、G、B 的字符串，第 iii 个字符表示顶点 AiA_iAi​ 的颜色。其中 R、G、B 分别表示红色、绿色、蓝色。

第三行一个长度为 nnn 且只包含 R、G、B 的字符串，第 iii 个字符表示边 AiAi+1A_iA_{i + 1}Ai​Ai+1​ 的颜色（An+1=A1A_{n + 1} = A_1An+1​=A1​）。其中 R、G、B 的含义同上。

保证每组数据的 nnn 的和不超过 10610^6106。

Output

对于每组数据：

第一行一个字符串，表示方案是否存在。若存在输出 Yes，不存在输出 No。

若方案存在，则接下来 n−3n - 3n−3 行，每行两个整数和一个字符 u,v,cu, v, cu,v,c，表示连接 AuAvA_uA_vAu​Av​ 并将此边染为颜色 ccc，其中 ccc 只能是 R、G、B 中的一个，分别表示红色、绿色、蓝色。你需要保证 1≤u,v≤n1 \le u, v \le n1≤u,v≤n 且 u≠vu \neq vu=v。且这 n−3n - 3n−3 条线段只在端点处相交。
