题目描述

时间限制：1.0 秒；内存限制：512 MB。

给定一个大小为 n×nn \times nn×n 的非负整数矩阵 AAA。对于一棵包含 nnn 个节点（编号为 111 到 nnn）的树，当且仅当满足以下条件时，我们称其为一棵 holly 树：

  • 对于任意一对节点 uuu 和 vvv（1≤u,v≤n1 \le u, v \le n1≤u,v≤n），Au,vA_{u,v}Au,v​ 等于该树中从 uuu 到 vvv 的简单路径上所有节点编号的按位异或和。

你的任务是构造一棵 holly 树。保证这样的 holly 树总是存在。

输入格式

输入的第一行包含一个整数 nnn（2≤n≤20002 \le n \le 20002≤n≤2000），表示矩阵 AAA 的大小。

接下来的 nnn 行描述矩阵 AAA。第 iii 行包含 n−i+1n - i + 1n−i+1 个整数 Ai,i,Ai,i+1,…,Ai,nA_{i,i}, A_{i,i+1}, \dots, A_{i,n}Ai,i​,Ai,i+1​,…,Ai,n​（0≤Ai,j<2110 \le A_{i,j} < 2^{11}0≤Ai,j​<211）。注意，对于所有 1≤i,j≤n1 \le i, j \le n1≤i,j≤n，均满足 Ai,j=Aj,iA_{i,j} = A_{j,i}Ai,j​=Aj,i​。

保证这样的 holly 树总是存在。

输出格式

输出 n−1n - 1n−1 行，每行包含两个整数 uuu 和 vvv（1≤u,v≤n1 \le u, v \le n1≤u,v≤n），表示 holly 树的一条边。
