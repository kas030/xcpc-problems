M.Mystique as Iris

25-ICPC-西安金牌题QOJ #14693

题面语言
完整题册

题目描述

时间限制：1.0 秒；内存限制：512 MB。

对一个由正整数组成的数组 xxx 进行以下两个步骤，称为一次操作：

  1. 选择 xxx 中任意两个相邻的元素，将其中一个减少 1，并将另一个设为 0。
  2. 从 xxx 中移除所有的 0。

我们称 xxx 是神秘的（mystic），当且仅当它可以在有限次（可能为零次）操作后被转化为一个空序列。

给你一个由 nnn 个整数组成的数组 aaa，以及一个整数 mmm。aaa 中的每个元素要么是 111 到 mmm 之间的整数，要么是 −1-1−1。你的任务是将 aaa 中所有出现的 −1-1−1 替换为 111 到 mmm 之间的任意整数。

求在替换后可以得到的不同神秘数组 aaa 的数量。由于答案可能非常大，请将其对 109+710^9 + 7109+7 取模后输出。

输入格式

输入的第一行包含两个整数 nnn 和 mmm（2≤n≤1062 \le n \le 10^62≤n≤106，1≤m≤1081 \le m \le 10^81≤m≤108）。

输入的第二行包含 nnn 个整数 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​（1≤ai≤m1 \le a_i \le m1≤ai​≤m 或 ai=−1a_i = -1ai​=−1）。

输出格式

输出一个整数，表示可以得到的不同神秘序列 aaa 的数量，模 109+710^9 + 7109+7 的结果。

样例

输入样例 1

2 2
-1 -1

输出样例 1

3

输入样例 2

6 10
-1 -1 -1 -1 1 7

输出样例 2

9125

说明

在第一个样例中，数组 aaa 为 [−1,−1][-1, -1][−1,−1]。通过替换两个 −1-1−1，一种可能的结果是 [1,2][1, 2][1,2]。在这种情况下，我们选择两个相邻的数：将第一个数减少 1，并将第二个数设为 0，得到 [0,0][0, 0][0,0]。移除所有 0 后，序列变为空。因此，[1,2][1, 2][1,2] 是一个神秘序列。

类似地，如果我们用 [1,1][1, 1][1,1] 或 [2,1][2, 1][2,1] 替换 −1-1−1，这两个序列也都可以被化为空。因此，不同的神秘序列总数为 3。
