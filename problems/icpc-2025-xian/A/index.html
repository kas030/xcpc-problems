25-ICPC-西安挑战题QOJ #14681

题面语言
完整题册

题目描述

时间限制：3.0 秒；内存限制：512 MB。

在一个宁静的杜鹃花园中，出现了 nnn 只危险的生物。每只生物都拥有攻击力和防御力。最初，第 iii 只生物（1≤i≤n1 \le i \le n1≤i≤n）的攻击力为 aia_iai​，防御力为 bib_ibi​。

你作为杜鹃花园的守护者，可以在脑海中想象它们之间的一场战争。一场战争由若干次（可能为 000 次）战斗组成。在每次想象的战斗中，你选择两只存活的生物 iii 和 jjj（1≤i,j≤n1 \le i, j \le n1≤i,j≤n，i≠ji \neq ji=j），并且：

  • 如果生物 iii 的攻击力大于或等于生物 jjj 的防御力（即 ai≥bja_i \ge b_jai​≥bj​），那么 iii 可以在战斗中击败 jjj，并且 jjj 被视为被消灭。
  • 否则，什么也不会发生。

请注意，战争是想象出来的；也就是说，在同一场战争中被消灭的生物不能用于该场战争后续的战斗，但它会在下一场战争开始时恢复活力，从而可以参与后续战争的战斗。

这些生物是不稳定的，会随着时间的推移发生变异。给你 qqq 次变异。在每次变异后，某只生物的属性会发生变化。具体来说，在第 iii 次变异中，第 viv_ivi​ 只生物的攻击力更新为 xix_ixi​，防御力更新为 yiy_iyi​。请注意，变异是持久的；在第 iii 次变异之后，前 i−1i - 1i−1 次变异的影响会累积。

由于每只残留的生物都会对花朵构成持续的威胁，你希望找到在想象战争的最佳战斗序列后，剩余生物的最小可能数量。你需要回答在所有变异开始前以及每次变异后的这一问题。

输入格式

输入的第一行包含两个整数 nnn 和 qqq（1≤n≤4⋅1051 \le n \le 4 \cdot 10^51≤n≤4⋅105，0≤q≤4⋅1050 \le q \le 4 \cdot 10^50≤q≤4⋅105），其中 nnn 是生物的数量，qqq 是变异的次数。

接下来的 nnn 行描述了所有的生物。其中的第 iii 行包含两个整数 aia_iai​ 和 bib_ibi​（1≤ai,bi≤1091 \le a_i, b_i \le 10^91≤ai​,bi​≤109），其中 aia_iai​ 是第 iii 只生物的攻击力，bib_ibi​ 是其防御力。

接下来的 qqq 行描述了所有的变异。其中的第 iii 行包含三个整数 viv_ivi​，xix_ixi​ 和 yiy_iyi​（1≤vi≤n1 \le v_i \le n1≤vi​≤n，1≤xi,yi≤1091 \le x_i, y_i \le 10^91≤xi​,yi​≤109），其中 xix_ixi​ 是生物 viv_ivi​ 的新攻击力，yiy_iyi​ 是生物 viv_ivi​ 的新防御力。

输出格式

输出 q+1q + 1q+1 行，每行包含一个整数，依次表示在任何变异发生之前以及每次变异之后的答案。

样例

输入格式 1

3 1
1 1
2 2
3 3
2 2 4

输出格式 1

1
2

说明

在样例中，在变异开始之前，第三只生物可以击败第一只和第二只生物。显然，这是想象战斗的最佳序列，因此答案为 111。

在第一次变异结束后，第二只生物的攻击力变为 222，防御力变为 444。现在第三只生物只能击败第一只生物，剩下 222 只生物。可以证明不存在更好的方案，因此答案为 222。
