J.Teleportation

23-ICPC-澳门铜牌题QOJ #7866

题面语言
完整题册

题目描述

时间限制：1.0 秒；内存限制：1024 MB。

Bobo 最近参观了一个奇怪的传送系统。该系统包含 nnn 个房间，编号为 000 到 n−1n-1n−1。每个房间都安装了一个传送装置。每个传送装置都包含一个看起来像时钟表盘的仪表板，上面有一个指针，按顺时针方向显示 000 到 n−1n-1n−1 的数字。最初，第 iii 个房间（0≤i≤n−10 \le i \le n-10≤i≤n−1）中传送装置仪表板上的指针指向数字 aia_iai​。

当 Bobo 在房间 iii（0≤i≤n−10 \le i \le n-10≤i≤n−1）时，他可以进行任意次数的以下操作：

  • 传送：立即传送到房间 (i+ai)(modn)(i + a_i) \pmod n(i+ai​)(modn)。
  • 顺时针移动指针：设置 ai←ai+1a_i \leftarrow a_i + 1ai​←ai​+1。

每次操作需要一个单位时间。Bobo 从房间 000 开始，他想尽快到达某个房间 xxx。他想知道需要多长时间。

输入格式

第一行包含两个整数 nnn（2≤n≤1052 \le n \le 10^52≤n≤105）和 xxx（1≤x≤n−11 \le x \le n-11≤x≤n−1），分别表示房间总数和 Bobo 的目标房间。

下一行包含 nnn 个整数 a0,a1,…,an−1a_0, a_1, \dots, a_{n-1}a0​,a1​,…,an−1​（0≤ai≤n−10 \le a_i \le n-10≤ai​≤n−1），其中 aia_iai​（0≤i≤n−10 \le i \le n-10≤i≤n−1）表示第 iii 个房间中仪表板指针指向的数字。

输出格式

输出一行一个整数，表示 Bobo 从房间 000 到达房间 xxx 所需的最短时间。

样例

输入格式 1

4 3
0 1 2 3

输出格式 1

4

输入格式 2

4 3
0 0 0 0

输出格式 2

4

输入格式 3

4 3
2 2 2 2

输出格式 3

2

说明

这里我们提供了第一个样例中一种可能的最佳路径的图形说明。最初，Bobo 在房间 000，每个仪表板上的指针分别指向 0,1,2,30, 1, 2, 30,1,2,3。

Bobo 进行的第一个操作是顺时针移动指针，使得房间 000 的仪表板指针指向 111。(a0=1a_0 = 1a0​=1)

然后 Bobo 传送到房间 (0+a0)(modn)=1(0 + a_0) \pmod n = 1(0+a0​)(modn)=1。

之后，Bobo 顺时针移动指针，使得房间 111 的仪表板指针指向 222。(a1=2a_1 = 2a1​=2)

然后 Bobo 传送到房间 (1+a1)(modn)=3(1 + a_1) \pmod n = 3(1+a1​)(modn)=3，到达了他的目标目的地。总共花费了 444 次操作。
