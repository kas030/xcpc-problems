G.Parity Game

题目描述

时间限制：1.0 秒；内存限制：1024 MB。

这是一个交互式问题。

Alice 和 Bob 正在进行如下游戏。游戏由参数 t∈{0,1}t \in \{0, 1\}t∈{0,1} 指定，规则如下：

有 nnn 个整数 a1,a2,…,an∈{0,1}a_1, a_2, \dots, a_n \in \{0, 1\}a1​,a2​,…,an​∈{0,1} 排成一行。只要还剩至少两个整数，两名玩家就轮流进行以下操作（从 Alice 开始）：

  • 选择两个相邻的整数 xxx 和 yyy，将它们替换为 x+yx + yx+y 或 x×yx \times yx×y（算术加法或算术乘法）。

当只剩下一个整数时游戏结束，根据剩余整数的奇偶性与参数 ttt 判断胜负：

  • t=0t = 0t=0：若剩余整数为偶数，则 Alice 获胜；否则 Bob 获胜。
  • t=1t = 1t=1：若剩余整数为奇数，则 Alice 获胜；否则 Bob 获胜。

给定初始的 nnn 个整数 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​ 和参数 ttt。你必须选择扮演 Alice 或 Bob，然后与扮演对手角色的交互器进行游戏。你的目标是赢得游戏。

输入格式

第一行包含两个整数 nnn 和 ttt (2≤n≤500,t∈{0,1}2 \le n \le 500, t \in \{0, 1\}2≤n≤500,t∈{0,1})，分别表示数组的大小和游戏参数。

第二行包含 nnn 个整数 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​ (0≤ai≤10 \le a_i \le 10≤ai​≤1)，表示数组。

交互

交互在读取两个整数 n,tn, tn,t 和数组 {ai}1≤i≤n\{a_i\}_{1 \le i \le n}{ai​}1≤i≤n​ 后开始。

你应当首先输出一行，内容为 “Alice” 或 “Bob”，表示你选择扮演的角色。如果你选择扮演 Alice，你将先手操作。否则，你将后手操作。

游戏过程如下：

  • 如果是你的回合：假设当前数组为 b1,b2,…,bmb_1, b_2, \dots, b_mb1​,b2​,…,bm​，长度为 mmm (2≤m≤n2 \le m \le n2≤m≤n)，你应当输出一个整数 ppp (1≤p≤m−11 \le p \le m-11≤p≤m−1) 和一个字符 ccc (c∈{+,*}c \in \{\texttt{+}, \texttt{*}\}c∈{+,*})，中间用空格隔开，表示你选择使用运算符 ccc 合并两个整数 bpb_pbp​ 和 bp+1b_{p+1}bp+1​。操作后，数组变为 b1,b2,…,bp−1,(bp c bp+1),bp+2,…,bmb_1, b_2, \dots, b_{p-1}, (b_p \ c \ b_{p+1}), b_{p+2}, \dots, b_mb1​,b2​,…,bp−1​,(bp​ c bp+1​),bp+2​,…,bm​，长度变为 m−1m-1m−1。
  • 如果是对手的回合：假设当前数组为 b1,b2,…,bmb_1, b_2, \dots, b_mb1​,b2​,…,bm​，长度为 mmm (2≤m≤n2 \le m \le n2≤m≤n)，你应当读取一行，包含一个整数 ppp (0≤p≤m−10 \le p \le m-10≤p≤m−1) 和一个字符 ccc (c∈{+,*}c \in \{\texttt{+}, \texttt{*}\}c∈{+,*})，表示对手选择使用运算符 ccc 合并两个整数 bpb_pbp​ 和 bp+1b_{p+1}bp+1​。操作后，数组变为 b1,b2,…,bp−1,(bp c bp+1),bp+2,…,bmb_1, b_2, \dots, b_{p-1}, (b_p \ c \ b_{p+1}), b_{p+2}, \dots, b_mb1​,b2​,…,bp−1​,(bp​ c bp+1​),bp+2​,…,bm​，长度变为 m−1m-1m−1。如果读取到的整数 ppp 为 000，则意味着你上一次的操作不合法。在这种情况下，你的程序应立即终止以接收 “Wrong Answer” 判决，否则你可能会收到任何可能的判决。

当数组中只剩下一个整数时，游戏结束，并根据题目规则进行判定。如果你赢得了游戏，你的程序将被判定为正确。如果你输掉了游戏，或者轮到你进行最后一次操作时你的操作无效，你将收到 “Wrong Answer” 判决。游戏结束时，你应该立即终止程序。

在输出你选择的角色以及你的操作后，请务必输出换行并刷新缓冲区。否则，你可能无法获得正确的判决。刷新缓冲区的方法如下：

  • C++: fflush(stdout) 或 cout.flush()；
  • Java: System.out.flush()；
  • Python: stdout.flush()。
