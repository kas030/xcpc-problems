题目描述

时间限制：1.0 秒；内存限制：1024 MB。

备受尊敬的 Panda 教授向国际大学生程序设计竞赛（International Collegiate Programming Conference）提交了 nnn 篇论文。每篇论文由 mmm 位匿名审稿人独立评审并给出评分。

评审共有七个等级，对应如下分数：

  • Strong Reject（强烈拒绝）：−3-3−3
  • Reject（拒绝）：−2-2−2
  • Weak Reject（弱拒绝）：−1-1−1
  • Borderline（边界）：000
  • Weak Accept（弱接受）：111
  • Accept（接受）：222
  • Strong Accept（强烈接受）：333

如果一篇论文的总分（所有 mmm 位审稿人评分的总和）大于或等于阈值 kkk，则该论文被接受；否则，它将被拒绝。

在审稿人提交评分后，会有一个 Rebuttal（反驳）阶段。在此阶段，Panda 最多可以选择 bbb 篇不同的论文进行反驳。反驳旨在改善审稿人对所选论文的评价。然而，审稿人的反应各不相同，会导致以下分数变化：

  • 给出高分（111 分或更高）的审稿人会对反驳产生负面反应：他们的评分会降低一个等级（例如，333 变为 222，111 变为 000）。
  • 给出低分（000 分或更低）的审稿人会对反驳产生正面反应：他们的评分会提高一个等级（例如，−3-3−3 变为 −2-2−2，000 变为 111）。

Panda 希望策略性地选择最多 bbb 篇论文进行反驳，以最大化所有反驳应用后最终被接受的论文数量。

输入格式

第一行包含一个整数 TTT (1≤T≤10001 \le T \le 10001≤T≤1000)，表示测试用例的数量。

对于每个测试用例：

第一行包含四个整数 n,m,k,bn, m, k, bn,m,k,b (1≤n≤1051 \le n \le 10^51≤n≤105, 1≤m≤101 \le m \le 101≤m≤10, −30≤k≤30-30 \le k \le 30−30≤k≤30, 0≤b≤n0 \le b \le n0≤b≤n)。其中 nnn 是论文数量，mmm 是每篇论文的审稿人数量，kkk 是接受论文的分数阈值，bbb 是最多可以选择进行反驳的论文数量。

接下来的 nnn 行中，第 iii 行包含 mmm 个空格分隔的整数 sijs_{ij}sij​ (−3≤sij≤3-3 \le s_{ij} \le 3−3≤sij​≤3)，表示第 jjj 位审稿人对第 iii 篇论文给出的初始评分。

保证所有测试用例的 ∑n≤2⋅105\sum n \le 2 \cdot 10^5∑n≤2⋅105。

输出格式

对于每个测试用例，在一行中输出一个整数，表示最终可能被接受的最大论文数量。
