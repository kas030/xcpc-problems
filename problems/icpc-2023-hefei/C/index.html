题目描述

时间限制：2.0 秒；内存限制：1024 MB。

Mr. Ham 对字符串，特别是回文串很感兴趣。今天，他找到了一个长度为 nnn 的字符串 sss。

对于长度为 nnn 的字符串 sss，他定义其从第 iii 个字符到第 jjj 个字符（1≤i,j≤n1 \le i, j \le n1≤i,j≤n）的循环子串如下：

  • 如果 i≤ji \le ji≤j，循环子串即为 sss 从第 iii 个字符到第 jjj 个字符的子串。他将其记作 s[i..j]s[i..j]s[i..j]。
  • 如果 i>ji > ji>j，循环子串即为 s[i..n]+s[1..j]s[i..n] + s[1..j]s[i..n]+s[1..j]，其中 +++ 表示两个字符串的拼接。他也将其记作 s[i..j]s[i..j]s[i..j]。

例如，如果 s=12345s = 12345s=12345，则 s[2..4]=234s[2..4] = 234s[2..4]=234，s[4..2]=4512s[4..2] = 4512s[4..2]=4512，且 s[3..3]=3s[3..3] = 3s[3..3]=3。

如果一个字符串 ttt 满足对于所有 1≤i≤n1 \le i \le n1≤i≤n 都有 t[i]=t[n−i+1]t[i] = t[n - i + 1]t[i]=t[n−i+1]，则称其为回文串。例如，1221 是回文串，而 123 不是。

给定字符串 sss，其中会有许多循环子串是回文串。记 PPP 为 sss 的所有本质不同的回文循环子串构成的集合，f(t)(t∈P)f(t) (t \in P)f(t)(t∈P) 为 ttt 作为循环子串在 sss 中出现的次数，g(t)(t∈P)g(t) (t \in P)g(t)(t∈P) 为 ttt 的长度。Mr. Ham 希望你计算：

∑t∈Pf(t)2×g(t)\sum_{t \in P} f(t)^2 \times g(t)t∈P∑​f(t)2×g(t)

答案可能非常大，你只需要输出答案对 998 244 353998\,244\,353998244353 取模的结果。

输入格式

第一行包含一个整数 nnn (1≤n≤3×1061 \le n \le 3 \times 10^61≤n≤3×106)，表示字符串 sss 的长度。 第二行包含一个长度为 nnn 的字符串 sss。sss 的每个字符都是数字。

输出格式

输出一个整数，表示求和结果对 998 244 353998\,244\,353998244353 取模后的值。

  • s[1..1]=s[3..3]=s[5..5]=0s[1..1] = s[3..3] = s[5..5] = 0s[1..1]=s[3..3]=s[5..5]=0。
  • s[2..2]=s[4..4]=1s[2..2] = s[4..4] = 1s[2..2]=s[4..4]=1。
  • s[5..1]=00s[5..1] = 00s[5..1]=00。
  • s[1..3]=s[3..5]=010s[1..3] = s[3..5] = 010s[1..3]=s[3..5]=010。
  • s[2..4]=101s[2..4] = 101s[2..4]=101。
