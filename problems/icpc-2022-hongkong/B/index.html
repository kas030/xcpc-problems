题目描述

时间限制：1 秒；内存限制：1024 MB。

Grammy 有一张 n+1n + 1n+1 行 m+1m + 1m+1 列的巨幅图片。行编号为 111 到 n+1n + 1n+1，列编号为 111 到 m+1m + 1m+1。

Grammy 决定以一种特殊的方式为这张图片上色。对于第 iii 行，Grammy 会以概率 pi,jp_{i,j}pi,j​ 将该行最左侧的 jjj (1≤j≤m1 \le j \le m1≤j≤m) 个单元格涂成黑色。对于第 jjj 列，Grammy 会以概率 qi,jq_{i,j}qi,j​ 将该列最顶部的 iii (1≤i≤n1 \le i \le n1≤i≤n) 个单元格涂成黑色。这些操作是相互独立的，且一个单元格可能被多次涂色。

我们将“美观度”定义为图片中相同颜色的极大正交连通区域的数量。在 Grammy 完成上色之前，她想知道图片中区域数量的期望值。请为她计算该图片的期望美观度。

两个单元格 xxx 和 yyy 处于同一个正交连通区域中，当且仅当它们满足以下条件： 它们颜色相同。 xxx 与 yyy 共享一条边，或者 xxx 与某个单元格 zzz 共享一条边，且 yyy 与 zzz 处于同一个正交连通区域中。

输入格式

第一行包含两个整数 n,mn, mn,m (1≤n,m≤10001 \le n, m \le 10001≤n,m≤1000)，表示图片的大小。

接下来的 nnn 行，每行包含 mmm 个整数 pi,jp_{i,j}pi,j​，表示将第 iii 行最左侧的 jjj 个单元格涂黑的概率，模 998 244 353998\,244\,353998244353。保证每一行概率之和为 111。

接下来的 nnn 行，每行包含 mmm 个整数 qi,jq_{i,j}qi,j​，表示将第 jjj 列最顶部的 iii 个单元格涂黑的概率，模 998 244 353998\,244\,353998244353。保证每一列概率之和为 111。

输出格式

输出一个整数，表示图片期望美观度对 998 244 353998\,244\,353998244353 取模的结果。
