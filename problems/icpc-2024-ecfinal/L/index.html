题目描述

时间限制：6.0 秒；内存限制：1024 MB。

企鹅 Tomorin 有一大堆石头！为了欣赏这些石头，她把其中一些放在地上，形成了 nnn 堆石头。最初，第 iii 堆石头有 aia_iai​ 个，其中 aia_iai​ 是一个非负整数。Tomorin 打算移动她的石头，你的任务是根据她的指令帮助她移动石头。

  • 1 l r v：Tomorin 重建了从 lll 到 rrr 的每一堆石头，使每一堆都有 vvv 个石头。更正式地说，对于所有满足 l≤i≤rl \le i \le rl≤i≤r 的 iii，执行 ai←va_i \leftarrow vai​←v。
  • 2 l r：Tomorin 观察从 lll 到 rrr 的石头堆。作为一个对自然数有品味的细心企鹅，她不喜欢有数字被遗漏。为了公平地解决这个问题，令 www 为在 a[l…r]a[l \dots r]a[l…r] 中没有出现的最小自然数；然后 Tomorin 从她的收藏中取出 www 个额外的石头放到这些堆中的每一堆。更正式地说，令 w=mex(al,al+1,…,ar)w = \text{mex}(a_l, a_{l+1}, \dots, a_r)w=mex(al​,al+1​,…,ar​)；对于所有 l≤i≤rl \le i \le rl≤i≤r，执行 ai←ai+wa_i \leftarrow a_i + wai​←ai​+w。这里，mex(S)=min⁡({0,1,2,3,… }∖S)\text{mex}(S) = \min (\{0, 1, 2, 3, \dots \} \setminus S)mex(S)=min({0,1,2,3,…}∖S)。
  • 3 l r：热情的饲养员 Rikki 要求计算从第 lll 堆到第 rrr 堆的石头总数，以检查你是否在敷衍 Tomorin。更正式地说，计算 ∑i=lrai\sum_{i=l}^{r} a_i∑i=lr​ai​。

输入格式

第一行包含两个整数 nnn 和 mmm (1≤n≤5×105,1≤m≤5×1051 \le n \le 5 \times 10^5, 1 \le m \le 5 \times 10^51≤n≤5×105,1≤m≤5×105)，分别表示序列的长度和操作次数。

第二行包含 nnn 个整数 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​ (0≤ai≤5×1050 \le a_i \le 5 \times 10^50≤ai​≤5×105)，表示序列 aaa。

接下来的 mmm 行中，第 iii 行首先包含一个整数 opiop_iopi​ (opi∈{1,2,3}op_i \in \{1, 2, 3\}opi​∈{1,2,3})，指定第 iii 次操作的类型。

  • 如果 opi=1op_i = 1opi​=1，则同一行后面跟着三个整数 l,rl, rl,r 和 vvv (1≤l≤r≤n,0≤v≤5×1051 \le l \le r \le n, 0 \le v \le 5 \times 10^51≤l≤r≤n,0≤v≤5×105)；
  • 否则，同一行后面跟着两个整数 lll 和 rrr (1≤l≤r≤n1 \le l \le r \le n1≤l≤r≤n)。
