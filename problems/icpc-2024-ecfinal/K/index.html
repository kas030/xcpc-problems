K.Exploration Boundary

24-ICPC-EC-Final挑战题QOJ #9985

题面语言
完整题册

题目描述

时间限制：4.0 秒；内存限制：1024 MB。

最近，FOCS 上的一篇论文《Universal Optimality of Dijkstra via Beyond-Worst-Case Heaps》引起了 Fuyu 的注意。该论文讨论了经典的单源最短路径算法如何通过具有工作集性质（working set property）的堆，在各类图上达到最优性。为了描述这种最优性，文中提出了“探索边界”（exploration boundary）的概念：即在 Dijkstra 算法运行过程中的某个时刻暂停，此时的探索边界就是图上的探索前沿，也就是那些已经被更新但距离尚未确定的顶点。

探索边界的一个示例，右侧边界是在确定了距离源点 sss 为 2 的顶点并更新其邻居后，基于左侧边界得到的。

为了更正式地定义它，考虑以下 Dijkstra 算法的描述。如果一个非空顶点集合可以在算法运行到第 6 行时通过提取 QQQ 中的顶点得到，则称其为探索边界。

对于无向图 GGG，如果我们分配不同的正权重 www，可以得到许多不同的探索边界集合。

两个探索边界的示例，它们可以通过不同的权重获得，但不能同时出现在 Dijkstra 算法的单次运行中。

给定一个无向图 GGG 和一些期望的探索边界，设源点 s=1s = 1s=1，你的任务是构造每条边的权重（如果可能的话），使得：

  • 每条边都有一个不超过 10910^9109 的正整数权重。
  • 没有两个顶点到 1 的距离相同，从而使得探索边界在 Dijkstra 算法执行过程中可以被唯一确定。
  • 所有期望的探索边界都出现在从 1 开始的 Dijkstra 算法运行过程中。

输入格式

输入包含多组测试数据。第一行包含一个整数 TTT (1≤T≤1051 \le T \le 10^51≤T≤105)，表示测试数据组数。对于每组测试数据：

  • 第一行包含两个整数 nnn 和 mmm (2≤n≤2×105,1≤m≤2×1052 \le n \le 2 \times 10^5, 1 \le m \le 2 \times 10^52≤n≤2×105,1≤m≤2×105)，分别表示顶点数和边数。
  • 接下来 mmm 行，每行包含两个整数 uuu 和 vvv (1≤u,v≤n1 \le u, v \le n1≤u,v≤n)，描述一条连接顶点 uuu 和 vvv 的无向边。
  • 接下来一行包含一个整数 kkk (1≤k≤2×1051 \le k \le 2 \times 10^51≤k≤2×105)，表示期望的探索边界数量。
  • 接下来 kkk 行，每行描述一个边界：首先是一个整数 bib_ibi​ (1≤bi≤n1 \le b_i \le n1≤bi​≤n)，表示第 iii 个边界中的顶点数量，随后是 bib_ibi​ 个整数，表示边界中的顶点。保证 bib_ibi​ 个顶点两两不同。

保证输入图是连通的，没有自环和重边，且同一组测试数据中的两个边界不会重合。所有测试数据的 nnn 之和、mmm 之和以及 bib_ibi​ 之和均不超过 10610^6106。

输出格式

对于每组测试数据：

  • 如果可以构造出这样的权重分配，则输出一行 Yes。并在下一行输出 mmm 个整数，表示输入中各边对应的权重。每个权重必须是 [1,109][1, 10^9][1,109] 范围内的正整数。
  • 否则，输出一行 No。
