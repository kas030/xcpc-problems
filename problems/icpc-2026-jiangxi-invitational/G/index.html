G.世界的意义

26-ICPC-南昌-邀挑战题QOJ #18278

题面语言
原始题面

题目描述

时间限制：2 秒；内存限制：1024 MB。

世界的意义必定在世界之外。
世界中的一切事物如其所是地存在，如其发生地发生。
世界中没有价值。
——《逻辑哲学论》

Fengmi 给你一个长度为 nnn、只包含 ( 和 ) 的字符串 sss。

你需要支持 qqq 次操作：

  1. 翻转第 kkk 个括号，即将 ( 变为 )，将 ) 变为 (。
  2. 查询区间 [l,r][l,r][l,r] 中最长合法括号子串的长度。

形式化地，你需要计算：

f(l,r)=max⁡({j−i+1∣l≤i≤j≤r∧valid⁡(i,j)}∪{0}),f(l,r)=\max\left(\{j-i+1\mid l\le i\le j\le r\land\operatorname{valid}(i,j)\}\cup\{0\}\right),f(l,r)=max({j−i+1∣l≤i≤j≤r∧valid(i,j)}∪{0}),

其中 valid⁡(i,j)\operatorname{valid}(i,j)valid(i,j) 表示子串 s[i..j]s[i..j]s[i..j] 是合法括号序列。

本题中的合法括号序列定义如下：

  1. 空序列是合法括号序列。
  2. 如果 AAA 是合法括号序列，那么 (A)(A)(A) 也是合法括号序列。
  3. 如果 AAA 和 BBB 都是合法括号序列，那么将二者拼接得到的 ABABAB 也是合法括号序列。

输入格式

第一行包含两个整数 n,qn,qn,q（1≤n,q≤2×1051\le n,q\le2\times10^51≤n,q≤2×105），分别表示括号串的长度和操作数。

第二行包含一个长度为 nnn、只由 ( 和 ) 组成的字符串 sss。不保证给定的字符串是合法括号序列。

接下来 qqq 行，每行描述以下两种操作之一：

  • 1 k（1≤k≤n1\le k\le n1≤k≤n）：翻转第 kkk 个括号。
  • 2 l r（1≤l≤r≤n1\le l\le r\le n1≤l≤r≤n）：查询区间 [l,r][l,r][l,r] 中最长合法括号子串的长度。

输出格式

对于每次第二类操作，单独输出一行一个整数，表示答案。

说明

第一组样例：

  • 初始字符串为 ()(()())。
  • 第一次查询区间 [1,8][1,8][1,8]：最长合法括号子串为 ()(()())，位于第 111 至 888 个位置，长度为 888。
  • 翻转第 444 个括号后，字符串变为 ()())())。
  • 第二次查询区间 [1,8][1,8][1,8]：最长合法括号子串为 ()()，位于第 111 至 444 个位置，长度为 444。
  • 翻转第 777 个括号后，字符串变为 ()())(()。
  • 第三次查询区间 [1,8][1,8][1,8]：最长合法括号子串为 ()()，位于第 111 至 444 个位置，长度为 444。

第二组样例：

  • 初始字符串为 (()())(()())。
  • 第一次查询区间 [1,12][1,12][1,12]：最长合法括号子串是整个字符串，长度为 121212。
  • 翻转第 333 个括号后，字符串变为 (((())(()())。
  • 第二次查询区间 [1,12][1,12][1,12]：最长合法括号子串为 (())(()())，位于第 333 至 121212 个位置，长度为 101010。
  • 翻转第 888 个括号后，字符串变为 (((())())())。
  • 第三次查询区间 [1,12][1,12][1,12]：最长合法括号子串为 (((())())())，位于第 111 至 121212 个位置，长度为 121212。
  • 第四次查询区间 [4,9][4,9][4,9]：最长合法括号子串为 ()，位于第 444 至 555 个位置，长度为 222。
