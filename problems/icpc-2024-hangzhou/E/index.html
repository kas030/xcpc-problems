题目描述

时间限制：2.0 秒；内存限制：1024 MB。

有一栋楼有 10910^9109 层，但只有 1 部电梯。初始时，电梯位于 fff 层。

有 nnn 个人在等待电梯。第 iii 个人目前在 lil_ili​ 层，想要乘坐电梯前往 rir_iri​ 层（li<ril_i < r_ili​<ri​）。由于电梯很小，它一次最多只能搭载 1 个人。

电梯向上移动 1 层需要消耗 1 单位电能。如果电梯向下移动，则不需要消耗电能。也就是说，将电梯从 xxx 层移动到 yyy 层需要消耗 max⁡(y−x,0)\max(y - x, 0)max(y−x,0) 单位电能。

请找到一种最优的接送顺序，使得总电能消耗最小。

更正式地说，设 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​ 是 nnn 的一个排列，其中 aia_iai​ 表示第 iii 个乘坐电梯的人是 aia_iai​。总电能消耗可以计算为：

∑i=1n(max⁡(lai−ra(i−1),0)+rai−lai)\sum_{i=1}^{n} (\max(l_{a_i} - r_{a_{(i-1)}}, 0) + r_{a_i} - l_{a_i})i=1∑n​(max(lai​​−ra(i−1)​​,0)+rai​​−lai​​)

其中为了方便起见，令 a0=0,r0=fa_0 = 0, r_0 = fa0​=0,r0​=f。

回想一下，长度为 nnn 的序列 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​ 是 nnn 的一个排列，当且仅当从 111 到 nnn 的每个整数（包含 111 和 nnn）在序列中恰好出现一次。

输入格式

输入包含多组测试数据。第一行包含一个整数 TTT (1≤T≤1041 \le T \le 10^41≤T≤104)，表示测试数据的组数。对于每组测试数据：

第一行包含两个整数 nnn 和 fff (1≤n≤105,1≤f≤1091 \le n \le 10^5, 1 \le f \le 10^91≤n≤105,1≤f≤109)，分别表示人数和电梯的初始位置。

接下来的 nnn 行中，第 iii 行包含两个整数 lil_ili​ 和 rir_iri​ (1≤li<ri≤1091 \le l_i < r_i \le 10^91≤li​<ri​≤109)，表示第 iii 个人想要从 lil_ili​ 层乘坐电梯前往 rir_iri​ 层。

保证所有测试数据的 nnn 之和不超过 3×1053 \times 10^53×105。

输出格式

对于每组测试数据，首先输出一行，包含一个整数，表示最小总电能消耗；然后输出另一行，包含 nnn 个整数 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​，中间用空格分隔，表示运送所有人的最优顺序。注意，这 nnn 个整数必须构成 nnn 的一个排列。如果存在多个最优顺序，输出其中任意一个即可。
