M.Make It Divisible

完整题册

题目描述

时间限制：1.5 秒。

给定一个长度为 nnn 的正整数序列 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​，如果存在一个整数 ddd 满足 l≤d≤rl \le d \le rl≤d≤r，且对于所有 l≤i≤rl \le i \le rl≤i≤r，aia_iai​ 都能被 ada_dad​ 整除，则称区间 [l,r][l, r][l,r] (1≤l≤r≤n1 \le l \le r \le n1≤l≤r≤n) 为可整除区间。如果对于所有 1≤l≤r≤n1 \le l \le r \le n1≤l≤r≤n，区间 [l,r][l, r][l,r] 都是可整除区间，则称整个序列为可整除序列。

给定另一个长度为 nnn 的序列 b1,b2,…,bnb_1, b_2, \dots, b_nb1​,b2​,…,bn​ 和一个整数 kkk，求所有满足 1≤x≤k1 \le x \le k1≤x≤k 且序列 b1+x,b2+x,…,bn+xb_1 + x, b_2 + x, \dots, b_n + xb1​+x,b2​+x,…,bn​+x 为可整除序列的整数 xxx。由于满足条件的整数可能很多，你只需要输出满足条件的 xxx 的个数以及所有这些 xxx 的和。

输入格式

输入包含多组测试数据。第一行包含一个整数 TTT (1≤T≤5001 \le T \le 5001≤T≤500)，表示测试数据组数。对于每组测试数据：

第一行包含两个整数 nnn 和 kkk (1≤n≤5×104,1≤k≤1091 \le n \le 5 \times 10^4, 1 \le k \le 10^91≤n≤5×104,1≤k≤109)。

第二行包含 nnn 个整数 b1,b2,…,bnb_1, b_2, \dots, b_nb1​,b2​,…,bn​ (1≤bi≤1091 \le b_i \le 10^91≤bi​≤109)。

保证所有测试数据的 nnn 之和不超过 5×1045 \times 10^45×104。

输出格式

对于每组测试数据，输出一行，包含两个由空格分隔的整数，第一个整数是满足条件的 xxx 的个数，第二个整数是所有满足条件的 xxx 的和。

7 79 1 7 1

0 0
100 5050

说明

对于第一组样例，满足条件的 xxx 为 x=1,x=2x = 1, x = 2x=1,x=2 和 x=5x = 5x=5。

对于第三组样例，所有 1≤x≤1001 \le x \le 1001≤x≤100 均满足条件。
