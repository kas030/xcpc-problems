题目描述

时间限制：1.0 秒；内存限制：1024 MB。

Pigeland 大学将举办 2224 年动物大学生程序设计竞赛（ACPC 2224）。与往年不同的是，今年东道主学校的参赛队伍不再被标记为非正式队伍，Pigeland 将派出正式队伍，每支队伍配备三台工作站。尽管如此，Pigeland 大学的教练 Pig-head 仍对其队伍获得金牌的机会感到不确定。因此，他决定以需要向在线评测系统上传数据为借口，提前从 AUS 出题组获取竞赛题目。

为了防止作弊，AUS 尝试使用一种特殊的密码对题目进行加密。具体来说，题目由仅包含小写英文字母的字符串表示。AUS 希望设计一个密码函数 f(x)f(x)f(x)，将小写英文字母映射为小写英文字母。对于一个题目 S=s1s2…snS = s_1s_2 \dots s_nS=s1​s2​…sn​，其加密后的版本是另一个字符串，由 F(S)=f(s1)f(s2)…f(sn)F(S) = f(s_1)f(s_2) \dots f(s_n)F(S)=f(s1​)f(s2​)…f(sn​) 给出。例如，当 S=abcabcS = \text{abcabc}S=abcabc 且 f(a)=a,f(b)=k,f(c)=af(\text{a}) = \text{a}, f(\text{b}) = \text{k}, f(\text{c}) = \text{a}f(a)=a,f(b)=k,f(c)=a 时，加密后的版本为 F(S)=akaakaF(S) = \text{akaaka}F(S)=akaaka。

作为 AUS 的一员，你的任务是设计这个密码函数 fff。AUS 的领导认为，如果存在至少一个题目可以被加密成与另一个题目相同的加密版本，且并非所有题目都产生相同的加密输出，那么该函数就是“强”的。为了验证这一点，他会给你三个题目 S1,S2S_1, S_2S1​,S2​ 和 S3S_3S3​，你需要找到一个密码函数 fff，使得 F(S1)=F(S2)F(S_1) = F(S_2)F(S1​)=F(S2​) 且 F(S1)≠F(S3)F(S_1) \neq F(S_3)F(S1​)=F(S3​)。由于 AUS 有几位经验丰富的成员，你的任务仅仅是判断是否存在这样的密码函数。

输入包含多个测试用例。第一行包含一个整数 TTT (1≤T≤1041 \le T \le 10^41≤T≤104)，表示测试用例的数量。每个测试用例包含：
