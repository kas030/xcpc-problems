C.简单字符串题

26-CCPC-南昌-邀挑战题QOJ #18947

题目描述

时间限制：5 秒；内存限制：256 MB。

我们可以定义 ABABAB 表示两个字符串 AAA，BBB 相连接，例如 A=aabA = \texttt{aab}A=aab，B=abB = \texttt{ab}B=ab，则 AB=aababAB = \texttt{aabab}AB=aabab。

并递归地定义 A1=AA^1=AA1=A，An=An−1AA^n = A^{n - 1} AAn=An−1A（n≥2n \ge 2n≥2 且为正整数）。例如 A=abbA = \texttt{abb}A=abb，则 A3=abbabbabbA^3=\texttt{abbabbabb}A3=abbabbabb。

现给定一个长度为 nnn 的字符串 SSS，给定常数 kkk，求 S=AiB1B2…BkCjS = A^iB_1B_2\dots B_kC^jS=AiB1​B2​…Bk​Cj 的方案数，其中 A,B1,B2,…,Bk,CA,B_1,B_2,\dots,B_k,CA,B1​,B2​,…,Bk​,C 为任意非空字符串，i,ji,ji,j 为任意正整数。

两种方案不同当且仅当 AAA、B1B_1B1​、B2B_2B2​、…\dots…、BkB_kBk​、CCC、iii、jjj 中有至少一个字符串或数字不同。

答案要对 998244353998244353998244353 取模。

Input

第一行两个正整数 n,k (2≤n≤5×105,0≤k≤n−2)n,k\ (2\le n\le5\times 10^5,0\le k\le n-2)n,k (2≤n≤5×105,0≤k≤n−2)，第二行一个字符串 SSS，意义见题目描述。SSS 仅由英文小写字母构成。

Output

输出一行一个整数表示答案。

Examples

Input 1

aabcc

Output 1

11
