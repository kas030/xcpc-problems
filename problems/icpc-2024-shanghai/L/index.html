题目描述

时间限制：6.0 秒；内存限制：1024 MB。

“懒人餐桌”（Lazy Susan）是一种放置在餐桌上的旋转圆盘，用于放置食物或餐具，方便围坐在桌子旁的人们分享和取用。

有 nnn 个人围坐在圆桌旁享用晚餐，每个人按顺时针方向编号为 000 到 n−1n-1n−1，且每两个人之间的距离相等。注意，在顺时针方向上，(n−1)(n-1)(n−1) 号人的旁边是 000 号人。

晚餐包含 nnn 道菜，每道菜按上菜顺序编号为 000 到 n−1n-1n−1。服务员将从第 xxx 个人开始，按顺时针顺序将餐桌上的每道菜放置在每个人的面前。具体来说，第 iii 道菜将被放置在第 [(x+i)(modn)][(x + i) \pmod n][(x+i)(modn)] 号人面前。

每次旋转“懒人餐桌”时，所有菜肴都可以顺时针或逆时针旋转到下一个人的位置。更准确地说，原本在第 iii 号人面前的菜肴，经过一次顺时针旋转后会移动到第 [(i+1)(modn)][(i+1) \pmod n][(i+1)(modn)] 号人的位置，经过一次逆时针旋转后会移动到第 [(i+n−1)(modn)][(i+n-1) \pmod n][(i+n−1)(modn)] 号人的位置。每次操作耗时 111 秒。

每个人都有一个触及距离 rir_iri​。如果存在一个整数 kkk 满足以下条件，第 iii 号人就可以享用当前在第 jjj 号人面前的菜肴：

  • −ri≤k≤ri-r_i \le k \le r_i−ri​≤k≤ri​
  • (i+k+n)(modn)=j(i + k + n) \pmod n = j(i+k+n)(modn)=j

一旦满足上述条件，该人可以立即享用这道菜。

在 nnn 个人之间共有 mmm 个偏好。第 iii 个偏好是：第 pip_ipi​ 号人希望在所有菜肴上齐后的 tit_iti​ 秒内享用到第 did_idi​ 道菜。请确定当服务员从 xxx 号人开始上菜时（对于所有 0≤x<n0 \le x < n0≤x<n），是否能满足所有偏好。

输入格式

第一行包含测试用例的数量 TTT (1≤T≤25001 \le T \le 25001≤T≤2500)。接下来是各测试用例的描述。

每个测试用例的第一行包含两个整数 n,mn, mn,m (2≤n≤5000,0≤m≤min⁡(n2,105)2 \le n \le 5000, 0 \le m \le \min(n^2, 10^5)2≤n≤5000,0≤m≤min(n2,105))，分别表示人数和偏好数量。

每个测试用例的第二行包含 nnn 个非负整数 r0,r1,…,rn−1r_0, r_1, \dots, r_{n-1}r0​,r1​,…,rn−1​ (0≤ri≤n0 \le r_i \le n0≤ri​≤n)，表示第 iii 号人的触及距离。

接下来的 mmm 行，每行包含三个整数 pi,di,tip_i, d_i, t_ipi​,di​,ti​ (0≤pi<n,0≤di<n,1≤ti≤1090 \le p_i < n, 0 \le d_i < n, 1 \le t_i \le 10^90≤pi​<n,0≤di​<n,1≤ti​≤109)，表示第 iii 个偏好的信息。保证对于任意 1≤i<j≤m1 \le i < j \le m1≤i<j≤m，满足 pi≠pjp_i \neq p_jpi​=pj​ 或 di≠djd_i \neq d_jdi​=dj​。

保证所有测试用例的 nnn 之和不超过 500050005000。 保证所有测试用例的 mmm 之和不超过 10510^5105。

输出格式

对于每个测试用例，输出一个长度为 nnn 的 010101 字符串 sss。如果服务员从第 xxx 号人开始上菜可以满足所有偏好，则 sx=1s_x = 1sx​=1，否则 sx=0s_x = 0sx​=0。
