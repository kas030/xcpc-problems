F.Fast Bogosort

24-ICPC-上海挑战题QOJ #9042

题面语言
完整题册

题目描述

时间限制：3.0 秒；内存限制：1024 MB。

你听说过 Bogosort 吗？Bogosort 是一种非常有趣的随机排序算法，它可以在最好情况下以 O(n)O(n)O(n) 的时间复杂度对一个包含 nnn 个元素的数组进行排序。该算法描述如下：

  • 均匀地随机打乱整个数组。
  • 检查数组是否有序。

是的，读完上面的算法后，你会意识到 Bogosort 的期望时间复杂度实际上是 O(n⋅n!)O(n \cdot n!)O(n⋅n!)！

Bogosort 非常迷人，但它运行得太慢了，这非常令人遗憾。因此，让我们通过使用以下算法“快速 Bogosort”（Fast Bogosort）来优化它，以对 111 到 nnn 的排列进行排序：

  • 如果数组已经有序，则停止。
  • 否则，将数组尽可能多地划分为若干段，使得每一段对应区间 [li,ri][l_i, r_i][li​,ri​] 且恰好包含数字 [li,ri][l_i, r_i][li​,ri​] 的排列。注意，这些段不能重叠，且它们的并集必须是整个范围 [1,n][1, n][1,n]。
  • 对于划分出的每一段 [l,r][l, r][l,r]，如果 l<rl < rl<r，则调用 shuffle(l, r) 来均匀地随机打乱该段内的数字。

如果我们只关心调用 shuffle(l, r) 的次数，很明显原始的 Bogosort 的期望调用次数为 n!n!n!。现在，给定一个 111 到 nnn 的排列，请计算 Fast Bogosort 调用 shuffle(l, r) 的期望次数。

输入格式

第一行包含一个整数 nnn (1≤n≤1051 \le n \le 10^51≤n≤105)，表示数组的长度。 第二行包含 nnn 个整数 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​，表示数组的内容。保证 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​ 是 1∼n1 \sim n1∼n 的一个排列。

输出格式

输出 Fast Bogosort 调用 shuffle(l, r) 的期望次数。可以证明该期望值总是一个有理数。此外，在本题的数据范围内，还可以证明当该值表示为最简分数 PQ\frac{P}{Q}QP​ 时，满足 Q≢0(mod998244353)Q \not\equiv 0 \pmod{998244353}Q≡0(mod998244353)。因此，存在唯一的整数 RRR 使得 R×Q≡P(mod998244353)R \times Q \equiv P \pmod{998244353}R×Q≡P(mod998244353)，且 0≤R<9982443530 \le R < 9982443530≤R<998244353。请输出这个 RRR。
