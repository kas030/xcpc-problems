题目描述

时间限制：7.0 秒；内存限制：1024 MB。

在幻象之夜的第十六个夜晚，骑士们聚集在一起，准备进行一场战斗。

两组骑士准备进行对决，每组包含 nnn 名骑士。第一组中第 iii 名骑士的力量值为 aia_iai​，第二组中第 jjj 名骑士的力量值为 bjb_jbj​。

你的任务是为今晚组织骑士之间的对决。每场对决涉及每组中的一名骑士，且每名骑士最多只能参加一场对决。对决的结果并不重要——真正重要的是对决变得多么狂野或疯狂。

一场对决的“疯狂度”（lunaticus）定义为参与对决的两名骑士的力量值之和。然而，有一个特殊条件：如果一场对决的疯狂度达到 998244353998244353998244353，它会溢出并重置为零。具体来说，第一组的第 iii 名骑士与第二组的第 jjj 名骑士之间的对决，其疯狂度为 (ai+bj)(mod998244353)(a_i + b_j) \pmod{998244353}(ai​+bj​)(mod998244353)。

该特殊条件仅适用于单场对决的疯狂度。在计算多场对决的疯狂度总和时，总和可以超过 998244353998244353998244353。

由于对决的场数尚未确定，你希望计算出对于每个从 111 到 kkk 的整数 xxx，今晚进行恰好 xxx 场对决时，疯狂度总和的最大可能值。此外，有 mmm 对特定的对决组合是不能组织的。请在避免这 mmm 个限制的情况下，使疯狂度总和最大化。

输入格式

第一行包含三个整数 n,m,kn, m, kn,m,k (1≤n≤105,0≤m≤3×105,1≤k≤min⁡(n,200)1 \le n \le 10^5, 0 \le m \le 3 \times 10^5, 1 \le k \le \min(n, 200)1≤n≤105,0≤m≤3×105,1≤k≤min(n,200))，分别表示每组骑士的人数、不能组织的额外对决组合数量，以及你需要回答的问题数量。

第二行包含 nnn 个整数 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​ (0≤ai<9982443530 \le a_i < 9982443530≤ai​<998244353)，表示第一组骑士的力量值。

第三行包含 nnn 个整数 b1,b2,…,bnb_1, b_2, \dots, b_nb1​,b2​,…,bn​ (0≤bi<9982443530 \le b_i < 9982443530≤bi​<998244353)，表示第二组骑士的力量值。

接下来的 mmm 行，第 iii 行包含两个整数 ui,viu_i, v_iui​,vi​ (1≤ui,vi≤n1 \le u_i, v_i \le n1≤ui​,vi​≤n)，表示你不能组织第一组的第 uiu_iui​ 名骑士与第二组的第 viv_ivi​ 名骑士之间的对决。保证所有给定的对决组合均不相同。

输出格式

在一行中输出 kkk 个数字，第 iii 个数字表示今晚进行恰好 iii 场对决时，疯狂度总和的最大可能值。对于第 iii 个数字，如果无法组织 iii 场对决，则输出 −1-1−1。
