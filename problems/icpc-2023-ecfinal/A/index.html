Little Cyan Fish（又名 Qingyu Xiao）非常喜欢 DFS 序的概念。今天，他有一个根节点为 1、包含 nnn 个顶点的有根树 TTT。对于 2≤i≤n2 \le i \le n2≤i≤n，顶点 iii 的父节点是 fif_ifi​（满足 1≤fi<i1 \le f_i < i1≤fi​<i）。

DFS 序 D=(D1,D2,…,Dn)D = (D_1, D_2, \dots, D_n)D=(D1​,D2​,…,Dn​) 表示在树的深度优先搜索过程中访问节点的序列。出现在该序列第 jjj 个位置的顶点（其中 1≤j≤n1 \le j \le n1≤j≤n）表示它是在访问了 j−1j-1j−1 个其他顶点后被访问的。在深度优先搜索过程中，如果一个顶点有多个子节点，它们将按照索引的升序进行访问。因此，在本题中，每棵有根树都有唯一的 DFS 序。
