题目描述

时间限制：3.0 秒；内存限制：1024 MB。

在学习了 Elegia 关于如何使用生成函数技巧解决组合计数问题的思路后，Little Cyan Fish 想要解决以下问题。

Little Cyan Fish 有 n+mn+mn+m 个整数，分别记为 x1,x2,…,xnx_1, x_2, \dots, x_nx1​,x2​,…,xn​ 和 y1,y2,…,ymy_1, y_2, \dots, y_my1​,y2​,…,ym​。Little Cyan Fish 已知：

  • 对于所有 1≤i≤n1 \le i \le n1≤i≤n，满足 li(x)≤xi≤ri(x)l_i^{(x)} \le x_i \le r_i^{(x)}li(x)​≤xi​≤ri(x)​。
  • 对于所有 1≤j≤m1 \le j \le m1≤j≤m，满足 lj(y)≤yj≤rj(y)l_j^{(y)} \le y_j \le r_j^{(y)}lj(y)​≤yj​≤rj(y)​。

Little Cyan Fish 尚未确定 xix_ixi​ 和 yjy_jyj​ 的具体取值。他想知道，对于任意一对整数 (a,b)(a, b)(a,b) (1≤a≤n,1≤b≤m1 \le a \le n, 1 \le b \le m1≤a≤n,1≤b≤m)，有多少种方式可以设定 xix_ixi​ (1≤i≤a1 \le i \le a1≤i≤a) 和 yjy_jyj​ (1≤j≤b1 \le j \le b1≤j≤b) 的值，使得 ∑i=1axi=∑j=1byj\sum_{i=1}^a x_i = \sum_{j=1}^b y_j∑i=1a​xi​=∑j=1b​yj​。由于结果可能非常大，你只需要输出其对 998 244 353998\,244\,353998244353 取模后的结果。

输入格式

第一行包含两个整数 nnn 和 mmm (1≤n,m≤5001 \le n, m \le 5001≤n,m≤500)。

接下来的 nnn 行描述数组 x1,x2,…,xnx_1, x_2, \dots, x_nx1​,x2​,…,xn​ 的约束。其中第 iii 行包含两个整数 li(x)l_i^{(x)}li(x)​ 和 ri(x)r_i^{(x)}ri(x)​ (1≤li(x)≤ri(x)≤5001 \le l_i^{(x)} \le r_i^{(x)} \le 5001≤li(x)​≤ri(x)​≤500)，表示一个约束。

接下来的 mmm 行描述数组 y1,y2,…,ymy_1, y_2, \dots, y_my1​,y2​,…,ym​ 的约束。其中第 jjj 行包含两个整数 lj(y)l_j^{(y)}lj(y)​ 和 rj(y)r_j^{(y)}rj(y)​ (1≤lj(y)≤rj(y)≤5001 \le l_j^{(y)} \le r_j^{(y)} \le 5001≤lj(y)​≤rj(y)​≤500)，表示一个约束。

输出格式

输出 nnn 行，每行包含 mmm 个整数。第 aaa 行的第 bbb 个整数表示设定 x1,x2,…,xax_1, x_2, \dots, x_ax1​,x2​,…,xa​ 和 y1,y2,…,yby_1, y_2, \dots, y_by1​,y2​,…,yb​ 的值使得 ∑i=1axi=∑j=1byj\sum_{i=1}^a x_i = \sum_{j=1}^b y_j∑i=1a​xi​=∑j=1b​yj​ 的方案数，对 998 244 353998\,244\,353998244353 取模。
