D.Random Permutation

23-ICPC-EC-Final挑战题QOJ #8050

题面语言
完整题册

题目描述

时间限制：3.0 秒；内存限制：1024 MB。

Little Cyan Fish 正在参加由 B 教授讲授的名为“Big-God-Live-Class”的在线竞赛编程课程。在最近的一节课中，B 教授介绍了一种使用两个优先队列寻找序列中位数的方法。受此启发，Little Cyan Fish 决定将其实现以进行练习。

具体来说，Little Cyan Fish 编写了一个程序，从输入文件中读取一个长度为 nnn 的排列 p1,p2,…,pnp_1, p_2, \dots, p_np1​,p2​,…,pn​。该程序的目标是计算所有连续子序列 pl,pl+1,…,prp_l, p_{l+1}, \dots, p_rpl​,pl+1​,…,pr​（对于每个 1≤l≤r≤n1 \le l \le r \le n1≤l≤r≤n）的中位数之和。

为了测试他的程序是否正确，Little Cyan Fish 想要均匀地生成一个 1,2,…,n1, 2, \dots, n1,2,…,n 的随机排列，并计算该和。他计划将他的程序计算出的和与正确答案进行比较。现在，你的任务是帮助他找到正确答案。

回想一下，数字列表 a1,a2,…,ata_1, a_2, \dots, a_ta1​,a2​,…,at​ 的中位数定义为列表中第 ⌊t2⌋\lfloor \frac{t}{2} \rfloor⌊2t​⌋ 小的数（注：此处原文定义为 ⌊t2⌋\lfloor \frac{t}{2} \rfloor⌊2t​⌋ 小，根据样例推断，对于长度为 ttt 的序列，中位数下标应为 ⌊t2⌋+1\lfloor \frac{t}{2} \rfloor + 1⌊2t​⌋+1 或根据题目具体定义，请参考样例说明）。例如，[1,5,4][1, 5, 4][1,5,4] 的中位数是 444，[11,4,5,14][11, 4, 5, 14][11,4,5,14] 的中位数是 555。

输入格式

第一行包含一个整数 nnn (1≤n≤3×1051 \le n \le 3 \times 10^51≤n≤3×105)。

下一行包含 nnn 个整数 p1,p2,…,pnp_1, p_2, \dots, p_np1​,p2​,…,pn​ (1≤pi≤n1 \le p_i \le n1≤pi​≤n)，表示该排列。保证 ppp 是通过均匀选择 n!n!n! 种排列之一生成的（由伪随机数生成器生成）。

最多有 202020 个测试文件。（注意，每个测试文件仅包含如上所述的单个测试用例。）

输出格式

输出一行，包含一个整数，表示答案。

样例

输入 1

4
1 4 2 3

输出 1

22

说明

  • [p1]=[1][p_1] = [1][p1​]=[1] 的中位数是 111。
  • [p2]=[4][p_2] = [4][p2​]=[4] 的中位数是 444。
  • [p3]=[2][p_3] = [2][p3​]=[2] 的中位数是 222。
  • [p4]=[3][p_4] = [3][p4​]=[3] 的中位数是 333。
  • [p1,p2]=[1,4][p_1, p_2] = [1, 4][p1​,p2​]=[1,4] 的中位数是 111。
  • [p2,p3]=[4,2][p_2, p_3] = [4, 2][p2​,p3​]=[4,2] 的中位数是 222。
  • [p3,p4]=[2,3][p_3, p_4] = [2, 3][p3​,p4​]=[2,3] 的中位数是 222。
  • [p1,p2,p3]=[1,4,2][p_1, p_2, p_3] = [1, 4, 2][p1​,p2​,p3​]=[1,4,2] 的中位数是 222。
  • [p2,p3,p4]=[4,2,3][p_2, p_3, p_4] = [4, 2, 3][p2​,p3​,p4​]=[4,2,3] 的中位数是 333。
  • [p1,p2,p3,p4]=[1,4,2,3][p_1, p_2, p_3, p_4] = [1, 4, 2, 3][p1​,p2​,p3​,p4​]=[1,4,2,3] 的中位数是 222。

因此，答案等于 1+4+2+3+1+2+2+2+3+2=221 + 4 + 2 + 3 + 1 + 2 + 2 + 2 + 3 + 2 = 221+4+2+3+1+2+2+2+3+2=22。
