C.GPA Optimization Plan

题目描述

时间限制：2.0 秒；内存限制：256 MB。

Xiao Bo 是一个勤奋的大学生，非常关心自己的学业成绩。在每个学期，他会修读若干门课程并获得相应的学分和绩点。绩点是衡量课程表现的一种方式，而平均学分绩点（GPA）是衡量学生整体学术水平的重要指标。Xiao Bo 希望能获得尽可能高的 GPA。

学校有一项特殊政策：每个学期，学生可以选择将至多一门课程的成绩转换为“通过/不通过”（PNP）模式（当然，他们也可以选择在某些学期不将任何课程转换为 PNP 模式）。在 PNP 模式下，该课程的绩点将不计入 GPA 的计算。

Xiao Bo 知道他在 mmm 个学期中总共修读了 nnn 门课程。他知道自己成绩单上每门课程的学分、绩点和学期，分别记为 si,gi,tis_i, g_i, t_isi​,gi​,ti​。保证成绩单上的前 2m2m2m 门课程满足：第 iii 门课程的学期为 ⌊i+12⌋\lfloor \frac{i+1}{2} \rfloor⌊2i+1​⌋（这确保了每个学期至少修读两门课程），而其余课程的学期则不作保证。Xiao Bo 希望在每个学期做出合理的决策，以最大化他最终的 GPA。

然而，Xiao Bo 觉得这有点太简单了，他想知道：对于任何满足 2m≤k≤n2m \le k \le n2m≤k≤n 的 kkk，如果他只考虑成绩单上第 111 到第 kkk 门课程，在考虑每个学期的 PNP 决策后，他能达到的最大 GPA 是多少？

GPA 的计算公式如下：假设当前有 nnn 门课程没有选择 PNP 模式，且第 iii 门课程的学分和绩点分别为 si,gis_i, g_isi​,gi​，则：

GPA=∑i=1nsi⋅gi∑i=1nsi\text{GPA} = \frac{\sum_{i=1}^n s_i \cdot g_i}{\sum_{i=1}^n s_i}GPA=∑i=1n​si​∑i=1n​si​⋅gi​​

输入格式

输入包含单测试点多组测试数据。输入的第一行包含一个整数 TTT（1≤T≤1041 \le T \le 10^41≤T≤104），表示测试数据的组数。

对于每组测试数据：

  • 第一行包含两个正整数 n,mn, mn,m（1≤m≤8,2m≤n≤1051 \le m \le 8, 2m \le n \le 10^51≤m≤8,2m≤n≤105），由空格隔开，分别表示课程总数和学期数。
  • 接下来的 nnn 行，每行包含三个整数 si,gi,tis_i, g_i, t_isi​,gi​,ti​（1≤si,gi≤105,1≤ti≤m1 \le s_i, g_i \le 10^5, 1 \le t_i \le m1≤si​,gi​≤105,1≤ti​≤m），由空格隔开，分别表示该课程的学分、绩点以及修读该课程的学期。保证对于所有 1≤i≤2m1 \le i \le 2m1≤i≤2m，满足 ti=⌊i+12⌋t_i = \lfloor \frac{i+1}{2} \rfloorti​=⌊2i+1​⌋。

保证所有测试数据的 nnn 之和不超过 3×1053 \times 10^53×105，即 ∑n≤3×105\sum n \le 3 \times 10^5∑n≤3×105。

输出格式

对于每组测试数据，输出 n−2m+1n - 2m + 1n−2m+1 行，每行分别对应 k=2m,k=2m+1,…,k=nk = 2m, k = 2m+1, \dots, k = nk=2m,k=2m+1,…,k=n，表示 Xiao Bo 如果只修读成绩单上第 111 到第 kkk 门课程时，所能达到的最大 GPA。

答案精度要求：你的输出将与标准答案进行比对。如果选手的输出值为 xxx，标准答案为 yyy，当满足 ∣x−y∣max⁡(1,∣y∣)≤10−6\frac{|x-y|}{\max(1,|y|)} \le 10^{-6}max(1,∣y∣)∣x−y∣​≤10−6 时，将被判定为正确。
