D.Route Investigation

完整题册

题目描述

时间限制：6.0 秒；内存限制：512 MB。

麻镇（Mazhen）的主干道呈南北走向，起点位于最南端，终点位于最北端。沿着这条道路有 n−1n-1n−1 个交叉路口，将整条道路划分为 nnn 个路段。从南到北的第 iii 个交叉路口连接了第 iii 个路段和第 i+1i+1i+1 个路段。由于方向可能存在歧义，第 iii 个交叉路口和路段均定义为从南到北方向的第 iii 个交叉路口和路段。

每个交叉路口都设有红绿灯。由于与交叉路口相连的街道具有方向性，在向北和向南行驶时，以相同颜色的信号灯通过同一个交叉路口所花费的时间可能会有所不同。研究人员认为，当随机地从南向北通过第 iii 个交叉路口时，遇到红灯、黄灯和绿灯的概率分别为 ri,yi,gir_i, y_i, g_iri​,yi​,gi​；当从北向南通过第 iii 个交叉路口时，遇到红灯、黄灯和绿灯的概率分别为 ri′,yi′,gi′r'_i, y'_i, g'_iri′​,yi′​,gi′​。假设到达交叉路口时，一定会遇到这三种情况之一：红灯、黄灯或绿灯，因此 ri+yi+gi=ri′+yi′+gi′=1r_i + y_i + g_i = r'_i + y'_i + g'_i = 1ri​+yi​+gi​=ri′​+yi′​+gi′​=1。

为了简化问题，研究人员假设无论方向和时间如何，遇到红灯、黄灯或绿灯时，等待时间总是分别为 111 秒、222 秒和 000 秒。

作为一名算法竞赛选手，研究人员很快计算出了在模 998 244 353998\,244\,353998244353 意义下，双向穿过整个路段的期望时间。然而，现在研究人员想知道一些更具体的信息。为此，研究人员进行了一次测试：从起点到终点，他记录了到达第 iii 个路段时的总等待时间，记为 aia_iai​；然后，从终点返回起点，他记录了到达第 iii 个路段时的总等待时间，记为 bib_ibi​。显然，a1=bn=0a_1 = b_n = 0a1​=bn​=0，且对于 1≤i<n1 \le i < n1≤i<n，有 ai≤ai+1≤ai+2a_i \le a_{i+1} \le a_i + 2ai​≤ai+1​≤ai​+2 且 bi+1≤bi≤bi+1+2b_{i+1} \le b_i \le b_{i+1} + 2bi+1​≤bi​≤bi+1​+2。令 ci=ai+bic_i = a_i + b_ici​=ai​+bi​。研究人员记录了这次测试中所有的 cic_ici​（1≤i≤n1 \le i \le n1≤i≤n）。

研究人员想知道这次测试的实际价值，因此他希望对于每个 i=1,2,…,ni = 1, 2, \dots, ni=1,2,…,n，求出“从起点到第 iii 个路段的总等待时间” + “从终点到第 iii 个路段的总等待时间”恰好等于 cic_ici​ 的概率，在模 998 244 353998\,244\,353998244353 意义下。这难倒了他，所以他来向你求助。

输入格式

输入的第一行包含一个整数 nnn（2≤n≤2×1052 \le n \le 2 \times 10^52≤n≤2×105）。

接下来的 n−1n - 1n−1 行，每行包含 444 个正整数。第 iii 行的 444 个正整数分别表示 100⋅ri,100⋅yi,100⋅ri′,100⋅yi′100 \cdot r_i, 100 \cdot y_i, 100 \cdot r'_i, 100 \cdot y'_i100⋅ri​,100⋅yi​,100⋅ri′​,100⋅yi′​。保证这 4(n−1)4(n - 1)4(n−1) 个正整数均不超过 100100100，且 ri+yi<1r_i + y_i < 1ri​+yi​<1 且 ri′+yi′<1r'_i + y'_i < 1ri′​+yi′​<1。

输入下一行包含 nnn 个非负整数，其中第 iii 个整数表示 cic_ici​（0≤ci≤2n0 \le c_i \le 2n0≤ci​≤2n）。保证存在满足 a1=bn=0a_1 = b_n = 0a1​=bn​=0 且对于 1≤i<n1 \le i < n1≤i<n 有 ai≤ai+1≤ai+2a_i \le a_{i+1} \le a_i + 2ai​≤ai+1​≤ai​+2 且 bi+1≤bi≤bi+1+2b_{i+1} \le b_i \le b_{i+1} + 2bi+1​≤bi​≤bi+1​+2，并且 ai+bi=cia_i + b_i = c_iai​+bi​=ci​ 的 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​ 和 b1,b2,…,bnb_1, b_2, \dots, b_nb1​,b2​,…,bn​。

输出格式

输出一行，包含 nnn 个非负整数。第 iii 个整数表示“从起点到第 iii 个路段的总等待时间” + “从终点到第 iii 个路段的总等待时间”恰好等于 cic_ici​ 的概率，在模 998 244 353998\,244\,353998244353 意义下。

说明

在样例中，在两个方向上，在第 111 个交叉路口遇到红/黄/绿灯的概率均为 14,14,12\frac{1}{4}, \frac{1}{4}, \frac{1}{2}41​,41​,21​。

此时，从南向北到达第 111 个路段且等待时间 a1=0a_1 = 0a1​=0 的概率为 111（因为没有经过任何交叉路口），而从北向南到达第 111 个路段且等待时间 b1=0b_1 = 0b1​=0 的概率为 12\frac{1}{2}21​（即在第 111 个交叉路口等待绿灯），因此 c1=0c_1 = 0c1​=0 的概率为 1×12=121 \times \frac{1}{2} = \frac{1}{2}1×21​=21​。
