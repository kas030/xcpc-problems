F.Turtle Soup

25-CCPC-重庆金牌题QOJ #15424

题目描述

时间限制：1.0 秒；内存限制：256 MB。

一个公司由 nnn 名成员组成，员工 ID 分别为 1,2,…,n1, 2, \dots, n1,2,…,n。成员 1 是老板，其他每个成员 iii（2≤i≤n2 \le i \le n2≤i≤n）都有一个直接主管 fif_ifi​（1≤fi<i1 \le f_i < i1≤fi​<i）。公司结构形成一棵以成员 1 为根的有根树。

在这家公司中，成员 aaa 认识成员 bbb 当且仅当满足以下条件中的至少一条：

  • a=ba = ba=b。
  • bbb 是 aaa 的祖先。换句话说，存在一个序列 u1,u2,…,uku_1, u_2, \dots, u_ku1​,u2​,…,uk​（2≤k2 \le k2≤k）使得 u1=au_1 = au1​=a，uk=bu_k = buk​=b，且对于所有 2≤i≤k2 \le i \le k2≤i≤k 都有 ui=fui−1u_i = f_{u_{i-1}}ui​=fui−1​​。
  • bbb 是 aaa 的直接孩子（bbb 是 aaa 的直接下属）。换句话说，fb=af_b = afb​=a。

请注意，认识关系不一定是对称的；aaa 认识 bbb 并不意味着 bbb 认识 aaa。

现在，成员们正在玩一个游戏。在每一轮中，一个特定的成员 mmm 担任猜测者，另一个成员 ppp 是目标。保证 ppp 是一个 mmm 不认识的成员。

为了确定 ppp 的身份，mmm 提出一系列问题。对于每个问题，mmm 选择一个 ID xxx 并询问：“ppp 认识成员 xxx 吗？”成员 ppp 总是如实回答。此外，如果 x=px = px=p，ppp 会特别透露自己就是成员 xxx，此时游戏结束。

每个问题都会根据公司树产生一定的移动代价。如果第 iii 个问题涉及成员 xix_ixi​，则该问题的代价为 dis(xi−1,xi)dis(x_{i-1}, x_i)dis(xi−1​,xi​)，其中 dis(a,b)dis(a, b)dis(a,b) 是树上 aaa 和 bbb 之间唯一路径上的边数。对于第一个问题（i=1i = 1i=1），代价为 dis(m,x1)dis(m, x_1)dis(m,x1​)。

成员 mmm 非常聪明，他会使用最优策略，以最小化在最坏情况下保证游戏结束所需的总代价。你的任务是为每个可能的猜测者 m∈{1,2,…,n}m \in \{1, 2, \dots, n\}m∈{1,2,…,n} 计算这个最小的最坏情况代价。

如果成员 mmm 已经认识公司中的所有人，则该 mmm 的答案为 0。

输入格式

输入的第一行包含一个整数 nnn（1≤n≤1051 \le n \le 10^51≤n≤105），表示公司中的总成员数。

第二行包含 n−1n - 1n−1 个整数，表示 f2,f3,…,fnf_2, f_3, \dots, f_nf2​,f3​,…,fn​。满足 1≤fi<i1 \le f_i < i1≤fi​<i。

输出格式

输出单行，包含 nnn 个整数，表示 m=1,m=2,…,m=nm = 1, m = 2, \dots, m = nm=1,m=2,…,m=n 时的答案。整数之间应以空格分隔。

样例

输入样例 1

3
1 1

输出样例 1

0 2 2

输入样例 2

5
1 1 3 2

输出样例 2

4 3 3 4 4

输入样例 3

6
1 1 2 2 3

输出样例 3

4 3 5 4 4 6

说明

为了解释样例 3 中 m=4m = 4m=4 的情况：首先，如图所示，成员 mmm 不认识成员 {3,5,6}\{3, 5, 6\}{3,5,6}。一种可能的最优策略是，首先询问 ppp 是否认识成员 2，代价为 1。如果是，则表明 p=5p = 5p=5，下一步是询问成员 5 以结束游戏，总代价为 2。否则，继续询问 ppp 是否认识成员 3，代价为 2。如果 p=3p = 3p=3，游戏结束，总代价为 3。否则，表明 p=6p = 6p=6，下一步花费 1 的代价询问成员 6，游戏结束，总代价为 4。因此，该策略在最坏情况下的代价为 4。可以证明，没有其他策略可以进一步降低最坏情况下的询问代价。
