题目描述

时间限制：1.0 秒；内存限制：256 MB。

有 n+1n + 1n+1 个节点，编号为 000 到 nnn。初始时，你位于节点 000。

每个节点都有一个传送门和一个计数器，其中节点 ppp（0≤p≤n0 \le p \le n0≤p≤n）的计数器记为 cpc_pcp​（初始时全部为 000）。每个计数器的取值范围在 000 到 k−1k - 1k−1 之间，代表 kkk 种传送方式。这些传送方式由数组 t1,t2,…,tk−1t_1, t_2, \dots, t_{k-1}t1​,t2​,…,tk−1​ 控制，具体规则如下。

当你位于任意节点 ppp 时，你将执行以下操作：

  1. 按下一次传送门按钮，将计数器 cpc_pcp​ 更新为 (cp+1) mod k(c_p + 1) \bmod k(cp​+1)modk。
  2. 如果更新后的 cp=0c_p = 0cp​=0，则传送至节点 p+1p + 1p+1。
  3. 否则，如果 p−tcp≥0p - t_{c_p} \ge 0p−tcp​​≥0，则传送至节点 p−tcpp - t_{c_p}p−tcp​​（特别地，当 tcp=0t_{c_p} = 0tcp​​=0 时，传送到自身也算作一次传送）。
  4. 否则，返回步骤 1 并重复上述步骤。

当你首次到达节点 nnn 时，你将立即停止，不再进行任何操作。

计算从开始到停止期间你使用传送门的次数（即成功传送的次数），并将结果模 109+710^9 + 7109+7 后输出。

输入格式

输入的第一行包含两个整数 nnn（1≤n≤1091 \le n \le 10^91≤n≤109）和 kkk（2≤k≤10002 \le k \le 10002≤k≤1000）。

第二行包含 k−1k - 1k−1 个整数，表示 t1,t2,…,tk−1t_1, t_2, \dots, t_{k-1}t1​,t2​,…,tk−1​。对于任意 i∈[1,k−1]i \in [1, k - 1]i∈[1,k−1]，满足 0≤ti≤min⁡{100,n−1}0 \le t_i \le \min\{100, n - 1\}0≤ti​≤min{100,n−1}。

输出格式

输出一个整数，表示传送门被使用的次数模 109+710^9 + 7109+7 的结果。

说明

对于第一个样例：

  • 所有节点的计数器状态为 [0,0,0][0, 0, 0][0,0,0]，且当前位置在节点 000。按下一次传送门按钮后，计数器状态变为 [1,0,0][1, 0, 0][1,0,0]。由于 t1=1t_1 = 1t1​=1 且 0−1<00 - 1 < 00−1<0，未发生传送，因此再次按下传送门按钮后，计数器状态变为 [0,0,0][0, 0, 0][0,0,0]，你传送至节点 111。
  • 当前位置在节点 111。按下一次传送门按钮后，计数器状态变为 [0,1,0][0, 1, 0][0,1,0]。由于 t1=1t_1 = 1t1​=1 且 1−1=01 - 1 = 01−1=0，你传送至节点 000。
  • 当前位置在节点 000。按下一次传送门按钮后，计数器状态变为 [1,1,0][1, 1, 0][1,1,0]。由于 t1=1t_1 = 1t1​=1 且 0−1<00 - 1 < 00−1<0，未发生传送，因此再次按下传送门按钮后，计数器状态变为 [0,1,0][0, 1, 0][0,1,0]，你传送至节点 111。
  • 当前位置在节点 111。按下一次传送门按钮后，计数器状态变为 [0,0,0][0, 0, 0][0,0,0]，你传送至节点 222。此时，你立即停止，总共进行了 444 次传送。
