题目描述

时间限制：1.0 秒；内存限制：1024 MB。

Bobo 想要使用拒绝采样算法来构造一个大小为 kkk 的随机集合 T⊂{1,2,…,n}T \subset \{1, 2, \dots, n\}T⊂{1,2,…,n}。对于参数 p1,p2,…,pnp_1, p_2, \dots, p_np1​,p2​,…,pn​ (0≤pi≤10 \le p_i \le 10≤pi​≤1) 和整数 kkk，拒绝采样器定义如下：

  1. 初始化 T←∅T \leftarrow \emptysetT←∅；
  2. 对于每个 iii (1≤i≤n1 \le i \le n1≤i≤n)，以概率 pip_ipi​ 将 iii 加入 TTT；
  3. 如果 TTT 的大小恰好为 kkk，则输出 TTT；否则，重复上述过程。

现在给定整数 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​ 和 kkk。Bobo 需要设置参数 p1,p2,…,pnp_1, p_2, \dots, p_np1​,p2​,…,pn​ 满足：

  • ∑i=1npi=k\sum_{i=1}^n p_i = k∑i=1n​pi​=k；
  • 对于所有满足 ∣S∣=k|S| = k∣S∣=k 的 S⊆{1,2,…,n}S \subseteq \{1, 2, \dots, n\}S⊆{1,2,…,n}，拒绝采样器输出 SSS 的概率与 ∏i∈Sai\prod_{i \in S} a_i∏i∈S​ai​ 成正比。

你的任务是为 Bobo 找出参数 p1,p2,…,pnp_1, p_2, \dots, p_np1​,p2​,…,pn​。保证这样的参数存在且唯一。如果每个 pip_ipi​ 与唯一正确答案的绝对误差不超过 10−610^{-6}10−6，则你的答案被视为正确。

输入格式

第一行包含两个整数 nnn 和 kkk (2≤n≤1052 \le n \le 10^52≤n≤105, 1≤k≤n−11 \le k \le n - 11≤k≤n−1)。 第二行包含 nnn 个整数 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​ (1≤ai≤1091 \le a_i \le 10^91≤ai​≤109)。

输出格式

输出 nnn 行。第 iii 行包含一个实数 pip_ipi​。 如果你的答案为 aaa，标准答案为 bbb，则当且仅当对于所有参数满足 ∣b−a∣≤10−6|b - a| \le 10^{-6}∣b−a∣≤10−6 时，你的答案被接受。
