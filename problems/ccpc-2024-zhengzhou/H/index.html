题目描述

时间限制：1.0 秒；内存限制：1024 MB。

在闲暇时间，Bobo 很喜欢玩益智游戏。他最喜欢的是《见证者》（The Witness），这是一款由 Jonathan Blow 设计并于 2016 年发行的广受好评的益智电子游戏。《见证者》包含 9 种主要类型的谜题以及若干隐藏的“环境”谜题，游戏开放世界中总共有 664 个谜题。玩家需要探索世界并推导所遇到各种谜题的规则。

在所有类型的谜题中，Bobo 最擅长一种被称为“黑白方块”的谜题。这类谜题基于矩形网格，要求玩家在网格中连接起点和终点，画出一条简单的网格路径，同时将两种不同颜色的网格单元分开。以下是该类谜题在游戏中的一些真实示例及其解法。起点和终点分别用圆圈和从网格突出的半圆标记。

给定一个“黑白方块”谜题实例，其中所有单元格要么是黑色，要么是白色，Bobo 想给你出一个挑战：你能提供该谜题的解，或者断言它无解吗？

形式上，“黑白方块”谜题的实例描述如下：

  • 两个正整数 n,mn, mn,m，表示矩形网格的行数和列数。网格中共有 n×mn \times mn×m 个单元格和 (n+1)×(m+1)(n + 1) \times (m + 1)(n+1)×(m+1) 个顶点。我们将网格左上角的顶点标记为 (0,0)(0, 0)(0,0)，右下角的顶点标记为 (n,m)(n, m)(n,m)，其余顶点依此类推。
  • 一个 n×mn \times mn×m 的二维数组，表示每个单元格的颜色。每个单元格的颜色只能是黑色或白色。
  • 一个起点 (sx,sy)(sx, sy)(sx,sy) 和一个终点 (ex,ey)(ex, ey)(ex,ey)，每个点都属于网格边界上的顶点。此处顶点 (x,y)(x, y)(x,y) 在边界上意味着满足以下至少一个条件：
    • x=0x = 0x=0
    • x=nx = nx=n
    • y=0y = 0y=0
    • y=my = my=m

此外，起点和终点不能重合。

“黑白方块”谜题的解由一条路径 P=((x1,y1),(x2,y2),…,(xℓ,yℓ))P = ((x_1, y_1), (x_2, y_2), \dots, (x_\ell, y_\ell))P=((x1​,y1​),(x2​,y2​),…,(xℓ​,yℓ​)) (ℓ≥2\ell \ge 2ℓ≥2) 描述，满足以下性质：

  • (x1,y1)=(sx,sy)(x_1, y_1) = (sx, sy)(x1​,y1​)=(sx,sy) 且 (xℓ,yℓ)=(ex,ey)(x_\ell, y_\ell) = (ex, ey)(xℓ​,yℓ​)=(ex,ey)。
  • 对于每个 2≤i≤ℓ2 \le i \le \ell2≤i≤ℓ，(xi−1,yi−1)(x_{i-1}, y_{i-1})(xi−1​,yi−1​) 和 (xi,yi)(x_i, y_i)(xi​,yi​) 在网格上相邻，即满足以下条件之一：
    • xi=xi−1x_i = x_{i-1}xi​=xi−1​ 且 ∣yi−yi−1∣=1|y_i - y_{i-1}| = 1∣yi​−yi−1​∣=1
    • ∣xi−xi−1∣=1|x_i - x_{i-1}| = 1∣xi​−xi−1​∣=1 且 yi=yi−1y_i = y_{i-1}yi​=yi−1​
  • PPP 是简单路径，即对于每个 1≤i<j≤ℓ1 \le i < j \le \ell1≤i<j≤ℓ，要么 xi≠xjx_i \neq x_jxi​=xj​，要么 yi≠yjy_i \neq y_jyi​=yj​。
  • 路径所分隔的网格的每个区域仅包含一种颜色。

输入格式

第一行包含两个整数 n,mn, mn,m (1≤n,m≤401 \le n, m \le 401≤n,m≤40)。

接下来 nnn 行，第 iii 行包含一个长度为 mmm 的字符串 sis_isi​，仅由字符 ‘B’ 和 ‘W’ 组成，其中 sis_isi​ 的第 jjj 个字符表示网格第 iii 行第 jjj 列单元格的颜色。

随后一行包含四个整数 sx,sy,ex,eysx, sy, ex, eysx,sy,ex,ey (0≤sx,ex≤n,0≤sy,ey≤m0 \le sx, ex \le n, 0 \le sy, ey \le m0≤sx,ex≤n,0≤sy,ey≤m)，表示起点和终点。保证起点和终点均在网格边界上且不重合。

输出格式

如果给定的“黑白方块”谜题实例无解，输出一行 “NO”（不含引号）。

否则，第一行输出 “YES”（不含引号）。然后输出一个整数 ℓ\ellℓ (ℓ≥2\ell \ge 2ℓ≥2)，表示解路径中包含的顶点数。接下来 ℓ\ellℓ 行，每行输出两个整数 (xi,yi)(x_i, y_i)(xi​,yi​)，表示解路径中的第 iii 个顶点。如果你的答案满足所需条件，则被视为正确。如果存在多个解，你可以输出其中任意一个。

你可以以任意大小写形式输出 “YES” 和 “NO”（例如，字符串 “yES”、“yes” 和 “Yes” 都将被识别为肯定回答）。
