F.Infinite Loop

24-CCPC-郑州铜牌题QOJ #9773

题面语言
完整题册

题目描述

时间限制：1.0 秒；内存限制：1024 MB。

Bobo 被困在一个奇特的一天无限循环中！每一天恰好有 kkk 个小时，且每天都有 nnn 个任务需要 Bobo 完成。

  • 每天的第 iii 个任务在第 aia_iai​ 个小时开始时到达，需要 bib_ibi​ 个小时的连续工作才能完成。
  • Bobo 工作勤奋且总是遵循严格的准则：只要有未完成的任务，Bobo 就会处理最早到达的那个未完成任务。

在第一天的开始，Bobo 手头没有任何任务。

你的任务是帮助 Bobo 回答 qqq 个询问。对于第 iii 个询问，给定任务到达的天数 xix_ixi​ 以及该天到达的任务索引 yiy_iyi​。你的目标是确定 Bobo 完成第 xix_ixi​ 天第 yiy_iyi​ 个任务的具体天数和小时数。

输入格式

第一行包含三个空格分隔的整数 nnn (1≤n≤1051 \le n \le 10^51≤n≤105)，kkk (1≤k≤1081 \le k \le 10^81≤k≤108) 和 qqq (1≤q≤1051 \le q \le 10^51≤q≤105)。

接下来的 nnn 行，每行包含两个空格分隔的整数，其中第 iii 行包含 aia_iai​ (1≤ai≤k1 \le a_i \le k1≤ai​≤k) 和 bib_ibi​ (1≤bi≤k1 \le b_i \le k1≤bi​≤k)。保证 aia_iai​ 严格单调递增。

随后 qqq 行，每行包含两个空格分隔的整数，其中第 iii 行包含 xix_ixi​ (1≤xi≤5×1051 \le x_i \le 5 \times 10^51≤xi​≤5×105) 和 yiy_iyi​ (1≤yi≤n1 \le y_i \le n1≤yi​≤n)。

输出格式

输出 qqq 行，其中第 iii 行输出两个空格分隔的整数 did_idi​ 和 hih_ihi​，表示第 iii 个询问对应的任务在第 did_idi​ 天的第 hih_ihi​ 个小时完成。
