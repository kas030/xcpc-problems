题目描述

时间限制：2 秒；内存限制：512 MB。

给定 nnn 条垂直线，其 xxx 坐标分别为 x1,x2,…,xnx_1, x_2, \dots, x_nx1​,x2​,…,xn​，权重分别为 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​；以及 mmm 条水平线，其 yyy 坐标分别为 y1,y2,…,ymy_1, y_2, \dots, y_my1​,y2​,…,ym​，权重分别为 b1,b2,…,bmb_1, b_2, \dots, b_mb1​,b2​,…,bm​。

若一个矩形的四条边均位于给定的直线上，则称该矩形为“好矩形”。定义一个好矩形的代价为其四条边代价之和。其中，一条边的代价等于其长度与该边所在直线权重的乘积。

求代价不超过 ccc 的好矩形的最大面积。注意，矩形的长和宽可以为零，因此答案总是存在的。

你需要回答 TTT 个关于不同 ccc 的查询。

输入格式

第一行包含三个整数 n,mn, mn,m (2≤n,m≤5 0002 \le n, m \le 5\,0002≤n,m≤5000) 和 TTT (1≤T≤1001 \le T \le 1001≤T≤100)。

第二行包含 nnn 个整数 x1,x2,…,xnx_1, x_2, \dots, x_nx1​,x2​,…,xn​ (1≤x1<x2<⋯<xn≤1051 \le x_1 < x_2 < \dots < x_n \le 10^51≤x1​<x2​<⋯<xn​≤105)。

第三行包含 nnn 个整数 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​ (1≤ai≤1071 \le a_i \le 10^71≤ai​≤107)。

第四行包含 mmm 个整数 y1,y2,…,ymy_1, y_2, \dots, y_my1​,y2​,…,ym​ (1≤y1<y2<⋯<ym≤1051 \le y_1 < y_2 < \dots < y_m \le 10^51≤y1​<y2​<⋯<ym​≤105)。

第五行包含 mmm 个整数 b1,b2,…,bmb_1, b_2, \dots, b_mb1​,b2​,…,bm​ (1≤bi≤1071 \le b_i \le 10^71≤bi​≤107)。

接下来的 TTT 行，每行包含一个整数 ccc (1≤c≤4×10121 \le c \le 4 \times 10^{12}1≤c≤4×1012)，表示一个查询。

输出格式

对于每个查询，输出一行表示答案。
