题单/25-ICPC-世界总决赛/Problem B

B.Blackboard Game

25-ICPC-世界总决赛挑战题QOJ #14602

题面语言
完整题册

题目描述

时间限制：1 秒；内存限制：2048 MB。

为了帮助她的低年级学生理解质因数分解的概念，Aisha 发明了一个让他们在黑板上玩的游戏。游戏规则如下。

游戏由两名玩家轮流进行。最初，黑板上写有从 111 到 nnn 的整数。开始时，先手玩家可以选择任意一个偶数并将其圈起来。在接下来的每一步中，当前玩家必须选择一个数字，该数字要么是当前被圈起来的数字乘以某个质数，要么是当前被圈起来的数字除以某个质数。然后，该玩家擦除之前圈起来的数字，并圈出新选择的数字。当玩家无法进行操作时，该玩家输掉游戏。

为了帮助 Aisha 的学生，请编写一个程序，在给定整数 nnn 的情况下，确定是先手（first）更有利还是后手（second）更有利，如果先手更有利，请找出一步获胜的先手开局操作。

输入格式

输入的第一行包含一个整数 ttt (1≤t≤401 \le t \le 401≤t≤40)，表示测试用例的数量。接下来是 ttt 个测试用例的描述。

每个测试用例由单行组成，包含一个整数 nnn (2≤n≤1072 \le n \le 10^72≤n≤107)，表示黑板上写着的最大数字。

在所有测试用例中，nnn 的总和最多为 10710^7107。

输出格式

对于每个测试用例，如果先手玩家对于给定的 nnn 具有必胜策略，则输出单词 first，后跟一个偶数——即任何可以延伸为必胜策略的合法第一步操作。如果后手玩家具有必胜策略，则仅输出单词 second。

样例

输入样例 1

1
5

输出样例 1

second

说明 1

对于 n=5n = 5n=5，无论第一步如何选择，先手玩家都会输掉游戏。

  • 如果先手玩家从 222 开始，后手玩家圈出 444，此时没有更多合法的操作。
  • 如果第一步是 444，后手玩家圈出 222。先手玩家随后必须圈出 111，后手玩家可以选择剩下的两个数字（333 或 555）之一即可获胜。

输入样例 2

2
12
17

输出样例 2

first 8
first 6
