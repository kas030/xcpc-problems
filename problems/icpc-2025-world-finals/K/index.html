K.Treasure Map

25-ICPC-世界总决赛铜牌题QOJ #14611

题面语言

题目描述

时间限制：4 秒；内存限制：2048 MB。

经过多年的搜寻，你终于找到了黑胡子船长那张标有他失落已久的宝藏埋藏地点的古老地图，它就深藏在海底。这张地图曾经是一幅分层设色图——也就是说，它展示了宝藏周围区域的海洋深度——但随着时间的推移，许多海拔标记已经褪色，不再清晰可辨。

具体来说，这张地图覆盖了海洋的一个矩形区域，该区域被细分为一个 (n−1)×(m−1)(n - 1) \times (m - 1)(n−1)×(m−1) 的单位正方形网格。地图最初显示了每个具有整数坐标 1≤x≤n1 \le x \le n1≤x≤n 且 1≤y≤m1 \le y \le m1≤y≤m 的点 p=(x,y)p = (x, y)p=(x,y) 的海洋深度 d(p)d(p)d(p)。该区域内没有岛屿。换句话说，已知对于所有点，都有 d(p)≥0d(p) \ge 0d(p)≥0。

绘制这张地图对黑胡子来说一定是一件相当困难的事，因为对于非整数坐标的点的深度，并没有唯一且自然的插值方法。考虑网格上的一个单位正方形，其顶点按顺时针顺序依次为 A,B,C,DA, B, C, DA,B,C,D，并且每个点 p∈{A,B,C,D}p \in \{A, B, C, D\}p∈{A,B,C,D} 都存储了某个深度 d(p)d(p)d(p)。一种自然的方法是在三角形 ABCABCABC 内进行线性插值，同样在 CDACDACDA 内也进行线性插值。另一种同样自然的方法是在 BCDBCDBCD 内进行线性插值，同样在 DABDABDAB 内也进行线性插值。通常，这两种插值的结果是不同的。例如，如果 d(A)=d(B)=d(C)=0d(A) = d(B) = d(C) = 0d(A)=d(B)=d(C)=0 且 d(D)=1d(D) = 1d(D)=1，第一种方法会导致整个 ABCABCABC 区域内的深度都等于零（图 K.1 左），而第二种方法会导致整个正方形内部的深度均为正数（右）。

图 K.1：在一个单位正方形内进行深度插值的两种方法。

然而，黑胡子既残忍又固执，他不会让这种令人讨厌的歧义阻止他。为了给他的宝藏找到完美的藏匿地点，他搜寻了七大洋，以找到一个在每个单位正方形上上述两种方法都能产生相同结果的海洋区域（或者也许他强迫他的一些海盗进行了一些地形改造工作来实现这一点——学者们对此意见不一）。

回到现在，你正在准备一次寻找宝藏的探险，并希望弄清楚宝藏可能埋藏在多深的地方。具体来说，给定地图上剩余的深度数据，你应该计算出宝藏所在位置的最小可能深度。

输入格式

输入的第一行包含五个整数 n,m,k,txn, m, k, t_xn,m,k,tx​ 和 tyt_yty​，其中 nnn 和 mmm（2≤n,m≤3⋅1052 \le n, m \le 3 \cdot 10^52≤n,m≤3⋅105）表示网格的最大坐标，kkk（1≤k≤3⋅1051 \le k \le 3 \cdot 10^51≤k≤3⋅105）是已知深度的数量，而 (tx,ty)(t_x, t_y)(tx​,ty​) 是宝藏的位置（1≤tx≤n1 \le t_x \le n1≤tx​≤n；1≤ty≤m1 \le t_y \le m1≤ty​≤m）。

接下来的 kkk 行，每行包含三个整数 x,yx, yx,y 和 ddd（1≤x≤n1 \le x \le n1≤x≤n；1≤y≤m1 \le y \le m1≤y≤m；0≤d≤1090 \le d \le 10^90≤d≤109），表示网格坐标 (x,y)(x, y)(x,y) 处的深度等于 ddd。每个点对 (x,y)(x, y)(x,y) 在输入中最多出现一次。

输出格式

如果给定的数据点可以扩展为一张有效的地图（即，对于每个单位正方形，两种插值方法产生相同的结果，且所有点的深度均为非负数），则输出一个整数：(tx,ty)(t_x, t_y)(tx​,ty​) 处的最小可能深度——可以证明这总是一个整数。否则，输出 impossible。
