题目描述

时间限制：2.0 秒；内存限制：512 MB。

你拥有一枚公平的硬币（即抛掷这枚硬币时，正面朝上和反面朝上的概率均为 50%）。你想要用它生成一个包含 nnn 个整数的序列 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​。为此，你需要重复以下过程恰好 nnn 次：

  • 不断抛掷硬币，直到出现反面为止。
  • 假设在停止前你得到了 kkk 次正面。
  • 将整数 kkk 加入序列的末尾。

对于一个整数序列 b1,b2,…,bmb_1, b_2, \dots, b_mb1​,b2​,…,bm​，定义 mex(b1,b2,…,bm)\text{mex}(b_1, b_2, \dots, b_m)mex(b1​,b2​,…,bm​) 为最小的非负整数 xxx，满足：

  • 对于每个 1≤i<x1 \le i < x1≤i<x，都存在 1≤j≤m1 \le j \le m1≤j≤m 使得 bj=ib_j = ibj​=i。
  • 对于所有 1≤j≤m1 \le j \le m1≤j≤m，都有 bj≠xb_j \neq xbj​=x。

例如，mex(0,1,0,3)=2\text{mex}(0, 1, 0, 3) = 2mex(0,1,0,3)=2，mex(4,3,2,1,0,6,7,5)=8\text{mex}(4, 3, 2, 1, 0, 6, 7, 5) = 8mex(4,3,2,1,0,6,7,5)=8 以及 mex(1,2,3)=0\text{mex}(1, 2, 3) = 0mex(1,2,3)=0。

现在，你需要计算 mex(a1,a2,…,an)\text{mex}(a_1, a_2, \dots, a_n)mex(a1​,a2​,…,an​) 的期望值，对 998 244 353998\,244\,353998244353 取模。

输入格式

输入的第一行包含一个整数 nnn (1≤n≤1051 \le n \le 10^51≤n≤105)。

输出格式

  • 否则，mex(a1)=0\text{mex}(a_1) = 0mex(a1​)=0。
