小青鱼正在对区间集合进行研究。

在本题中，我们用 [l,r][l, r][l,r] 表示区间 {x∣l≤x≤r}\{x \mid l \le x \le r\}{x∣l≤x≤r}。对于一个包含区间 [l,r][l, r][l,r] 的集合 SSS，当且仅当满足以下三个条件时，称其为 Cyanic 集合：

  1. S⊆{[l,r]∣l,r∈Z,0≤l≤r≤n}S \subseteq \{[l, r] \mid l, r \in \mathbb{Z}, 0 \le l \le r \le n\}S⊆{[l,r]∣l,r∈Z,0≤l≤r≤n}。即 SSS 中的每个元素都是端点为整数且包含在 [0,n][0, n][0,n] 内的闭区间 [l,r][l, r][l,r]。
  2. 对于所有整数 i∈[0,n]i \in [0, n]i∈[0,n]，区间 [i,i]∈S[i, i] \in S[i,i]∈S。
  3. 对于任意两个区间 [l0,r0]∈S[l_0, r_0] \in S[l0​,r0​]∈S 和 [l1,r1]∈S[l_1, r_1] \in S[l1​,r1​]∈S，如果 l0≤l1<r0≤r1l_0 \le l_1 < r_0 \le r_1l0​≤l1​<r0​≤r1​，那么区间 [l0,l1][l_0, l_1][l0​,l1​] 和 [r0,r1][r_0, r_1][r0​,r1​] 也必须属于 SSS。

为了帮助你理解，小青鱼考虑了 n=3n = 3n=3 时的以下几种情况：

  • 集合 {[0,0],[2,2]}\{[0, 0], [2, 2]\}{[0,0],[2,2]} 不是 Cyanic 集合。区间 [1,1]∉S[1, 1] \notin S[1,1]∈/S，因此违反了第二个条件。
  • 集合 {[0,0],[1,1],[2,2],[3,3],[0,2],[1,3]}\{[0, 0], [1, 1], [2, 2], [3, 3], [0, 2], [1, 3]\}{[0,0],[1,1],[2,2],[3,3],[0,2],[1,3]} 不是 Cyanic 集合。当我们选择 [l0,r0]=[0,2][l_0, r_0] = [0, 2][l0​,r0​]=[0,2] 和 [l1,r1]=[1,3][l_1, r_1] = [1, 3][l1​,r1​]=[1,3] 时，区间 [l0,l1]=[0,1]∉S[l_0, l_1] = [0, 1] \notin S[l0​,l1​]=[0,1]∈/S，因此违反了第三个条件。
  • 集合 {[0,0],[1,1],[2,2],[3,3],[0,2],[0,1],[1,2]}\{[0, 0], [1, 1], [2, 2], [3, 3], [0, 2], [0, 1], [1, 2]\}{[0,0],[1,1],[2,2],[3,3],[0,2],[0,1],[1,2]} 是一个 Cyanic 集合。
  • 集合 {[0,0],[1,1],[2,2],[3,3],[0,3],[1,2]}\{[0, 0], [1, 1], [2, 2], [3, 3], [0, 3], [1, 2]\}{[0,0],[1,1],[2,2],[3,3],[0,3],[1,2]} 也是一个 Cyanic 集合。
