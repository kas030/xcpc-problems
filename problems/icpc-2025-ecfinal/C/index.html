C.Potential Peak

25-ICPC-EC-Final挑战题QOJ #16330

题面语言
完整题册

题目描述

时间限制：6.0 秒；内存限制：2048 MB。

一个跑步俱乐部正在招募新成员并快速发展，每天恰好有一名新成员加入。每位成员加入时都有一个特定的初始实力水平，并根据他们的到来顺序被分配一个唯一的 ID。

在每天结束时，教练喜欢计算一个他称为俱乐部“总潜力”的指标。这个值就是当前所有成员个人潜力的总和。为了保持成员们的积极性，成员的潜力是通过一个涉及单次高强度训练的假设性“如果……会怎样”场景来计算的。

在这个虚构的训练中，成员可以选择付出一定量的努力来暂时提升自己的实力水平。他们每付出 111 单位的努力，其实力水平就会恰好提升 111 单位。作为回报，对于当前俱乐部中满足以下条件的每一位其他成员，他们将获得 111 单位的“快乐值”：

  • 加入俱乐部的时间严格晚于他们；且
  • 原本的实力水平严格高于他们，但由于这次训练，现在被他们追平或超越。

注意，在此计算过程中，只有该成员的实力水平会提升，而所有其他成员的实力水平仍保持在原始值不变。

单个成员的潜力定义为：通过最优地选择努力程度，他们所能获得的净收益（快乐值减去努力值）的最大可能值。这些训练完全是理论上的；它们仅用于教练的每日报告，成员们实际的实力水平日复一日保持不变。

你的任务是帮助教练计算在招募期的每一天结束时俱乐部的总潜力。

输入格式

输入的第一行包含一个整数 nnn (1≤n≤1051 \le n \le 10^51≤n≤105)，表示俱乐部招募成员的天数。

第二行包含 nnn 个整数 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​ (1≤ai≤n1 \le a_i \le n1≤ai​≤n)，其中 aia_iai​ 表示在第 iii 天加入的成员的初始实力水平。

输出格式

在单行中输出 nnn 个整数。第 kkk 个整数应当是第 kkk 天结束时俱乐部的总潜力。

样例

输入样例 1

8
1 2 3 1 2 3 2 3

输出样例 1

0 0 0 0 1 3 5 9

输入样例 2

1
1

输出样例 2

0

说明

样例 1 说明：在第 5 天，有 5 名成员，其实力水平为 [1,2,3,1,2][1, 2, 3, 1, 2][1,2,3,1,2]。对于成员 1： 有 3 名较晚加入且实力严格高于他的成员：成员 2、成员 3 和成员 5。成员 1 的最大潜力为 111，可以通过以下任一策略达到：

  • 如果成员 1 付出 111 单位的努力，他的实力将变为 222。他将追平或超越成员 2 和成员 5。快乐值为 222 单位，净收益为 2−1=12 - 1 = 12−1=1 单位。
  • 如果成员 1 付出 222 单位的努力，他的实力将变为 333。他将追平或超越成员 2、成员 3 和成员 5。快乐值为 333 单位，净收益为 3−2=13 - 2 = 13−2=1 单位。

其他成员的最大潜力均为 000。因此，第 5 天的总潜力为 111。

在第 8 天，有 8 名成员，其实力水平为 [1,2,3,1,2,3,2,3][1, 2, 3, 1, 2, 3, 2, 3][1,2,3,1,2,3,2,3]。最优努力值为 [2,1,0,2,1,0,1,0][2, 1, 0, 2, 1, 0, 1, 0][2,1,0,2,1,0,1,0]，对应的最大潜力分别为 [4,2,0,2,1,0,0,0][4, 2, 0, 2, 1, 0, 0, 0][4,2,0,2,1,0,0,0]。
