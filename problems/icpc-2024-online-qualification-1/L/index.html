题目描述

时间限制：5.0 秒；内存限制：1024 MB。

Arthur 拥有一个公牛农场。他的生意非常兴隆，以至于最近他开始为提供足够的牛栏而发愁。他的农场里有 nnn 个牛栏，还有 (n−1)(n-1)(n−1) 头公牛。重要的是，不能有两头公牛共用一个牛栏（否则它们可能会互相伤害）。Arthur 有一个遥控器，可以让他移动牛栏里的公牛。按下按钮会导致所有公牛同时移动。具体来说，如果一头公牛在按下第 iii 个按钮之前位于第 jjj 个牛栏，那么它会移动到第 ti,jt_{i,j}ti,j​ 个牛栏。

由于需要修理一些牛栏，Arthur 准备了一份包含 qqq 个询问的列表。每个询问询问是否可以通过某种方式操纵公牛，使得在最后第 bbb 个牛栏中没有公牛，前提是开始时只有第 aaa 个牛栏是空的，并且只能使用前 ccc 个按钮。记住，在任何时刻，两头公牛都不能共用一个牛栏！

输入格式

输入包含多个测试用例。第一行包含一个整数 ttt (1≤t≤20001 \le t \le 20001≤t≤2000)，表示测试用例的数量。接下来是各测试用例的描述。

每个测试用例的第一行包含三个整数 n,ℓ,qn, \ell, qn,ℓ,q (1≤n,ℓ≤2000,1≤q≤1061 \le n, \ell \le 2000, 1 \le q \le 10^61≤n,ℓ≤2000,1≤q≤106)，分别表示牛栏的数量、遥控器按钮的数量和询问的数量。

接下来的 ℓ\ellℓ 行中，第 iii 行包含 nnn 个数字 ti,1,ti,2,…,ti,nt_{i,1}, t_{i,2}, \dots, t_{i,n}ti,1​,ti,2​,…,ti,n​，其中 ti,jt_{i,j}ti,j​ 表示按下第 iii 个按钮后，第 jjj 个牛栏中的公牛将移动到的牛栏编号。

接下来的 qqq 行中，第 iii 行包含三个数字 ai,bi,cia_i, b_i, c_iai​,bi​,ci​，表示第 iii 个询问的参数。

数字 ti,jt_{i,j}ti,j​ 以及 ai,bi,cia_i, b_i, c_iai​,bi​,ci​ 经过编码以减小输入大小。一个数字 xxx 的编码是一个由两个字符组成的字符串，字符分别为 ASCII 码 48+⌊x/50⌋48 + \lfloor x/50 \rfloor48+⌊x/50⌋ 和 48+(x mod 50)48 + (x \bmod 50)48+(xmod50)。三个数字的编码是它们各自编码的拼接。例如，字符串 ?;;=EL 编码了三个数字 761,563,1078761, 563, 1078761,563,1078。

保证所有测试用例中 nnn 的总和不超过 200020002000，ℓ\ellℓ 的总和不超过 200020002000，且 qqq 的总和不超过 10610^6106。

保证 1≤ti,j,a,b≤n,0≤c≤ℓ1 \le t_{i,j}, a, b \le n, 0 \le c \le \ell1≤ti,j​,a,b≤n,0≤c≤ℓ。

输出格式

对于每个测试用例，在新的一行中打印一个长度为 qqq 的字符串。如果第 iii 个询问中可以安全地移动公牛，则第 iii 个字符应为 111，否则应为 000。
