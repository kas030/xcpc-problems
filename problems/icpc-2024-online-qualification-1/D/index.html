完整题册

题目描述

时间限制：7.0 秒；内存限制：1024 MB。

X 国正受到 Y 国的攻击！为了防御，X 国设置了 nnn 排防御工事，编号依次为 1,2,…,n1, 2, \dots, n1,2,…,n。编号为 iii 的防御工事的军事强度为 aia_iai​。如果一个防御工事的军事强度为零，则认为该防御工事被击败。初始时，没有防御工事被击败。

战斗持续 qqq 天，每天早上会发生以下事件之一：

  • 部队调动：给定参数 x,yx, yx,y，将编号为 xxx 的防御工事的军事强度设为 yyy。
  • 增援：给定参数 l,r,vl, r, vl,r,v，将编号为 l,l+1,…,rl, l+1, \dots, rl,l+1,…,r 的防御工事的军事强度增加 vvv（包括已经击败的防御工事）。
  • 招募：所有未被击败的防御工事的军事强度增加 111。
  • 训练：令 bi=max⁡{r−l+1∣1≤l≤i≤r≤n,且对于所有 l≤j≤r,aj>0}b_i = \max\{r - l + 1 \mid 1 \le l \le i \le r \le n, \text{且对于所有 } l \le j \le r, a_j > 0\}bi​=max{r−l+1∣1≤l≤i≤r≤n,且对于所有 l≤j≤r,aj​>0}，即包含防御工事 iii 且未被击败的最长连续段的长度。对于所有 1≤i≤n1 \le i \le n1≤i≤n，令 ai:=ai+bia_i := a_i + b_iai​:=ai​+bi​。
  • 阅兵：给定参数 l,rl, rl,r，查询编号为 l,l+1,…,rl, l+1, \dots, rl,l+1,…,r 的防御工事的总军事强度。

每天晚上会发生一次溃败事件：对于编号为 iii 的防御工事，如果 i<ni < ni<n 且编号为 i+1i+1i+1 的防御工事在当天中午之前已经被击败，那么该防御工事也将被击败（即其军事强度变为零）。

作为 X 国的总指挥官，你需要为每次“阅兵”操作提供正确的结果。

输入格式

第一行包含两个整数 nnn 和 qqq，分别表示防御工事的数量和天数。

第二行包含 nnn 个整数，表示 a1,…,ana_1, \dots, a_na1​,…,an​，即每个防御工事的初始军事强度。

接下来的 qqq 行描述了 qqq 天中每天早上发生的事件。在第 iii 行中，第一个整数 opopop 表示第 iii 天发生的事件类型：

  • 如果 op=1op = 1op=1，发生部队调动，随后给出参数 x,yx, yx,y。
  • 如果 op=2op = 2op=2，发生增援，随后给出参数 l,r,vl, r, vl,r,v。
  • 如果 op=3op = 3op=3，发生招募。
  • 如果 op=4op = 4op=4，发生训练。
  • 如果 op=5op = 5op=5，发生阅兵，随后给出参数 l,rl, rl,r。

保证 1≤n,q≤3×1051 \le n, q \le 3 \times 10^51≤n,q≤3×105 且 1≤ai≤1051 \le a_i \le 10^51≤ai​≤105。对于部队调动事件，保证 1≤x≤n1 \le x \le n1≤x≤n 且 0≤y≤1050 \le y \le 10^50≤y≤105。对于增援事件，保证 1≤l≤r≤n1 \le l \le r \le n1≤l≤r≤n 且 1≤v≤1051 \le v \le 10^51≤v≤105。对于阅兵事件，保证 1≤l≤r≤n1 \le l \le r \le n1≤l≤r≤n。

输出格式

对于每次“阅兵”事件，输出一行一个整数，表示答案。
