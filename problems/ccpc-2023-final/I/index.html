I.All the Way Left

题目描述

时间限制：2.5 秒；内存限制：1024 MB。

Little Drink Congee 是 Little Cyan Fish 的好朋友，也是著名表演团体 All the Way Left 的成员。他最近一直在练习在舞台上辨别方向的能力。为了练习，他在舞台上选了 nnn 个不同的点 A1,A2,…,AnA_1, A_2, \dots, A_nA1​,A2​,…,An​。舞台被表示为一个二维笛卡尔坐标系，其中第 iii 个点位于坐标 (xi,yi)(x_i, y_i)(xi​,yi​)。Little Drink Congee 想要按照 p1,p2,…,pnp_1, p_2, \dots, p_np1​,p2​,…,pn​ 的顺序经过所有这些点。遍历是一个长度为 nnn 的排列 ppp，其中每个点 ApiA_{p_i}Api​​ 都通过一条有向线段连接到 Api+1A_{p_{i+1}}Api+1​​。

Little Drink Congee 认为一个遍历是“好的”，当且仅当满足以下条件：

  • 它是不自相交的，即除了相邻线段在公共端点处相交外，没有两条线段相交。
  • 对于每个 1≤i≤n−21 \le i \le n - 21≤i≤n−2，第 iii 次转向是向左的（或直行）。形式上，向量 ApiApi+1⃗\vec{A_{p_i}A_{p_{i+1}}}Api​​Api+1​​​ 和 Api+1Api+2⃗\vec{A_{p_{i+1}}A_{p_{i+2}}}Api+1​​Api+2​​​ 的叉积是非负的。

Little Drink Congee 想知道“好的”遍历的数量，结果对 (109+7)(10^9 + 7)(109+7) 取模。然而，他需要花时间陪伴 Little Cyan Fish，无法自己解决这个挑战。请帮他计算一下！

输入格式

第一行包含一个整数 TTT (1≤T≤1041 \le T \le 10^41≤T≤104)，表示测试用例的数量。 对于每个测试用例，第一行包含一个整数 nnn (1≤n≤2×1031 \le n \le 2 \times 10^31≤n≤2×103)。 接下来的 nnn 行中，第 iii 行包含两个整数 xix_ixi​ 和 yiy_iyi​ (1≤xi,yi≤1091 \le x_i, y_i \le 10^91≤xi​,yi​≤109)，表示点 AiA_iAi​ 的坐标。所有点的坐标各不相同。 保证所有测试用例的 n2n^2n2 之和不超过 4×1064 \times 10^64×106。

输出格式

对于每个测试用例，输出一行，包含“好的”遍历的数量，结果对 (109+7)(10^9 + 7)(109+7) 取模。
