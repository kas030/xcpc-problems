A.Doubt VS Lie

22-CCPC-网预选签到题QOJ #14534

原始题面

题目描述

时间限制：1.0 秒；内存限制：512 MB。

Doubt VS Lie 是一种扑克游戏。最初有 4 名玩家，分别用 0, 1, 2, 3 表示。对于玩家 xxx，定义 S(x)S(x)S(x) 为他/她当前手牌的集合。在最开始，对所有 0≤x≤30 \le x \le 30≤x≤3 有 ∣S(x)∣=13|S(x)| = 13∣S(x)∣=13，且对于任意 0≤x,y≤3,x≠y0 \le x, y \le 3, x \neq y0≤x,y≤3,x=y，有 S(x)∩S(y)=∅S(x) \cap S(y) = \emptysetS(x)∩S(y)=∅。⋃S(x)\bigcup S(x)⋃S(x) 恰好是一副不含大小王的扑克牌。正如你稍后会知道的，在这个游戏中，卡牌的花色并不重要。因此，你可以假设 ⋃S(x)\bigcup S(x)⋃S(x) 恰好包含 4 张 Ace、4 张 2、4 张 3、……、4 张 Queen 和 4 张 King。为方便起见，在输入/输出和以下说明中，我们用 “1” 表示 Ace，“11” 表示 Jack，“12” 表示 Queen，“13” 表示 King，其他牌则用它们的数字（2 到 10）表示。

游戏过程如下：

  1. 首先，玩家 0 选择一个 xxx（1≤x≤131 \le x \le 131≤x≤13）以及他/她手中的任意 yyy（1≤y≤∣S(0)∣1 \le y \le |S(0)|1≤y≤∣S(0)∣）张牌，将这 yyy 张牌背面朝上放在桌上，然后声明：“这是 yyy 张牌 xxx”。
  2. 当玩家 ppp 完成他/她的操作后，轮到玩家 qqq（q=(p+1) mod 4q = (p + 1) \bmod 4q=(p+1)mod4）。
    • (a) 如果玩家 ppp 打出了牌并声明“这是 yyy 张牌 xxx”，玩家 qqq 可以选择：
      • i. 从他/她手中任意打出 zzz（1≤z≤∣S((p+1) mod 4)∣1 \le z \le |S((p + 1) \bmod 4)|1≤z≤∣S((p+1)mod4)∣）张牌，背面朝上放在桌上，然后声明：“这是 zzz 张牌 xxx”。注意，xxx 必须与玩家 ppp 声明的相同。
      • ii. 不打牌并提出质疑。然后他将翻开玩家 ppp 刚刚打出的牌，并检查其声明是否属实。如果属实，则质疑失败，玩家 qqq 必须将桌上的所有牌收回自己手中。否则，质疑成功，玩家 ppp 必须将桌上的所有牌收回自己手中。
    • (b) 如果玩家 ppp 提出了质疑，无论质疑是否成功，玩家 qqq 都要选择一个 xxx（1≤x≤131 \le x \le 131≤x≤13）以及他/她手中的任意 yyy（1≤y≤∣S(q)∣1 \le y \le |S(q)|1≤y≤∣S(q)∣）张牌，将这 yyy 张牌背面朝上放在桌上，并像玩家 0 最初那样声明：“这是 yyy 张牌 xxx”。注意，此时 xxx 可以任意选择。
  3. 当有玩家选择提出质疑，在某人收走桌上的所有牌之后，如果有人手中没有牌，则该玩家赢得游戏。

为简化起见，这次你只需要编写一个程序来模拟游戏过程。

输入格式

首先是 4 行，第 iii 行包含 13 个数字，表示玩家 (i−1)(i - 1)(i−1) 手中的牌。

接下来一行包含一个整数 mmm（2≤m≤202 \le m \le 202≤m≤20），表示游戏的轮数。接下来的 mmm 行，每行是以下格式之一（不含引号）：

  1. “S x y a1 a2 ... ay”，表示当前玩家打出牌 a1,a2,…,aya_1, a_2, \dots, a_ya1​,a2​,…,ay​，并声明“这是 yyy 张牌 xxx”。
  2. “! y a1 a2 ... ay”，表示当前玩家选择不提出质疑，并打出 yyy 张牌 a1,a2,…,aya_1, a_2, \dots, a_ya1​,a2​,…,ay​，并声明“这是 yyy 张牌 xxx”，其中 xxx 保持不变。
  3. “?”，表示当前玩家选择提出质疑。

测试数据保证所有操作都是合法的。并且在游戏过程中，没有人会赢得游戏（即游戏不会提前结束）。

输出格式

输出共 4 行，第 iii 行按非递减顺序输出在 mmm 轮后玩家 (i−1)(i - 1)(i−1) 手中的牌。
