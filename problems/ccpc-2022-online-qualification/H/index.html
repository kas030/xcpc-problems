题目描述

时间限制：1.0 秒；内存限制：512 MB。

彼得对数学非常痴迷。他经常研究有趣的数学问题。有一次，他对倍数问题产生了兴趣。设 S[L,R](x)S_{[L,R]}(x)S[L,R]​(x) 为区间 [L,R][L, R][L,R] 内 xxx 的倍数集合。形式化地，S[L,R](x)={d∣L≤d≤R,x∣d}S_{[L,R]}(x) = \{d \mid L \le d \le R, x \mid d\}S[L,R]​(x)={d∣L≤d≤R,x∣d}。

他将一个集合的权重定义为该集合中所有元素的和。然后，他将 S[L,R](x)S_{[L,R]}(x)S[L,R]​(x) 的所有非空子集的权重相加，得到结果 KKK。

不幸的是，彼得丢三落四。在完成计算任务后，他忘记了初始的 xxx 是什么。然而，他写下了区间 [L,R][L, R][L,R] 和结果 KKK。现在他想让你——一位聪明的 XCPCer，告诉他所有可能的 xxx。

输入格式

本题包含多组测试数据。

第一行包含一个整数 TTT (1≤T≤1001 \le T \le 1001≤T≤100)，表示彼得完成的计算任务数量。

接下来的 TTT 行中，每行包含三个整数 L,RL, RL,R (1≤L≤R≤10121 \le L \le R \le 10^{12}1≤L≤R≤1012) 和 KKK (1≤K≤10141 \le K \le 10^{14}1≤K≤1014)，分别表示区间和结果。

输出格式

对于每个任务，如果没有合法的 xxx，输出 No Solution。如果合法的 xxx 的数量超过 10510^5105，输出 Too Many!。否则，在第一行输出合法 xxx 的数量，然后在下一行按升序输出所有合法的 xxx，用空格隔开。
