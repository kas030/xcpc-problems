N.New CCPC Rules

26-CCPC-网预选签到题QOJ #20728

题面语言
原始题面

题目描述

时间限制：1 秒；内存限制：512 MB。

为了增强比赛的悬念和观赏性，CCPC 提出了一种采用“动态揭榜／发放气球”机制的新赛制。在这一赛制下，比赛过程中不会立即公开每支队伍具体通过了哪些题目，而是动态揭晓榜单信息。

根据规则，当以下任一条件成立时，某道题对应的榜单信息将“解冻”：

  • 通过该题的队伍数大于等于 505050。
  • 通过该题的队伍数大于等于参赛队伍总数的 20%20\%20%，这一比例对应的人数不一定是整数。
  • 比赛进入“封榜”时段。具体来说，时间以 HH:MM 格式表示从开赛起经过的时间；从第 240240240 分钟起（含第 240240240 分钟）进入封榜时段。

这一赛制尚未正式确定，本次网络赛也未采用。不过，为了提前熟悉接下来的现场赛规则，请你在本题中实现上述判定。

已知一场比赛共有 nnn 支参赛队伍，其中 mmm 支队伍通过了某道题，以及当前的比赛时间。请判断这道题目前是否满足解冻条件。

输入格式

第一行包含一个整数 TTT（1≤T≤1001\le T\le 1001≤T≤100），表示测试用例数。

接下来 TTT 行，每行包含两个整数 n,mn,mn,m（2≤n≤1042\le n\le 10^42≤n≤104，0≤m≤n0\le m\le n0≤m≤n）和一个格式为 HH:MM 的字符串，分别表示参赛队伍总数、当前通过这道题的队伍数，以及当前的比赛时间。保证时间在 00:00 到 05:00 之间，包含两个端点。

输出格式

对于每个测试用例，若满足解冻条件，输出 YES；否则输出 NO。

样例

输入

5
100 50 00:00
100 10 03:59
100 10 04:00
100 20 02:00
10000 0 05:00

输出

YES
NO
YES
YES
YES

Problem Statement

Time limit: 1 s; Memory limit: 512 MB.

To enhance the suspense and spectator appeal of the contest, the CCPC has introduced a new format featuring a “dynamic scoreboard/balloon-awarding” system. Under this format, the specific problem numbers solved by each team are not displayed immediately during the contest; instead, the scoreboard is revealed dynamically.


Introduction to the new CCPC rules

According to the rules, the scoreboard status for a specific problem “unfreezes” when any one of the following three conditions is met:

  1. The number of teams that have solved the problem is greater than or equal to 50\mathbf{50}50.
  2. The number of teams that have solved the problem is greater than or equal to 20%\mathbf{20\%}20% of the total number of participating teams (not necessarily an integer).
  3. The contest enters the “scoreboard freeze” period. Specifically, the time is represented by a string in the format “HH:MM” indicating the elapsed contest time; the freeze period begins at the 240\mathbf{240}240-minute mark (inclusive).

Although the new format has not yet been officially finalized and is not used in the online contest, please implement this new rule for this problem to better prepare for the upcoming on-site contests.

Given a contest with nnn participating teams, a problem solved by mmm teams, and the current time, please determine whether the problem currently meets the criteria for unfreezing.

Input

The first line contains an integer TTT (1≤T≤1001 \le T \le 1001≤T≤100), representing the number of test cases.

The next TTT lines each contain two integers n,mn,mn,m (2≤n≤1042\leq n\leq 10^42≤n≤104, 0≤m≤n0\leq m\leq n0≤m≤n) and a string in “HH:MM” format, representing the total number of teams, the current number of teams that have solved a specific problem, and the current time, respectively. The input guarantees that the current time is between “00:00” and “05:00” (inclusive).

Output

For each test case, output “YES” if the unfreezing condition is met, or “NO” otherwise.

Examples

Input 1

5
100 50 00:00
100 10 03:59
100 10 04:00
100 20 02:00
10000 0 05:00

Output 1

YES
NO
YES
YES
YES
