难度分级说明

本站根据正式队伍及各奖牌组的赛内通过率，将题目分为签到、铜牌、银牌、金牌和挑战五档，用于训练选题。

如何判定难度

金、银、铜牌组互不重叠。每组的通过率为：该组通过题目的队伍数 ÷ 该组总队伍数。

按下表从上往下判断，取第一个满足条件的难度。

判定条件 标签
铜牌组通过率 ≥ 90%，且全部正式队伍通过率 ≥ 80% 签到题
未达到签到条件，铜牌组通过率 ≥ 50% 铜牌题
铜牌组不足 50%，银牌组达到 50% 银牌题
铜、银牌组均不足 50%，金牌组达到 50% 金牌题
各奖牌组均未达到 50% 挑战题

例如，铜、银、金牌组通过率分别为 12%、65%、92% 时，该题为银牌题。题目详情页可查看各组的通过队数与总队数。

奖牌组如何划分

只统计正式队伍在比赛期间的通过情况，不计打星队、场外队和赛后提交。

按比赛奖牌人数，将正式队伍分为金、银、铜牌组。缺少奖牌人数的比赛，按榜单排名比例估算，并在比赛页面标注。

榜单数据来自 XCPCIO。发现统计错误，可附上题目链接和依据在 GitHub 反馈。
